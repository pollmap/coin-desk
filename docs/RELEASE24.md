# 0.24 — 모바일에서 지표부터 보기

## 바꾼 이유와 범위

모바일 첫 화면의 여덟 코인 표는 지표 분석이라는 서비스의 용도를 설명하지 못했고, 작은 화면에서는 분석 링크가 가로 스크롤 밖에 있었습니다. 지표 선택창의 중복 분류와 긴 설명, 날짜 도구의 겹침도 확인했습니다. 이번 변경은 기존 지표를 모바일에서 바로 읽고 조작하는 흐름에 집중합니다.

## 화면과 행동

| 위치 | 변경 |
|---|---|
| 모바일 첫 진입 | 별도 조건 없는 `/`에서 BTC MVRV·최근 5년을 바로 표시합니다. 실시간 현재 가격과 최근 확정 지표 관측은 구분합니다. |
| 탐색 | 하단 지표·시장·비교·내 저장. 지표 탭은 마지막 분석으로 돌아갑니다. 데스크톱 첫 화면은 시장입니다. |
| 지표 | MVRV·가격 위치·레인보우·RSI·펀딩률 중 지원되는 지표를 차트 위에서 바로 엽니다. 지표 이름의 펼침 버튼으로 다른 지표를 검색합니다. |
| 선택창 | 검색과 네 분류를 유지하고, 별도 질문 버튼 여섯 개와 반복 지원 문구를 제거했습니다. 목적별 검색 별칭은 유지합니다. |
| 도구 | 기간·날짜·구간 확대·더보기 한곳. 모바일 가격 비교·원천·전체화면은 더보기에서 엽니다. |
| 설명 | 가까이에는 한 줄 뜻, 차트 아래에는 원천·관측일·공식·예시·한계. 사전은 설명 전용입니다. |
| 저장 | 지표명 옆 분석 저장, 하단 내 저장에서 재개. 기존 백업·개인 자료 형식은 유지합니다. |
| 시장 | 모바일은 코인·가격·24시간 변화·분석 링크가 화면 안에 들어오는 행으로 표시합니다. 거래대금·30일 선은 넓은 화면에 유지합니다. |

흰색·청록·보리와 저장한 다크 테마를 유지합니다. 장식 카드, 홍보 문구, 새 라이브러리는 추가하지 않았습니다. 가장 좁은 화면에서는 한글 코인명 대신 티커를 표시하며 선택창에는 전체 이름을 제공합니다. 버튼 위치를 움직이는 효과는 없습니다.

## 호환과 구현

기존 `metric`, 기간·날짜·비교·주석·원천 URL과 저장 설정을 우선합니다. 명시적인 시장 `sort`, `view`, `theme`, `market` 링크는 시장에서 열립니다. `/coins`는 모바일에서도 시장이고 화면 크기를 바꾸는 것만으로 현재 페이지를 이동시키지 않습니다.

시장 일괄 조회와 중앙 SSE 가격 연결을 유지합니다. 지표 첫 진입은 현재 가격을 위한 시장 일괄 조회 한 번과 선택한 지표 이력을 요청합니다. 관계·테마·전체 overview를 선행 조회하지 않습니다. 수집기, DB 스키마, 예약 작업, 가격 유효성 및 지표 계산은 변경하지 않습니다.

날짜 버튼의 글자가 10×2px로 눌리던 문제는 오래된 범례용 `button > span` 규칙을 제거해 해결했습니다. 수정 화면의 기존 모바일 규칙을 정리하고 쓰지 않는 질문 버튼 스타일을 제거했습니다. 모든 과거 CSS를 정리한 것은 아닙니다.

실데이터 저장 검수에서 USD 참조 분석을 저장하면 현재 가격의 거래소가 Upbit에서 Binance로 바뀌고, 고정한 날짜가 사라지는 문제도 발견했습니다. 현재 가격 원천과 분석 원천을 각각 보존하고, 고정 날짜는 기존 `analysisOptions`의 `reading_date`로 백업·복원합니다. 공유 링크에도 고정 날짜를 포함하며 실제 관측이 없는 날짜는 값을 만들지 않습니다. 날짜 복원이 명시한 확대 구간을 덮어쓰지 않도록 분리했습니다. 설정 버전과 기존 저장 키는 바꾸지 않습니다.

## 검증과 배포

[0.24 감사 기록](audit-24/README.md)에 로컬·원격 CI·배포와 운영 화면 검증을 구분합니다. API/웹 컨테이너와 Pages만 교체하고 이전 이미지와 정적 자산은 보존합니다. 수집·시세 허브·백업 프로세스와 DB는 유지합니다.

자동 검사는 첫 진입·320/390/430px 조작·테마 대비·초점 복귀·시장 이동·코인 전환·날짜 고정·저장 복원과 기존 전체 회귀를 포함합니다. 실제 데이터 화면도 별도로 확인합니다. Apple Safari·VoiceOver 실기기와 처음 사용하는 사람 5명의 사용성 검사는 미검증입니다. 48시간 대기는 완료 조건에 넣지 않습니다.
