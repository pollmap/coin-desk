# Coin Desk 0.12 — 같은 코인, 같은 가격 기준

2026-09-24. 데스크톱에서 코인 선택 → 가격 기준 선택 → 분석으로 이어지는 흐름을 정리했습니다.

## 바뀐 동작

- 작은 선택 상자를 이름·로고가 큰 검색형 코인 선택기로 교체했습니다. BTC·DOGE·ETH 바로가기, 8개 코인 검색, 한글 별칭, Enter 선택, Escape/바깥 클릭 닫기를 지원합니다. 해당 분석을 지원하지 않는 코인을 고르면 전체 가격으로 이동합니다.
- 전체 가격과 기술적 분석, 시장 시세, 성과 비교는 같은 `price-market` 설정을 사용합니다. URL의 명시적 선택이 우선합니다. KRW는 Upbit, USDT는 Binance 실제 가격이며 환율 환산을 하지 않습니다.
- 전체 가격은 선택 거래소의 최초 확보 일봉부터 확정 종가를 보여줍니다. DOGE Binance는 2019-07-05, Upbit는 2021-02-24부터입니다. 상장 이전 이력 링크는 별도 Coin Metrics USD 참조가격을 엽니다. DOGE 최초 참조 관측은 2014-01-23입니다. 참조·체결 가격을 이어 붙이지 않습니다.
- 로그축을 우측의 독립 가격축 버튼으로 배치했습니다. 지표 탐색은 가로 행 목록으로 바꾸고 설명·산식은 펼쳐 읽습니다. 일상적인 수집시각은 데이터 정보 안에 두되 지연·오류는 유지합니다.
- 웃는 시바견과 청록 워드마크를 사이드바, 브랜드 화면, 사이트 아이콘, 공유 메타데이터에 적용했습니다. DOGE에는 dogecoin.com의 코인 식별 이미지를 사용합니다.
- `/research`에 사용자 제공 37개 계정을 중복 제거해 등록했습니다. 이름·핸들 검색, 즐겨찾기, 선택 코인 X 검색, 미디어·제공된 영상/사이트 링크가 작동합니다. 리스트의 다른 계정이나 언급된 소속 조직을 임의로 추가하지 않았습니다.

## 자동 갱신의 실제 범위

방문자와 무관한 Cloudflare Cron이 매분 실행됩니다. 현재 시세 화면은 60초마다 조회합니다. 배경 시세 수집은 기존 480초 목표 주기이며, 1시간봉·일별 지표도 각각 원천 주기에 따릅니다. 모든 데이터가 매분 새 값으로 바뀐다는 의미는 아닙니다. 48시간은 갱신 간격이 아니라 운영 관찰 구간입니다. 과거 실패 기록을 삭제하거나 48시간 연속 무장애로 표현하지 않습니다.

X 자동 수집기는 구현했지만 아직 비활성입니다. 배포 환경에 X 인증키가 없음을 키 이름만 조회해 확인했습니다. [연결 방법과 제한](RESEARCH_CONNECTION.md)을 참조하세요. API에 연결하지 않은 상태를 실제 피드처럼 표시하지 않습니다.

## 검증

- TypeScript + Vitest 267개 / 30파일 통과. 검색 별칭, URL/통화 유지, 확정 종가 분리, 37계정 중복/소속 제외, X 호출 cap·동시 실행·실패 차단·민감정보 비노출 포함.
- Python Decimal 기준 EMA/RSI/Bollinger/MACD 검증 통과.
- 브랜드 이미지 실제 PNG 헤더, 원본 크기 1254×1254, manifest/OG 연결 검사 통과.
- 브라우저에서 DOGE KRW → 기술적 분석의 KRW 유지, 비트 검색 → BTC 전환, 2014년 USD 이력, 지표 행 목록, CW → DOGE 원문 검색을 확인했습니다.
- X 인증 호출의 실제 성공은 아직 검증하지 못했습니다. 테스트는 로컬 SQLite와 응답 fixture이며 공개 계정 링크와 별개입니다.
