# 0.26.1 — 시장 첫 로딩과 관심목록

시장 진입에 필요하지 않은 지표·사전 카탈로그를 지연 로드합니다. 지표 검색을 시작하거나 이전 분석 주소를 열 때 해당 코드를 받습니다. 코인 검색과 기본 분석 연결은 같은 지원 정의를 사용하는 작은 모듈로 분리했습니다.

- 관심 코인을 8개로 잘라 저장하던 오류를 수정했습니다. 150개까지 저장·백업·복원하며, 시장에서 별을 누를 때 기존 분석·주석·추가 개인 설정을 변경하지 않습니다.
- 처음 지표 검색이 늦게 응답해도 Enter로 열 수 있습니다. 검색어를 지우거나 초점을 옮긴 뒤 도착한 응답은 이동을 실행하지 않습니다.
- 이전 공유 링크의 코인·지표·기간·날짜·해시를 보존합니다.
- Pages의 내용 해시가 붙은 `/assets/` 파일에 장기 캐시를 적용합니다. HTML·API에는 적용하지 않으며 이전 파일을 보존해 열린 탭의 호환을 유지합니다.
- 처음 JavaScript는 gzip 143.15KB에서 117.88KB로 약 17.7% 감소했습니다. 코드 전송량과 실제 LCP는 별도 지표입니다.
- README의 현재 구조를 VPS Node·SQLite·시세 스트림으로 바로잡았습니다. 과거 Cloudflare 증거는 당시 기록으로 유지합니다.

수집 코드·공개 API·DB 스키마·기존 브라우저 저장 키는 변경하지 않습니다. 원격 CI·배포·실제 데이터 확인 결과는 [감사 기록](audit-26/patch-0261/README.md)에 구분합니다.
