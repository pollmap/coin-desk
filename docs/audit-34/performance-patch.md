SSE는 **150개 자산·실제 지원 거래소 조합 241개를 구독한 주 연결 100개와 구독을 바꾼 재접속 10개**를 검사했습니다. 최대 동시 연결은 100개, steady 구간은 60.001초였고 모든 연결이 HTTP 200·정상 종료했으며 오류·끊김 프레임·자동 재시도는 0입니다. 100명 steady 허브→클라이언트 p95 보고값은 1,252.5ms, 시계 오차를 더한 상한은 **1,623ms**입니다.

지원 조합 241개 중 신선한 실제 체결을 관측한 것은 **231개**, 새 틱을 관측한 것은 202개입니다. 보고된 고유 새 체결은 3,086개이며, 지연 표본은 같은 체결이 여러 클라이언트에 반복될 수 있습니다. 신선한 체결을 관측하지 못한 10개는 Binance YFI, Upbit COMP·COW·GRT·ICP·JST·MORPHO·SPX·WIF·XAUT입니다. 이 짧은 시험만으로 미거래와 수집 장애를 구분하지 않습니다.

브라우저와 자원 원시 표본의 p95를 nearest-rank 방식으로 다시 계산했습니다. SSE는 종료 시 지연 배열을 저장하지 않아, 러너의 같은 공식·시장별 개수 합계·시계 오차 합산을 대조했습니다. 46,110개 SSE 지연을 원본에서 독립 재계산한 것으로 표현하지 않습니다. SSE 연결별 핸드셰이크 p95는 다시 계산했습니다.

최초 성능 시도는 Pages `/index.html`의 `/` 이동(HTTP 308)을 임의 리다이렉트 차단 검사가 거부해 **유효 표본 0개·invalid**로 끝났습니다. 이 실패를 보존하고 알려진 index만 정규 첫 주소 `/`로 읽도록 검사 보조도구 한 줄을 바꾼 뒤 새 출력에 측정했습니다. 크기·해시·런타임·리다이렉트 차단·20회 조건은 유지했고 제품은 수정하지 않았습니다.

직접 공급자 수집·DB 쓰기·서버 변경·개인 프로필·fixture는 시험에 사용하지 않았습니다. 기존 수집기의 자연 갱신, 전체 과거 이력, 실제 Safari·VoiceOver, 사람 대상 사용성은 별도 검증입니다. 48시간 대기는 추가하지 않습니다. 원시 헤더·내부 경로·PID·개인 자료를 제외한 식별자와 증거 해시는 [performance-patch.json](performance-patch.json)에 기록했습니다.
