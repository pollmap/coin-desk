## 변경과 확인 범위

가격·슈퍼트렌드·이동평균 리본·볼린저밴드의 새 진입을 전체 기간으로 정리하고, 시장·검색의 가격 링크도 전체를 사용하게 했습니다. 명시 URL·기존 저장·동일 지표 재진입의 기간과 확대 구간은 보존합니다. 차트의 가격축 정밀도, 실제 관측 위치와 툴팁, 터치·키보드, 보조 패널과 작은 화면 가림을 검사합니다.

조회에서는 작은 보관 청크를 고정 개수만 읽고 종료하던 결함과, 이력 상태가 없는 DB에서 최근 테이블만으로 최초일 메타데이터를 구하던 불일치를 격리 SQLite로 재현해 수정했습니다. 전체 가격은 계산 준비기간 이전에도 유지하고, 실제 OHLC와 USD 종가를 섞지 않습니다.

실제 체결 300초, 시간봉 90일, 슈퍼트렌드와 위치 밴드의 계산 준비 조건, 8GiB 과거 이력 보호는 유지합니다. 원천·공식·수집 시각을 공개 차트에 다시 노출하거나 공유·내보내기·날짜별 표를 추가하지 않습니다.

## 원격 검사와 추가 결함

PR #68의 최종 CI `38531878255`는 타입·단위 809개, 서버 31+32개, 복구 2개, Chromium 211개·WebKit 210개를 재시도 없이 통과했습니다. 개인 경로 2개와 WebKit native 다중 터치 1개는 제외했습니다. 같은 소스의 최종 로컬 전체 검사는 424개 중 421개 통과·3개 제외였습니다.

병합 뒤 main CI `38533804014`는 실패했습니다. Chromium 320·390px에서 지표 선택창 닫기 버튼의 테마 전환 중 대비가 1.48:1로 낮아졌습니다. WebKit 210개, 타입·단위·서버·복구·컨테이너는 통과했지만 이 main과 그 컨테이너 산출물은 배포하지 않습니다.

실제 프레임을 측정해 밝음→어두움 약 51ms에서 전경 `rgb(150,154,163)`, 배경 `rgb(123,124,128)`의 대비 1.47865:1을 재현했습니다. 두 테마의 최종 색은 충분한 대비를 갖지만 글자색과 배경색의 동시 보간 중에만 대비가 무너졌습니다. 버튼의 테두리 전환만 남기고 글자색·배경색의 보간을 제거했습니다. 검사 대기나 대비 합격선 변경으로 처리하지 않았습니다.

수정 후 Chromium·WebKit의 320·390·1280px에서 양방향 전환의 모든 프레임, 위치·크기 불변, axe, Escape와 초점 복귀 6개가 재시도 없이 통과했습니다. 별도 일반·hover·focus 18조건의 최소 문자 대비는 12.60:1이었습니다. 이 추가 수정의 PR·main 전체 검사는 별도로 확인합니다.

추가 수정 PR #69 CI `38536256064`는 5개 작업 모두 성공했고, 브라우저 421개 통과·3개 제외·실패 및 재시도 0을 확인했습니다. 그러나 병합 뒤 두 번째 main CI `38547791450`는 WebKit의 설명→사전 복귀 1개가 실패했습니다. Chromium 211개, WebKit 209개와 타입·단위·서버·복구·컨테이너는 통과했지만 이 main 산출물도 배포하지 않았습니다.

원격 trace와 실제 WebKit pointer 입력으로 원인을 재현했습니다. ‘주의할 점’에 pointerdown한 뒤 예시의 지연 로딩이 끝나면서 해당 summary가 52.39px 아래로 이동했습니다. 같은 클릭점의 pointerup은 ‘계산식·기호’에 전달됐고 실제 click은 공통 DIV에서 끝나 두 details가 접힌 채 남았습니다. 검사 대상의 링크가 단순히 느리게 나타난 것이 아니라 사용자의 클릭 대상이 움직이는 제품 결함입니다. 예시·두 펼침 영역·상세 설명 링크를 하나의 준비 경계로 묶어 수정하고, 클릭 중 로딩·키보드·복귀 검사를 별도로 수행합니다.

단일 준비 경계만으로는 충분하지 않았습니다. 같은 지연 로딩 중 닫기 버튼에서 native pointerdown한 뒤 내용을 표시하면 버튼이 71.59px 위로 이동했고 pointerup은 본문에서 끝나 창이 닫히지 않았습니다. 설명창에만 안정적인 읽기 영역과 내부 스크롤을 적용하며, 일반 지표 선택창·저장창의 크기와 동작은 유지합니다. 클릭을 강제로 재실행하거나 임의의 계산 높이·긴 대기 시간으로 덮지 않습니다.

설명창 수정 후 지연 모듈과 native 클릭을 겹치는 검사, 원래 학습 흐름·드로잉/설명 연결 6개가 양 엔진에서 재시도 없이 통과했습니다. 320×568·390×844·1280×720에서 닫기 pointerdown→모듈 준비→pointerup이 같은 버튼으로 전달됐고 위치·크기·차트 범위·canvas가 유지됐습니다. 모바일 touch 닫기, Escape·초점 복귀, 키보드 펼침과 ETH·Upbit 사전 복귀도 확인했습니다. 이 수정의 전체 PR·main 검사는 별도로 수행합니다.
