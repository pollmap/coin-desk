# 0.25 — 코인 탐색과 150개 종목

모바일·태블릿·PC 첫 화면을 시장으로 통일했습니다. 검색 → 코인 → 지표 → 날짜 확인 → 저장의 흐름을 유지하면서 수집 정보와 공식은 눌러서 확인하도록 옮겼습니다.

## 화면

- 시장은 전체·관심·테마 탭, 한글·영문·티커·별칭 검색을 제공합니다. `펭귄`은 PENGU로 연결됩니다.
- 첫 목록은 모바일 20개, PC 50개이며 더 보기로 확장합니다. 모바일은 가격·24시간 변동만 표시하고, 거래대금은 태블릿부터, 작은 차트는 PC부터 제공합니다.
- 거래소·검색·탭·정렬은 URL과 기기 설정에, 펼친 행 수와 스크롤은 기기에 보존합니다. 시세 갱신으로 행을 재정렬하지 않습니다.
- 선택 거래소에 없는 종목은 검색 결과에 실제 지원 거래소를 표시합니다. 상세 진입 시 해당 거래소를 명시적으로 선택합니다.
- 코인 상세는 값·기준일·기간·날짜를 우선합니다. 설명·데이터 정보는 모바일 시트/PC 대화상자로 엽니다. 정상 수집 문구·항상 열린 기술 정보·중복 설명을 제거했습니다.
- 가격 비교·전체화면·주석·패턴은 더보기, 저장은 바로가기입니다. 창 크기와 설명 패널 변화로 날짜·확대 구간을 초기화하지 않습니다.

## 자산과 원천

동결 명부는 [자산 레지스트리](../shared/asset-registry.json)입니다. 기존 8개와 PENGU를 포함한 업비트 우선 100개, 중복을 제외한 바이낸스 50개를 선정했습니다. 추가 50개 중 업비트에도 있는 3개가 있어 실제 지원은 Upbit KRW 103개·Binance USDT 138개, 총 241개 거래소 조합입니다. 순위 변화로 자동 편입·퇴출하지 않습니다.

| 데이터 | 실제 확인 범위 | 조건 |
|---|---:|---|
| 거래소 가격·기술 분석 | 150개, 241개 거래소 조합 | 제공자 일봉 전체·시간봉 90일, 확정 OHLC |
| USD 참조가격 | 143개 | Coin Metrics 일별 종가, 거래소 OHLC 아님 |
| 온체인 | 34개 | 실제 응답이 있는 자산·필드 조합 |
| MVRV | 33개 | 원천별 측정 대상과 공급 정의를 함께 제공 |
| 선물 | 136개 | 실제 Bybit USDT 무기한 계약, 다섯 지표별 최근 이력 |
| 테마·관계 | 검토한 13개 코인 | 미검토 프로젝트 관계를 추측해 채우지 않음 |

SHIB의 Coin Metrics ID는 `shib_eth`, Bybit 계약은 `SHIB1000USDT`입니다. PEPE의 `1000PEPEUSDT`와 마찬가지로 계약 수량을 실제 코인 수량으로 변환합니다. BEAM은 동명 자산 혼동을 피하기 위해 Coin Metrics 연결을 활성화하지 않았습니다. GTC·FRAX 등 식별이 일치하지 않는 후보는 제외했습니다.

초기 원문 대조: 확정 가격 봉 891,501개, 온체인 일별 행 113,990개, 참조가격 296,178개, 선물 관측 19,040개입니다. 원천 조회 시점과 세부 범위는 [검수 기록](audit-25/README.md)을 따릅니다. 숫자는 전체 체인 데이터나 현재까지의 실시간 완전성을 뜻하지 않습니다.

### 의도적인 제한

- 모든 코인에 MVRV가 있는 것은 아닙니다. 검증된 MVRV가 없으면 RSI 14로 시작합니다. 직접 입력한 미지원 링크에는 이유와 대안을 제공합니다.
- KAIA Upbit 일봉은 최초 수집 시 진행 중인 봉 하나뿐이었습니다. 이를 확정 이력으로 세지 않으며 RSI는 이력 부족으로 표시합니다. Binance의 별도 이력은 사용자가 원천을 선택해 볼 수 있습니다.
- DASH·DCR의 과거 수수료 원천값에 음수가 있어 해당 필드만 비활성화했습니다. 원본과 다른 지원 필드는 보존했습니다.
- 계약 주소가 확인되지 않은 자산은 주소를 생성하지 않습니다. 검토된 거래소 심볼·제공자 ID·네트워크 측정 범위로 연결하며 전 종목 계약 주소 검토 완료를 주장하지 않습니다.
- 기본 도미넌스의 기존 8개 범위는 유지합니다. 거래소 가격 지원과 도미넌스 지원은 다릅니다.
- Coin Metrics Community는 비상업 이용 조건을 유지합니다. 유료 지표·전체 노드·지갑 추적을 추가하지 않습니다.

## 실행 구조

React·Lightweight Charts → Pages/VPS 웹 → Node 읽기 API → SQLite를 유지합니다. 거래소 중앙 스트림과 분 단위 시세 확인은 별도 프로세스입니다.

- `GET /api/v1/assets`: 검색·원천·지원 지표·테마·페이지.
- `GET /api/v1/market`: 검색·원천·페이지·선택 자산·작은 차트 묶음 조회. 시장 첫 진입에 상세 API 150개를 호출하지 않습니다.
- `GET /api/v1/quotes/stream?market=…&assets=…`: 보이는 종목·관심 종목에 한정한 변경분. `assets` 없는 기존 전체 스냅샷 방식도 유지합니다.
- 수집기는 최신 구간 확인과 과거 체크포인트를 분리합니다. 시간 예산을 넘긴 시세 묶음은 다음 묶음부터 이어가며, 배경 작업은 실행 예정 시각 순으로 처리합니다.
- 실제 체결 300초 신선도와 원천 관측 주기를 유지합니다. 연결 상태만으로 신선한 가격이라고 표시하지 않습니다.
- DB 스키마·주소·개인 저장 키·작업공간 버전·자료함·백업 형식은 유지합니다. 새 자료 이관은 확인된 백업을 요구하고 기존 파티션을 덮어쓰지 않습니다.
