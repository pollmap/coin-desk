# VPS 이전 검증

찬희님의 2026-10-02 요청은 남은 지표 화면 개편에 더해 백엔드·데이터·서버를 자체 VPS로 이전하는 것입니다. 이전의 Cloudflare 구조 유지 제한보다 최신 요청을 우선하며, 기존 자료와 계산·API를 보존합니다. [구조와 실행 절차](../../DEPLOYMENT.md)

## 구현

- Node 24 실행부: 기존 Worker API와 수집을 빌드해 직접 사용합니다. 신규 백엔드 프레임워크나 DB 라이브러리를 설치하지 않았습니다.
- SQLite WAL: 실제 읽기 전용 API 연결, 원자적 batch, 잠금 대기, 체크섬 원장, import 검증 전 기존 DB 마이그레이션 거부.
- 시세·배경·최근 선물·분산 분석의 독립 매분 실행. 중복·오류·겹침·건강 상태를 기록하며 기존 수집 정책·데이터 기준은 유지합니다.
- 운영 export의 격리 이관과 전체 테이블 복원 대조. 신호·정정 이력·브리핑·ETH 체인 이력과 추가 사용자 테이블도 보존합니다.
- 온라인 백업·복원 검증·예산/보존·실패 상태, 프로젝트별 Docker·Nginx·HTTPS·승격·코드 롤백 도구.
- 기존 Pages 주소를 유지하는 선택적 읽기 전용 API 연결부. 개인 헤더와 쿠키를 전달하지 않습니다.

## 이번 실행에서 확인한 외부 한계

- SSH alias를 사용할 수 없었으며 제공된 키·주소로 연결했을 때 22번 포트 소켓 연결이 `Permission denied`로 실패했습니다. 키가 거부됐다는 증거가 아닙니다.
- 네트워크 권한 요청은 허용 프로필을 반환하지 않았습니다. 제한을 우회하지 않았습니다.
- 로컬 Docker 실행 파일이 없습니다. YAML 파싱과 소스 검사만으로 실제 Compose·이미지 실행 통과라고 기록하지 않습니다.
- VPS 자원·기존 서비스·포트·DNS·인증서, 운영 D1 export 이관, 원천 서버 접근성, 운영 승격은 아직 확인하지 않았습니다. 기존 서비스·Cron·DB를 변경하지 않았습니다.
- 0.20 원격 push·PR·CI·main 병합도 기존 쓰기/네트워크 제약으로 대기 상태입니다. 로컬 검사 통과는 원격 CI 통과가 아닙니다.

이번 실행의 확정 검사 수와 리허설은 [verification.json](verification.json)에 기록합니다. 타입·단위 479개, 새 실행부와 원천 접근 검사 5개, 이관·백업·shadow 구분 6개, 기존 복구 2개, 독립 Decimal 3개를 통과했습니다. Chromium/WebKit 지표 회귀 54개는 재시도 없이 통과했고 새 실행 방식에서 정상 종료했습니다. 가격축 수정 뒤 12개 집중 검사도 재시도 없이 통과했습니다. 전체 112개 브라우저 검사의 앞선 결과와 최신 집중 검사를 구분합니다. Docker 빌드·격리 컨테이너 smoke도 CI에 추가했지만 이 변경의 원격 CI를 실행하지는 못했습니다.

읽기 전용 로컬 캐시 **18개 테이블·122,102행**을 격리 export→이관→온라인 백업→복원해 전체 스키마·내용을 대조했습니다. 최초 시도에서 Windows CR/LF 스키마 직렬화 차이를 발견했으며 행 해시는 일치했습니다. 줄바꿈을 그대로 보존하도록 고치고 회귀·리허설을 다시 통과했습니다. 운영 D1 export를 확보한 것은 아닙니다.

새 Node 서버로 로컬 읽기 API [29개 표본](local-api.json)을 확인했습니다. 28개는 200, health는 수집을 켜지 않은 오래된 캐시이므로 **503을 그대로 유지**합니다. shadow 검사에서 이 상태를 기록하며, 실제 활성화 검사에서는 health 200을 요구합니다. 자연 수집이나 최신 운영 데이터의 증거가 아닙니다.

실제 브라우저에서 MVRV·ONDO RSI/Binance 전환·자체 BTC 레인보우가 표시됐고, 캐시 지연을 확인했습니다. 로딩 중 이력 0개/부족을 단정하던 문구와 레인보우 경계선의 가격축 라벨 10개가 겹치는 문제를 수정했습니다. 경계선 수치와 내보내기 자료는 보존했습니다. [수정 후 화면](native-rainbow.jpg)은 로컬 캐시이며 운영 화면이 아닙니다. 첫 브라우저 본문 54개 통과 후 Windows 종료가 멈췄고 알려진 fixture만 정지했습니다. 직접 프로세스 관리·IPC 정리로 바꾼 이후 같은 검사 54개가 정상 종료했습니다. 관련 없는 Node 프로세스를 정리하지 않았습니다.

stage에 8개 원천의 공개 응답 접근 검사를 추가했습니다. DB를 열거나 예약 체크포인트를 변경하지 않으며, 접근/시세 검증 실패는 전환 전에 실패로 남깁니다. 실패 응답의 본문·요청 헤더는 증거에 넣지 않습니다. 격리 fixture 검사는 통과했으나 실제 VPS에서 실행하지 못했으므로 원천 103개 정상이나 실제 수집 완료 증거가 아닙니다.

X 개인 자료와 기존 사용자 변경을 보존했습니다. 실제 Apple 기기 검증은 대기입니다. **전체 계획·배포·운영 마감 완료를 선언하지 않습니다.**
