## 문제와 변경

온체인·선물 탭을 눌러도 큰 가격 차트가 먼저 나왔고 선택 지표는 아래에 표시됐습니다. 각 탭의 지표를 주 차트로 바꾸고 지표 선택 바로 아래에서 교체하도록 수정했습니다. 가격 비교는 선택형 보조 pane입니다. 주 지표를 선택하는 목록은 현재 표시하는 한 항목만 선택 상태로 표시합니다.

가격용 봉 간격·시각화·로그축·이동평균 설정은 가격·기술 탭에 한정합니다. 조회 기간, 지표 검색, 전체화면, 근거는 해당 차트 바로 위에 있습니다. 지표의 단위·출처와 결측 상태를 유지하며 데이터를 못 받아도 가격으로 대신 표시하지 않습니다. 펀딩의 음수도 선형 축에 표시합니다.
