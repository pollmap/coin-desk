# 0.15.5 시장 표와 분석 탐색 개선

2026-09-27. 찬희님의 최신 방향은 CoinGlass에 가까운 정보 밀도와 즉시 분석 흐름입니다. 기존 Coin Desk 브랜드, BTC 우선·DOGE·ETH 중심, 전체 기간 기본값을 유지합니다.

캡처는 공개 사이트의 데스크톱 화면을 직접 열어 저장하고 검사했습니다. CoinGlass의 일부 비동기 표는 초기 로딩 상태였으며, 로그인·유료 영역 전체를 검증했다고 주장하지 않습니다. 청산 히트맵·전체 거래소 합계는 확보되지 않았으므로 추가하지 않습니다. 우리 선물 표는 **Bybit 단일 거래소**이며 미결제약정을 USD로 잘못 표시하지 않습니다.

## 참고한 공개 원칙

- [CoinGlass](https://www.coinglass.com/): 수급 수치 중심 표, 관심 목록, 분류, 값에서 세부 분석으로 이동.
- [CryptoQuant](https://cryptoquant.com/asset/btc/summary): 자산과 지표 선택, 검색, 관심 지표 분리. 우리 지표 분류는 제공자 이름보다 분석 질문을 먼저 둡니다.
- [TradingView](https://www.tradingview.com/features/): 차트 가까운 조작과 직접 탐색. 선택한 지표가 바로 주 차트가 되고 URL로 복원됩니다.
- [LazyAlpha 공개 설명](https://www.lazyalpha.io/how.html): 확정 봉 조건과 선택형 설명. 기존 관찰 신호의 확정 봉 규칙을 유지하며 독점 산식·투자 성과·주식 실적 점수는 복제하지 않습니다.

## 데이터·성능

`GET /api/v1/market-derivatives`는 활성 자산별 최신 관측을 기본키로 조회하는 읽기 전용 API입니다. 각 값은 고유한 관측 시각·최근 확인 시각·지연 상태를 보존합니다. 미래 관측을 제외하고 누락은 null, 원천 오류는 지연으로 표시합니다. 5분 캐시와 갱신을 사용하고 방문 요청으로 외부 수집이나 DB 쓰기를 실행하지 않습니다.

온체인·선물 단일 주 차트에서는 현재 표시할 지표만 요청합니다. 가격 비교는 사용자가 켰을 때만 읽습니다. 시장 표 수급 값에서는 시간별 미결제약정/롱 계정 차트로 이동하며 기존 일별 이력도 별도 선택할 수 있습니다.

로컬 D1 어댑터는 SELECT 배치 결과를 버리고 있어 실제 D1과 다른 값을 반환했습니다. 결과 컬럼을 검사해 읽기 배치 결과를 반환하도록 고쳤고 원자적 쓰기 배치를 유지합니다.

## 수집 경로 수정

0.15.4 분리 후 7분간 28개 실행이 CPU 중단 없이 완료됐으나 Binance 시세와 일부 배경 선물은 HTTP 502였습니다. 원격 SELECT로 Binance 시세 정체와 Upbit 증가를 구분했습니다. [Cloudflare의 위치 제약](https://developers.cloudflare.com/workers/configuration/placement/)에 따르면 named entrypoint에는 위치 설정이 적용되지 않습니다. `InternalFeed`에서 같은 Worker의 기본 HTTP handler를 Service binding으로 호출하도록 수정하여 서울 위치 설정을 적용합니다. 공개 token 검사는 유지하고 인증값을 새 Worker로 복사하지 않습니다. 실제 복구 여부는 배포 후 자연 Cron과 읽기 전용 조회로 판정합니다.

## 검증과 완료 구분

타입·단위 검사, 실제 읽기 API의 자산/단위/미래/결측/오류/무쓰기 검사, Chromium·WebKit의 시장 표→지표 차트·통화 유지·분류·검색 회귀를 추가했습니다. 기존 좁은 화면·두 테마 axe·키보드·공유 검사도 유지합니다. 결과와 배포 식별자는 검증 후 추가합니다. 실제 Apple 기기 Safari·VoiceOver는 별도 미검증입니다. 전체 UTC 하루 비용과 다음 날 브리핑은 관찰 완료 전까지 운영 마감으로 처리하지 않습니다.

## 0.15.6 표시 보완

운영 검수에서 시간별 미결제약정은 빠른 선택 버튼의 일별 ID와 일치하지 않아 선택 표시가 빠졌습니다. 시간별·일별 모두 현재 지표를 표시하고, 같은 버튼을 다시 눌러도 선택한 일별 이력을 유지합니다. 롱/숏 계정 비중은 함께 반올림해 표시 합계가 100%가 되도록 보완합니다. 원천 관측과 차트 값은 바꾸지 않습니다. 해당 선택 흐름 회귀와 57.35%·경곗값·잘못된 비중 검사를 추가했습니다.
