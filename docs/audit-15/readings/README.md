# 차트 수치 탐색 개선 · 2026-09-26

목표: 코인을 고르고 같은 시점의 가격과 지표를 읽는 흐름을 줄입니다. 공개 리서치·역사 화면은 제외 상태를 유지합니다.

## 발견과 수정

| 기존 문제 | 적용한 변경 |
|---|---|
| 커서 범례에 지표 값이 없음 | 가격·지표를 정확한 동일 UTC 시각으로 표시 |
| 펀딩 시각에 일별 가격이 없으면 최신 가격으로 대체 | 미관측은 —, 보간·과거값 복사 없음 |
| 방향키는 글자만 바꾸고 차트 커서는 고정 | 실제 차트 커서 이동, Home/End/Escape, 날짜 입력과 이전/다음 |
| 확대 후 같은 기간 버튼을 다시 눌러도 복원 안 됨 | 같은 기간 재선택 시 범위·커서 복원 |
| CSV에는 가격만, 표는 가격 날짜만 포함 | 모든 선택 지표의 관측 시각 합집합, 단위·원천 포함 CSV |
| 지표를 여러 번 찾아 추가 | 장기 추세·온체인 평가·선물 수급·DOGE/ETH의 BTC 비교 묶음 |
| 미선택 RSI·상대강도 목록에 현재값이 없음 | 이미 계산한 실제 값과 추세 미리보기 재사용 |
| 아래쪽 최신 숫자가 과거 날짜 범례와 충돌 | 아래쪽은 근거 열기로 정리 |
| 기본 화면에도 가격 위치 밴드 코드 로드 | 밴드 선택 시 지연 로드 |

## 공식 참고와 확보 범위

- [TradingView 지표 수치·커서 안내](https://www.tradingview.com/support/solutions/43000502564-i-can-t-see-ohlc-indicator-values-and-the-crosshair-cursor/): 모바일에서도 시점별 지표 값을 탐색하는 원칙을 참고했습니다. Coin Desk에는 날짜 입력·버튼·키보드 경로를 함께 제공합니다.
- [CoinGlass Coins Markets](https://docs.coinglass.com/reference/coins-markets): 펀딩 가중 기준과 OI 금액/수량을 구분합니다. Coin Desk는 확보한 Bybit 정산 펀딩과 코인 수량 단위를 명시하며 전체 거래소 집계로 표시하지 않습니다. 청산 히트맵 데이터 확보는 대기입니다.
- [LazyAlpha 공개 작동 방식](https://www.lazyalpha.io/how.html): 확정 봉 조건, 선택형 근거 설명, 브리핑 연결을 참고했습니다. 자체 공개 산식을 유지하며 PEG·SEPA와 비공개 신호 산식은 복제하지 않습니다. 이번 변경은 근거를 필요할 때 여는 흐름에 집중했습니다.
- [CryptoQuant BTC 공개 요약](https://cryptoquant.com/asset/btc/summary), [업비트 BTC](https://upbit.com/exchange?code=CRIX.UPBIT.KRW-BTC): 공개 진입 페이지를 재확인했습니다. 문서 수집만으로 유료/로그인 화면 전체 UX를 검증했다고 판단하지 않습니다.
- [lazyalphaio X](https://x.com/lazyalphaio)는 웹 접근 오류로 전체 게시물을 확보하지 못했습니다. 검색에서도 신뢰할 만한 해당 계정 원문을 확보하지 못했으며, 공식 사이트의 공개 설명만 사용했습니다. 공개 게시물 아카이브 기능을 제품에 재도입하지 않았습니다.
