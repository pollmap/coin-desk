# 0.15.1 최종 사용 흐름·운영 점검

2026-09-26 KST. BTC·DOGE·ETH를 우선하며 기존 데이터와 보조 코인 지원을 보존합니다. 모든 경쟁 서비스의 유료 기능을 구현했다는 의미는 아닙니다.

## 실제 발견한 문제와 수정

- Upbit 코인 이름을 누르면 USD 기본값으로 바뀌던 링크를 수정했습니다. 이름과 차트 버튼 모두 자산·시장·통화·전체 기간을 명시합니다. 검색 결과도 현재 가격 기준을 유지합니다.
- 성과 비교 링크에 선택 자산과 기간을 명시합니다. 코인 목록에서는 전체 기간으로 열어 과거 저장 날짜가 끼어들지 않습니다. USD 참조 화면의 비교는 지원 범위에 맞춰 ‘거래소 비교’로 표시하며 Binance USDT를 명시합니다.
- 한 코인의 이미지 오류가 다른 코인 전환 후에도 남던 fallback 상태를 자산별로 분리했습니다. 8개 로컬 코인 PNG의 고유 경로·실제 크기·브라우저 로딩을 확인했습니다. 브랜드 마크와 코인 표식은 별도입니다.
- 시세 목록은 전체 8개 요청이 끝날 때까지 기다리지 않고 응답별로 표시합니다. 동시 요청은 두 개이며, 실패 시 기존 값을 보존하고 오류를 표시합니다. 시장 변경 시 이전 요청은 취소합니다.
- RSI·200일선에 확정 일봉 기준일을 추가했습니다. 새 일봉이 들어오면 한 시간 캐시가 남았어도 다시 계산합니다. 미완성 봉과 결측일을 건너뛴 계산은 사용하지 않습니다.
- 시장·비교의 이동 버튼, 44px 차트 링크, 가격 숫자 정렬, 좁은 화면 목록 배치를 정리했습니다. 시장 변경은 브라우저 탐색 이력에 남깁니다.
- 정상 상태의 반복 설명은 근거 패널로 옮겼습니다. 지연·오류·실제 과거 수집 상태는 계속 표시합니다.

## 자동 수집 용량

최근 선물 전용 경로와 배경 큐의 중복 확인이 복구 대기 시간을 늘릴 수 있었습니다. 핵심 코인의 현재가 60초·최근 선물 5분 전용 경로는 유지합니다. 배경 선물 과거 확인은 시간당으로 분리하고, 보조 코인의 일별 가격·참조·온체인·선물 확인은 6시간으로 조정합니다. 보조 코인 시간봉은 1시간입니다. 원천 관측 지연 허용값을 늘린 것은 아닙니다. 재시도·과거 수집 next_attempt와 커서는 계속 우선합니다.

정상 배경 작업 수요가 시간당 50개 미만인지, 전체 작업이 지연된 테스트 상황에서도 120회 처리 안에 모두 선택되는지 검증했습니다. 원천 실패나 장기 재수집을 포함한 실제 처리 시간을 보장하는 수치는 아닙니다. 하루 10,000개 선물 과거 후보 예약 제한은 유지하며 계정 전체 D1 쓰기 보장은 별도 관찰이 필요합니다.
