# 발견 사항과 처리 결과

| 구분 | 발견 | 처리·검증 |
|---|---|---|
| 수집 공정성 | 정상 주요 코인 우선 정책에서 기한이 지난 실패/보조 원천이 밀릴 수 있음 | VPS에 오래 기다린 기한 우선 적용. 모든 원천이 계속 과거 이력을 처리하는 재현에서 N+2분 내 모든 작업 선택, backoff 유지 |
| 최신 봉과 과거 결측 | 과거 페이지를 채우는 동안 최신 봉도 늦어질 수 있는 경로 | 최신 응답 먼저 저장, 과거 복구 커서 별도 유지. 과거 실패와 새 관측 성공을 분리해 테스트 |
| ETH 실제 회복 | 배포 전 Coin Metrics 저장 관측이 10월 7일로 갱신됨 | 이번 수정의 회복 성과로 주장하지 않음. 원천과 별도 대조 |
| 오류 진단 | SQLite가 rollback을 이미 끝내면 추가 rollback이 최초 오류를 덮어씀 | 실제 SQLite trigger의 자동 rollback, 원자성, 다음 트랜잭션 복구 검증 |
| 백업 | 초기 파일 작성·임시 폴더 생성 오류가 진단 경로 밖에 있었음 | 상태 원자 교체·안전한 오류 코드. 기존 스냅샷 보존, 공간 부족 fixture, 온라인 WAL 백업 복원 검사 |
| 날짜 범위 | 사용자 범위가 LWC에 적용되기 전 React 업데이트가 이전 범위를 다시 적용 | 요청 범위가 차트에 반영될 때까지 유지. 밴드·레인보우·MVRV·가격 저장/공유 회귀 |
| 모바일·접근성 | 제목 줄바꿈, 작은 이어보기 링크, 지도 출처 링크 대비 | 제목 위계·버튼 묶음·터치 크기·지도 출처 색상 수정. 320~1920px·axe 검사 |
| 관계 선택 | React Flow의 선택 통지가 목록에서 고른 노드를 이전 선택으로 되돌림 | 사용자 선택 변경만 반영. 목록·지도·근거·차트 이동 검사 |
| 지표 변경 | 닫히는 선택창과 라우터 전환 사이에 이전 지표 도움말이 남는 경합 | 라우터의 실제 전환이 끝난 뒤 선택창을 닫도록 수정. 관련 도움말 회귀 |
| Windows 검증 도구 | 감사 JSON 저장 중 Vite 문서 watch가 EBUSY로 종료 | 문서·배포 산출물은 watch에서 제외, fixture 종료 시 후속 실패 검사를 중단 |
| 개발 검사 실패 | 초기 선택자·레이아웃·초점·타입·지도 대비 검사 실패 | 로컬 실패 trace는 work/browser-checks에 보존. 최종 검사와 구분 |
| 데이터 제한 | SOL·ONDO·PEPE MVRV 미확보, 펀딩 주기 가변, 일부 이력 결측 | 지원 불가/빈 간격을 그대로 기록. 다른 자산/원천으로 대체하지 않음 |
| 설명 범위 | 프로젝트 분류는 편집 분류이며 투자 위험 종합평가가 아님 | 원문·확인일·관계 의미 명시. ONDO 상품·토큰 분리 |
| 외부 미검증 | Apple 기기 없음, 첫 사용자 5명 미모집 | Safari·VoiceOver·사람 성공률은 미검증 |

운영 snapshot의 HTTP 성공과 실제 관측 갱신을 구분합니다. 배포 후 자연 수집과 현재 지연은 별도 증거로 추가합니다. 최초 ETH 저장 오류나 과거 서버 공간 부족의 원인을 증거 없이 확정하지 않습니다.

로컬 전체 검사 161개 통과·3개 실패·개인 경로 2개 제외 후, 실패한 지표 전환과 WebKit 체크박스 크기를 수정했습니다. 지표 전환 10회, 양 테마 reflow 12개, 관계 지도 12개 후속 검사는 재시도 없이 통과했습니다. 최종 전체 검사는 원격 CI로 별도 기록합니다.

개발 도구 의존성의 source-map-js, miniflare 하위 sharp·undici를 호환 패치 버전으로 고정해 npm audit 전체 취약점 0을 확인했습니다. Wrangler 주 버전과 운영 런타임 구성은 변경하지 않았습니다.

지원 대조표 검수 중 Bybit 시간별 OI·계정 비중의 감사 간격이 5분으로 잘못 지정된 것을 발견했습니다. 실제 수집의 1시간 주기와 일치시켜 결측을 재집계했습니다. 서비스의 수집·계산 간격 변경은 아닙니다.

원격 CI 37806799822는 단위 512개와 서버·복구·빌드를 통과했으나 WebKit 768px 상대강도 차트가 y=242.25px로 240px 기준을 넘었습니다(브라우저 167 통과·1 실패·2 제외). 범례 숫자 크기를 정리하고 상대강도의 날짜 도구도 상단으로 통합했습니다. 모바일 도구 두 줄과 기간 선택 높이를 정리한 뒤 해당 흐름 Chromium/WebKit 모두 통과했습니다. 판정 기준과 재시도 0은 유지했습니다.

원격 CI 37810096213에서도 167 통과·1 실패·2 제외였으며, WebKit 320px의 상대강도 범례가 두 줄이 되어 y=305px가 됐습니다. 이미 제목·원천에 있는 코인 쌍 이름을 짧은 범례에서 반복하지 않도록 줄였습니다. 축·내보내기·접근성 설명의 전체 대상은 보존합니다.

CI 37811723342는 같은 WebKit 320px에서 305px를 기록했습니다(167 통과·1 실패·2 제외). 실패 스크린샷을 직접 대조한 결과, 추가 높이는 상관 문구가 아니라 큰 숫자와 동일 크기로 표시한 ‘100 기준’ 단위의 줄바꿈에서 발생했습니다. 숫자와 단위의 위계를 분리하고 좁은 화면에서 긴 비율 단위도 안전하게 감싸도록 수정했습니다. 앞선 범례 축약만으로 이 문제를 해결했다고 표현하지 않습니다.

실제 Chrome 관계 검수에서 프로젝트·네트워크 노드의 설명이 토큰 설명을 반복하는 것을 확인했습니다. ONDO 토큰과 Ondo DAO, 각 네트워크의 설명을 대상을 주어로 각각 분리했습니다. 관계의 출처와 원문 근거는 유지합니다.

최종 PR CI 37814862992는 단위 512개·브라우저 168개(재시도 0, 개인 경로 2개 제외)와 서버·복구·컨테이너 검사를 통과했습니다. 37813362004도 브라우저 168개를 통과했지만 마지막 문구 수정 커밋으로 후속 빌드 도중 취소됐으므로 전체 성공으로 집계하지 않습니다.

운영 파일 대조에서 확장 ZIP의 create_system 값(Windows 0, Linux 3)만 다른 것을 확인했습니다. 내용·CRC 9개는 같았으며 하나의 검증된 VPS ZIP으로 Pages를 맞췄습니다. VPS 정적 파일 한 건의 40초 응답 시간 초과는 재요청으로 동일 SHA-256을 확인했으며 최초 오류도 기록에 보존합니다. 일반적인 전 지역 지연 개선 완료로 확대 해석하지 않습니다.
