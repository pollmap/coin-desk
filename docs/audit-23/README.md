## 구현과 확인할 흐름

시장에 전체·관심·테마를 두고 5개 편집 분류에서 해당 코인의 실제 지표로 이동합니다. 지표는 사용 목적과 짧은 뜻으로 찾으며, 날짜 도구와 저장을 차트 위에 모았습니다. 마우스 임시 확인과 클릭·키보드 날짜 고정을 구분합니다. 관계는 기본 목록과 고정 배치 지도를 제공하며 원문 근거에서 실제 지표로 연결합니다.

수집은 기한이 지난 오래 대기한 원천부터 처리하고, 최신 봉과 과거 이력 복구를 분리합니다. 공급자 backoff와 실제 체결 시각 300초 기준을 유지합니다. SQLite 최초 오류와 백업 실패를 보존하며 결측을 채워 최신값처럼 표시하지 않습니다.

ETH 10월 7일 관측과 활성 원천 103/103 회복은 **새 코드 배포 전**에 이미 확인했습니다. 이번 수정이 최초 장애를 해결했다는 인과관계로 소급하지 않습니다. 공정성·최신/과거 작업 분리·트랜잭션·백업 결함은 재현 검사와 운영 갱신으로 검증했습니다. 최초 장애 전체 원인은 확정하지 않았습니다.

## 범위와 남은 외부 검증

48시간 대기는 완료 조건이 아닙니다. 기존 이력·과거 오류·원천 지연 판정은 지우거나 완화하지 않았습니다. 5분 자연 갱신은 짧은 표본이며 하루 전체나 다른 방문자 부재의 증거가 아닙니다.

SOL·ONDO·PEPE MVRV는 미지원입니다. 원천에 없는 과거 일봉과 보유 이력의 결측을 보존합니다. 모든 제공자의 원장으로 지표를 독립 재산출한 것은 아닙니다. 테마는 여덟 추적 코인의 분류로 시장 전체 순위가 아니며, 관계는 투자 판단·인과관계를 뜻하지 않습니다.

Apple 기기가 없어 실제 Safari·VoiceOver는 미검증입니다. 사람 5명의 사용성 과제는 모집 전이며 성공률을 만들지 않았습니다. 자동 검사와 에이전트가 조작한 실제 Chrome은 사람의 이해도 검사를 대체하지 않습니다. 개인 자료 전체의 내용 검토와 X 추가 수집은 이번 범위가 아닙니다.

## 배포와 복구

동일 소스의 읽기 전용 VPS 후보에서 API 29개와 실제 사용자 흐름을 확인한 뒤 main 병합본을 배포했습니다. API·quotes·background·recent·analysis·backup 6개만 교체했고 시세 허브는 기존 컨테이너를 유지했습니다. 원격 마이그레이션과 DB 복원을 수행하지 않았습니다.

이전 API 릴리스 `vps-9435cadabaa44937`, 이전 수집·백업 이미지 `vps-f1546991c2aab31a`, 당시 Compose 환경과 검증된 SQLite 백업을 보존합니다. 코드 복구는 이전 Compose 환경으로 여섯 서비스를 복원합니다. 현재 DB와 백업 파일을 덮어쓰는 데이터 복원은 별도 절차입니다. 이전 정적 자산을 보존해 열려 있던 화면의 파일 경로를 유지했습니다. 같은 VPS 백업은 외부 재해복구를 의미하지 않습니다.

배포 준비에서 Docker 프로필을 빠뜨린 도구 오류는 서비스 교체 전 중단됐습니다. 수집기 프로필을 포함한 설정 비교 후 재개했습니다. 후보 포트 검사와 Windows 줄바꿈 재개 명령 오류도 운영 변경 전에 확인·정정했습니다. 변경이 없는 서비스를 반복 배포하거나 이 오류를 제품 API 장애로 기록하지 않습니다.

첫 Pages 배포 `e2f8cf22` 이후 확장 ZIP의 OS 표시 메타데이터 차이를 발견했습니다. 내부 파일 9개와 CRC가 동일함을 확인하고 VPS의 동일 빌드 ZIP을 승격해 최종 Pages `25ddf5e9`에 맞췄습니다([대조](extension-packaging.json)). 확장 기능·권한·버전은 변경하지 않았습니다. 이후 증거 문서 커밋 때문에 서비스를 다시 배포하지 않습니다.
