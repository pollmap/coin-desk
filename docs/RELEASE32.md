# 0.32 — 가격·MVRV·슈퍼트렌드와 BTC 기준 비교

상세의 바로가기를 가격·MVRV·슈퍼트렌드로 정리합니다. 지원하지 않는 MVRV를 다른 자산 값으로 대체하지 않으며, 코인 전환 때 가격으로 이동합니다. 명시한 RSI·기타 공유 링크와 저장 분석은 유지합니다.

- 지표 선택은 검색·사용 목적·현재 코인의 지원 목록으로 구성합니다. PC는 중앙 대화상자, 모바일은 아래 시트입니다. 지표 전환은 주 차트를 바꾸며 관계·설명창을 자동으로 열지 않습니다.
- 최근 확정값, 임시 탐색값, 고정 날짜를 구분합니다. 날짜·확대 구간을 유지하며 BTC 기준 비교와 저장을 상세에서 바로 엽니다. BTC의 기본 상대는 ETH입니다.
- 읽는 법에 정의·설명용 도식·예시를 배치하고 공식·기호·출처·한계는 펼쳐 읽습니다. 사전의 반복적인 150개 티커는 접힌 목록으로 이동합니다.
- 헤더의 신호 메뉴를 제거하고 필요한 지표의 전환 표시와 날짜 목록으로 연결합니다. 정확한 신호 ID를 조회하며 수정·철회·다른 원천·찾을 수 없는 신호를 구분합니다.
- `view:asset_rainbow`는 고정한 자산·원천별 기준일과 이전 730개 유효 관측을 사용합니다. 전체 이력으로 누적 회귀하고 화면 기간만 자릅니다. 기존 BTC 제네시스 모형은 유지합니다.
- BTC 해시 리본은 해시레이트 30·60일 평균과 가격 10·20일 평균을 사용합니다. 감소·회복·회복 후 가격 조건을 구분하고 한 회복 구간에서 한 번 표시합니다. 다른 PoW 자산은 해시레이트 추세만 제공합니다. DASH·ZEC 단위는 GH/s입니다.
- Binance 분 시세의 구간 종료 시각과 실제 마지막 거래 시각을 분리합니다. 거래 ID·가격·시각을 대조하고 300초 신선도 기준을 유지합니다. 오래된 스트림이 같은 초의 더 최신 저장 거래를 덮지 못합니다.

[감사 기록](audit-32/README.md)에 계산·UI·실제 원천·배포·성능 결과를 각각 기록합니다. 합성 검사 결과는 실제 원천의 완전성 근거가 아닙니다. 채굴 비용은 필요한 장비·전력 이력이 없어 제공하지 않습니다. 공간 보호 기준에 걸린 과거 이력 작업과 외부 미검증을 완료로 표현하지 않습니다.

## 0.32.1 설명·주기 보완

운영 화면의 추가 검수에서 기본 RSI와 고급 RSI의 설명, 선택 봉과 원천 관측 주기의 표시를 다시 대조했습니다. 기본 RSI 14는 확정 일봉의 14개 변화로 계산하며, 화면 표시 기간을 바꿔도 계산 기간은 바뀌지 않습니다. 고급 기술 설정의 선택 봉·N은 별도로 설명합니다. 가격·리본·볼린저밴드·슈퍼트렌드의 데이터 정보는 실제 선택 봉을 표시합니다. 계산·DB·시세 수집 계약은 유지합니다.

[보완 검사 기록](audit-32/patch-0321.md)에서 코드·CI·배포 확인을 구분합니다.

## 0.32.2 모바일 배치와 버튼 보완

날짜 고정 뒤에도 차트와 필수 버튼이 가까이 있도록 해시·슈퍼트렌드의 보조값을 차트 아래에 한 번만 표시합니다. 가격 원천·관계·최근값 버튼의 터치 영역과 모바일 가격 선택창의 크기를 정리합니다. 짧게 표시한 날짜의 전체 UTC 시각과 단위는 접근성 정보에 보존합니다. 차트 계산·수집·시세 시각·저장 형식은 바꾸지 않습니다.
