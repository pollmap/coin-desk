- [모형 계약](model-contracts.md): 고정 기준일·회귀·결측·해시 주기·단위·합성 검사의 한계를 기록합니다.
- [데이터·운영 계약](data-runtime.md): 실제 거래 시각·부분 실패·연결 재사용·공간 진단과 배포 범위를 기록합니다.

## 현재 게이트

2026-10-13 코드 통합 시점의 로컬 단위 760개, Node 서버 31개, VPS 도구 27개, 복구 2개 검사가 통과했습니다. 독립 Decimal 계산 검사와 150개 로고/브랜드 검사는 통과했고 의존성 감사 결과 알려진 취약점 0개입니다. 새 테스트 fixture의 Quote 타입 누락으로 두 빌드가 실패했고 fixture를 실제 계약에 맞춘 후 타입·빌드가 통과했습니다. 실패는 제품 시세 오류와 구분합니다.

전체 Chromium/WebKit 검사는 진행 중이며 PR·main CI·배포·운영 브라우저·실데이터·성능 결과를 후속 확인으로 기록합니다. 코드 작성이나 HTTP 200만으로 해당 게이트를 통과시키지 않습니다.

## 알려진 제한

2026-10-13 10:00 UTC VPS 여유 공간은 약 4.486GiB로 과거 수집 보호 기준 8GiB에 못 미칩니다. DB·WAL·백업·압축 효율·파일시스템 예약 공간을 조사했으나 기존 자료나 다른 프로젝트를 삭제하지 않는 최적화만으로 필요한 약 3.514GiB를 확보할 수 없었습니다. 과거 채우기는 보류하며 최신 수집은 별도로 유지합니다. 출시일·원천 최초 관측·실제 저장 시작일과 계산 준비기간을 구분합니다.

보고된 오른쪽 창의 동일 증상은 재현되지 않았습니다. 확인한 Portal 스타일·검색 중첩·URL 잔존 결함의 수정과 그 증상의 해결 주장은 구분합니다. 실제 Apple Safari·VoiceOver, 처음 쓰는 사람 대상 사용성 검사는 미실시입니다. 48시간 대기는 적용하지 않습니다.

## 통합 검사에서 발견한 추가 결함

첫 전체 브라우저 실행(`work/browser-checks/1791887546541-94860`)은 원천 변경 때 더보기 닫힘, 시장 분석 링크의 옛 RSI 기대값, 상대강도 모바일 차트 시작점 289px를 발견해 중단했습니다. 원천 변경에는 설정 영역을 유지하고, 새 슈퍼트렌드 진입에 맞춰 기대값을 바꾸고, 44px 터치 영역을 유지하면서 간격을 줄였습니다.

후속 범위 검사(`work/browser-checks/1791888028307-93536`)에서는 320·390px MVRV 차트 277px, PC 232px·높이 440px를 확인했습니다. 상대강도는 281px로 1px 미달이 남아 여백을 추가 조정했습니다. 이 실행의 WebKit 기존 자료함/차트 검사 세 개는 45초 제한을 초과했습니다. 소스가 검사 도중 CSS 갱신된 구간도 있으므로 완료 실행으로 합산하지 않으며 원인을 확정하지 않습니다. 시간 기준·재시도·비공개 경로 조건은 완화하지 않았습니다.

명시한 날짜와 과거 신호의 우선순위, 최근값을 누른 후 URL이 과거 날짜를 다시 복원하는 문제도 회귀에 포함했습니다. 실제 날짜 선택과 URL을 함께 갱신하고 최근값은 과거 신호 선택을 소비합니다. 최종 동결 소스의 원격 전체 검사와 제한된 로컬 재검사로 다시 확인합니다.

## 첫 PR 전체 CI와 수정

PR #65의 첫 CI `38386413550`은 checks·컨테이너가 통과했지만 Chromium 147통과/14실패/1개 제외, WebKit 145통과/16실패/1개 제외로 실패했습니다. 이 결과를 완료로 합산하지 않습니다.

날짜를 URL에 저장하면서 구간 초기화까지 다시 실행하고, LWC의 다음 프레임에 적용할 구간 대신 이전 구간을 URL에 기록하는 회귀를 찾았습니다. 날짜 복원과 구간 초기화를 분리하고 날짜·구간을 한 번에 반영하며 같은 구간의 URL 응답은 재초기화하지 않습니다. 키보드 이동의 대기 구간도 먼저 기록합니다.

시장 링크에 무거운 지표 카탈로그를 선행 로딩한 회귀는 가벼운 전용 링크 함수와 150개×두 거래소 대조로 고쳤습니다. WebKit의 지연 시세 문구가 화면을 넘는 문제는 짧은 상태·폭 제한·줄바꿈으로 정리하고 정확한 시각과 사유는 정보 패널에 보존합니다. 슈퍼트렌드 시작점 282px는 터치 기준을 유지하며 간격을 줄입니다. 스트림 검사의 옛 상태 문구는 현재 문구로 맞췄고 301초 후 실제 체결 지연 회귀를 추가했습니다.

동결 소스의 새 핵심 검사 46개는 두 엔진에서 재시도 없이 통과했습니다. 이후 날짜 원자화·시장·넘침 수정의 일부 로컬 실행은 SSR 60초/준비 120초 제한에서 브라우저 시작 전에 종료됐으므로 통과로 기록하지 않습니다. 로컬 메모리 여유 약 2.2GB/32.8GB와 여러 Node 프로세스를 관측했으나 시간 초과의 원인은 확정하지 않았습니다. 검사 시간이나 데이터 신선도 기준은 완화하지 않으며 원격 전체 CI로 다시 검증합니다.
