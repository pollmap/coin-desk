## 알려진 제한

2026-10-13 10:00 UTC VPS 여유 공간은 약 4.486GiB로 과거 수집 보호 기준 8GiB에 못 미칩니다. DB·WAL·백업·압축 효율·파일시스템 예약 공간을 조사했으나 기존 자료나 다른 프로젝트를 삭제하지 않는 최적화만으로 필요한 약 3.514GiB를 확보할 수 없었습니다. 과거 채우기는 보류하며 최신 수집은 별도로 유지합니다. 출시일·원천 최초 관측·실제 저장 시작일과 계산 준비기간을 구분합니다.

보고된 오른쪽 창의 동일 증상은 재현되지 않았습니다. 확인한 Portal 스타일·검색 중첩·URL 잔존 결함의 수정과 그 증상의 해결 주장은 구분합니다. 실제 Apple Safari·VoiceOver, 처음 쓰는 사람 대상 사용성 검사는 미실시입니다. 48시간 대기는 적용하지 않습니다.

후속 범위 검사(`work/browser-checks/1791888028307-93536`)에서는 320·390px MVRV 차트 277px, PC 232px·높이 440px를 확인했습니다. 상대강도는 281px로 1px 미달이 남아 여백을 추가 조정했습니다. 이 실행의 WebKit 기존 자료함/차트 검사 세 개는 45초 제한을 초과했습니다. 소스가 검사 도중 CSS 갱신된 구간도 있으므로 완료 실행으로 합산하지 않으며 원인을 확정하지 않습니다. 시간 기준·재시도·비공개 경로 조건은 완화하지 않았습니다.
