# 0.32.1 설명과 데이터 주기 보완

2026-10-13 운영 화면을 추가 검수하면서 계산값과 설명의 적용 범위가 다른 부분을 발견했습니다. 새 분석 기능을 늘리지 않고 설명과 주기 표기만 바로잡습니다.

| 대상 | 확인한 실제 계산 | 보완 |
|---|---|---|
| 기본 RSI 14 | 선택 URL에 주봉이 남아 있어도 확정 일봉 14개 변화 | 고급 선택 봉 RSI와 분리하고 표시 기간은 N을 바꾸지 않는다고 명시 |
| 고급 RSI | 선택 봉 간격·N에 따른 Wilder 계산 | 일봉·주봉 예시를 구분 |
| 가격·리본·볼린저밴드·슈퍼트렌드 | 선택한 확정 봉으로 표시·계산 | 공통 지표 정의와 데이터 정보 표시를 연결 |
| 온체인·기본 RSI·밴드 | 일별 관측 | 선택 봉으로 오인하지 않도록 일별 정의 유지 |

계산 함수·공개 API·DB·의존성·모형 버전·개인 저장 형식은 변경하지 않습니다. 이번 표현 변경에 수집기나 시세 허브를 다시 배포하지 않습니다.

현재 관련 단위 검사 95개와 TypeScript가 통과했습니다. 전체 검사·원격 CI·main 병합·해당 보완 릴리스 배포는 후속 증거로 확인하며, 0.32의 실제 사용 흐름 44개 통과를 새 코드의 검증으로 대신하지 않습니다. 앞선 검사 결과와 실패 자료는 보존합니다.
