# 0.32.1 설명과 데이터 주기 보완

2026-10-13 운영 화면을 추가 검수하면서 계산값과 설명의 적용 범위가 다른 부분을 발견했습니다. 새 분석 기능을 늘리지 않고 설명과 주기 표기만 바로잡습니다.

| 대상 | 확인한 실제 계산 | 보완 |
|---|---|---|
| 기본 RSI 14 | 선택 URL에 주봉이 남아 있어도 확정 일봉 14개 변화 | 고급 선택 봉 RSI와 분리하고 표시 기간은 N을 바꾸지 않는다고 명시 |
| 고급 RSI | 선택 봉 간격·N에 따른 Wilder 계산 | 일봉·주봉 예시를 구분 |
| 가격·리본·볼린저밴드·슈퍼트렌드 | 선택한 확정 봉으로 표시·계산 | 공통 지표 정의와 데이터 정보 표시를 연결 |
| 온체인·기본 RSI·밴드 | 일별 관측 | 선택 봉으로 오인하지 않도록 일별 정의 유지 |

계산 함수·공개 API·DB·의존성·모형 버전·개인 저장 형식은 변경하지 않습니다. 이번 표현 변경에 수집기나 시세 허브를 다시 배포하지 않습니다.

관련 단위 검사 95개와 TypeScript를 확인한 뒤, 전체 단위 764개·Node 서버 31개·VPS 도구 27개·복구 2개·Chromium/WebKit 336개가 통과했습니다. 브라우저 재시도는 0이며 개인 경로 2개는 제외했습니다. PR #66과 PR CI `38405098522`, main CI `38406758530`은 통과했고 코드 main은 `7363f80a30a5f6e98a0f18b566bec455645ab255`입니다. 앞선 검사 결과와 실패 자료는 보존합니다.

VPS는 `vps-c7a1074bf44ddf04`, Pages는 `https://92aac3fe.coin-desk.pages.dev`로 적용했습니다. 변경된 API·웹만 배포했으며 보호 대상 수집·시세·백업 서비스 7개의 컨테이너 ID가 그대로였습니다. 운영 SQLite 온라인 스냅샷과 독립 복원에서 21개 테이블의 스키마·인덱스·행 수·내용을 대조했고, 준비용 RAM 마운트는 검증 뒤 정상 해제했습니다. 과거 수집의 8GiB 여유 공간 기준은 유지했습니다.

두 주소의 공개 파일 512개는 최종 대조에서 모두 일치했습니다. 첫 조회는 511개 일치와 VPS 워드마크 한 건의 시간 초과였고, 해당 한 건의 별도 후속 조회에서 정상 바이트를 확인했습니다. 이 복합 결과를 한 번의 동시 통과로 표현하지 않으며 시간 초과 원인은 미확정입니다. VPS HTML의 공유 메타데이터 주소 치환만 사전에 선언한 예외로 대조했습니다.
