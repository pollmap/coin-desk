## 현재 입력 대조와 한계

2026-10-17 원천 재조회는 Coin Metrics 143개 응답과 저장된 585시리즈를 대조했습니다. 최초·최근 관측일은 일치했고, 과거 차이는 별도 보정 절차로 처리합니다. 이것으로 Bitview·Glassnode·공포탐욕·ETF·거시 지표까지 검증했다고 표현하지 않습니다. 결과는 [릴리스 감사](README.md)의 데이터 증거로 연결합니다.

보유자 묶음의 STH/LTH MVRV는 기존 무료 Bitview 입력으로 연결합니다. LTH SOPR와 ‘장기보유자 손실’은 별도 입력과 정의가 필요합니다. 무료 원천에서 확인하지 못한 지표는 빈 차트나 추정 수치로 추가하지 않습니다. 라이선스 검토 없이 무료 공개 접근을 상업적 재배포 허가로 확대하지 않습니다.

## 정의 근거

- [Coin Metrics 시가총액·실현가치](https://docs.coinmetrics.io/network-data/network-data-overview/market/market-capitalization): 원장 공급량과 유통량을 구분합니다. 문서에 지표가 있다는 사실은 Community API 이용 가능 여부와 다릅니다.
- [Glassnode 공급 지표](https://docs.glassnode.com/basic-api/endpoints/supply), [손익 지표](https://docs.glassnode.com/basic-api/endpoints/indicators): HODL Waves·실현가치 가중 비중·SOPR·NUPL을 구분하는 정의 근거입니다. 유료 시계열을 취득했다는 의미가 아닙니다.
- [Capriole Hash Ribbons 원문](https://capriole.com/hash-ribbons-bitcoin-bottoms): 해시·가격 조건의 근거입니다. 과거의 성과 문구를 매수 보장이나 바닥 확정으로 옮기지 않습니다.
- [Alternative.me 공포·탐욕](https://alternative.me/crypto/fear-and-greed-index/): 공개 API·귀속 요구를 확인한 후보 원천입니다. 현재 운영 연결은 아닙니다.
- [Lightweight Charts 역할](https://tradingview.github.io/lightweight-charts/docs/product-comparison): 차트 라이브러리가 시장 데이터를 제공하지 않습니다.
