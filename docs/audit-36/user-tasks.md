# 실제 사용 과제

상태: 사람 대상 미검증. 브라우저 도구와 자동 회귀의 통과 여부는 [릴리스 기록](README.md)에 따로 기록합니다.

| 과제 | 도움 없이 확인할 행동 | 기록할 결과 |
|---|---|---|
| 관심 코인 찾기 | 시장에서 DOGE를 찾아 한 번 선택 | 성공 여부·막힌 위치 |
| 사이클 훑기 | 가격에서 가치평가·보유자·추세로 내려가기 | 필요한 차트를 찾았는지·스크롤 방해 여부 |
| 필요한 차트 확대 | MVRV를 크게 열고 다시 돌아오기 | 같은 코인·범위·읽던 위치인지 |
| BTC와 비교 | DOGE와 BTC의 성과 또는 비율 확인 | 기준 코인·통화·단위를 이해했는지 |
| 분석 다시 열기 | 차트 구성을 저장하고 내 저장에서 다시 열기 | 구성·기간·범위·읽던 위치 복원 여부 |

가격·지표의 기준과 데이터가 틀렸다고 느껴지거나, 버튼이 무엇을 하는지 알 수 없는 지점은 성공률과 별개로 기록합니다. 진행시간·성공률·만족도를 실제 참여 없이 채우지 않습니다.

Apple Safari·VoiceOver·실물 휴대폰 검증은 별도 미검증입니다. Chromium의 CDP 터치는 실제 하드웨어 검사로 표현하지 않습니다.
