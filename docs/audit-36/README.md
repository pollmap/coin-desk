0.35 배포 뒤 순차 상태 조회의 지연 원천은 66~67개, 실제 오류는 0개였으며 health는 503이었습니다. 이 수치는 표본이며 현재 가격 모두 정상 또는 전체 과거 복구 완료를 의미하지 않습니다. 오래된 실제 체결을 최신 수신 시각으로 바꾸지 않습니다.

과거 테스트 수나 성능을 이번 릴리스의 검증 결과로 쓰지 않습니다. 사용자 개인 원본·인증·요청 헤더·서버 비공개 로그는 이 기록에 포함하지 않습니다.

143개는 Coin Metrics 참조가격 자산 수이며 모두 MVRV를 지원한다는 뜻이 아닙니다. 대조한 585개 계열에는 참조가격 143개, 공개 네트워크·유도 지표 408개, 내부 중복 가격 34개가 포함됩니다.

원천 대조 보정은 [독립 검증 증거](../audit-35/source-reconciliation-20261017.json)를 따릅니다. 원천의 과거 값 수정과 이전 수집 오류 중 어느 쪽이 차이를 만들었는지는 확정하지 않았습니다. 두 번의 읽기 검사 실패는 실제 DB 쓰기 전에 중단됐으며 권한을 넓히지 않고 별도 경로에서 다시 검증했습니다. 공개 양 주소의 과거 값 표본 20건도 원천과 일치했습니다.

선물 일회 복구는 [진행 증거](../audit-35/derivatives-recovery-20261017.json)로 분리합니다. 기존 일일 예산을 초기화하지 않았고 승인된 100만 후보 한도·만료·체크포인트·자원 보호를 사용합니다. CPU 보호로 중단한 뒤 실제 기준 충족을 확인하고 재개했습니다. 실행 중인 작업을 전량 복구 완료로 기록하지 않습니다.

실데이터 로컬 미리보기에서 가격→MVRV 읽는 법→크게 보기→뒤로 가기를 수행했습니다. 처음에는 집중 화면에 이전 스크롤이 남고 복귀 위치가 잘렸습니다. 모드 전환·이동 전 저장·지연 렌더 높이 보존을 수정한 뒤 확대 화면 0px, 원래 대시보드 937.5px→938px 복귀와 왼쪽 목록 top 80px를 확인했습니다. 이는 브라우저 도구 검수이며 찬희님 직접 과제·실물 기기 검사가 아닙니다.
