## 변경과 호환

일반 코인 선택은 여러 차트를 읽는 대시보드로, 명시적인 지표 링크는 집중 화면으로 연결합니다. USD 장기 종가와 실제 KRW·USDT OHLC를 구분하고, 기존 계산·확정 봉·준비기간·결측 조건을 유지합니다. 대시보드의 기본 상대 비교는 가격 비율입니다. 별도 가격 성과 비교와 같은 지표 비교는 각기 다른 행동으로 유지합니다.

활성 주소는 지원 코인의 기본 네트워크 차트이며 거래 수·리본·볼린저밴드·계절성은 선택해서 추가합니다. 공통 입력을 공유하고 화면 가까운 차트만 생성합니다. 기존 저장 버전 1·2와 개인 자료를 보존하고 버전 2에 차트 구성·개별 확대·읽던 위치를 선택 필드로 추가했습니다.

## 실패와 수정 이력

- 첫 PR 실행은 후속 커밋으로 취소됐으므로 최종 판정에 사용하지 않습니다.
- `39022639293`: 작은 모바일의 WLFI 차트 시작점이 Chromium 282.17px·WebKit 283.17px로 280px 기준을 넘었습니다. 이름과 시세의 폭 경쟁을 줄이고 실제 간격을 정리했습니다. 글자·이름·가격·44px 조작 영역과 검사 기준은 유지했습니다.
- `39023920575`: Chromium 232개 통과, WebKit의 비교 설정창 대비 2건 실패. 로컬에서는 최종 색상 대비가 정상이고 열기 중 본문 투명도 변화가 관측됐습니다. 원격과 동일한 axe 실패는 로컬에서 재현되지 않아 원인을 확정하지 않았습니다. 본문 페이드를 제거하고 첫 표시부터 opacity 1인지를 검사했습니다. 배경막 전환은 유지합니다.
- 수정 후 관련 44개 양 엔진 로컬 검사는 재시도 없이 통과했습니다. 이전 42·114·44개 실행에는 대상 중복이 있으므로 합산하지 않습니다. HMR이 있었던 개발 실행과 고정 빌드의 CI를 구분합니다.
- `39025158439`: WebKit은 통과했지만 Chromium의 데스크톱·터치 펀딩률 보조 패널에서 방향키 날짜 이동 2건이 실패했습니다. 화면 갱신 전에 연속 입력하면 이전 날짜를 다시 참조하는 경로를 로컬에서 재현했습니다. 최신 요청 날짜를 동기적으로 사용하고 대기 중 커서 작업을 교체하도록 고쳤습니다. 빠른 입력·마우스와 터치 전환·Escape·코인 변경을 따로 검사했습니다.
- 독립 코드 검토에서 MVRV 대시보드의 새 확대 범위가 ‘같은 지표 비교’에 전달되지 않는 결함을 발견하고 로컬에서 재현했습니다. 비교와 크게 보기의 링크에 현재 범위를 선언적으로 반영했습니다. 일반·Ctrl·중간 클릭의 실제 목적지와 차트 재생성 여부를 확인했습니다. 중간 클릭은 브라우저별로 새 탭 또는 같은 탭일 수 있어 실제 이동 결과를 검사합니다.
- `39027082512`: WebKit 234개 통과, Chromium 234개 통과·1개 실패. Ctrl 클릭의 새 탭을 Playwright가 찾지 못했지만 원격 trace에는 정확한 비교 URL의 새 페이지 문서와 API HTTP 200이 남았습니다. 제품 링크의 잘못된 이동으로 단정하지 않았습니다. 네이티브 탭 검사 2개만 공식 full Chromium의 새 headless 채널에서 실행하도록 분리했고 검사 본문·기대값·시간 제한·재시도 정책은 유지했습니다. 관련 로컬 양 엔진 4개 검사는 통과했으며 최종 원격 결과를 별도로 기록합니다.
- 로컬 fixture의 포트 충돌·초기 테스트 구성 오류와 수정 전 실패도 [로컬 QA](local-qa.json)에 보존했습니다. 테스트 시작 실패를 제품 통과 수에 넣지 않았고, 실패 job 재시도로 결과를 바꾸지 않았습니다.
- 첫 운영 배포 준비 호출은 로컬 배포 드라이버가 생성한 원격 Python 문자열의 줄바꿈 오류로 중단됐습니다. 서버에 전송된 7개 파일만 있었고 준비 실행·백업·DB 쓰기·운영 교체는 시작되지 않았습니다. 해당 문자열을 raw 본문으로 수정하고 생성 코드 compile 회귀 검사를 추가했습니다. 기존 파일 해시와 운영 릴리스를 다시 확인한 뒤 같은 검증 이미지·엔진으로 준비 단계부터 이어갔습니다. 최종 실행 결과는 배포 증거에 분리했습니다.
- 일반 CI의 개인 원본 경로 opt-in 검사는 양 엔진에서 각각 제외합니다. WebKit의 실제 다중 터치 한 항목은 도구 제약으로 별도 제외하며 개인 자료 검사로 분류하지 않습니다.

- 0.36 실화면에서 PC 휠이 차트 위에서 페이지를 이동시키지 않는 결함을 발견했습니다. 수정 전 양 엔진 4건 실패를 재현한 뒤, 0.36.1에서 대시보드의 휠을 페이지로 전달했습니다. 가로 드래그·핀치·집중 차트 휠 확대는 유지합니다. 관련 양 엔진 30개와 실제 CDP 터치 조작을 확인했으며 실물 휴대폰 검사로 표현하지 않습니다. [로컬 근거](wheel-local-0361.json).
- 최초 0.36 운영 흐름 검수는 28단계 중 26개를 통과했고 PC 저장 복원 2건은 검사 도구의 DOM 교체 경합으로 실패했습니다. 정확한 이동 URL·값을 보존하고, 새 화면 준비를 기다리는 별도 검사 2건을 통과했습니다. 기존 실패 기록을 지우지 않았으며 0.36.1 전체 재검사 결과는 따로 연결합니다.
- 0.36.1 배포 직후 Pages의 JavaScript 2개 경로에서 기본 HTML이 돌아와 첫 대조는 233/235였습니다. 재배포 없이 해당 경로의 배포 전용·운영 주소에서 올바른 파일을 확인했고, 이어진 전체 재대조는 양 주소 235/235가 일치했습니다. 전파·캐시 중 어느 것이 원인인지는 확정하지 않았습니다. [최초 불일치](deployment-initial-0361.json)를 보존합니다.

## 데이터·운영 한계

Coin Metrics 143개는 USD 참조가격 자산 수입니다. 모두 MVRV를 지원한다는 뜻이 아닙니다. 585계열에는 가격 143개·공개 네트워크/유도 408개·내부 중복 가격 34개가 포함됩니다. 과거 차이가 공급자 수정 때문인지 이전 수집 오류 때문인지는 확정하지 않았습니다. 공개 양 주소의 과거 표본 20개도 원천과 일치했습니다.

가격 캔들의 최초 관측·공백에 대한 이전 10월 15일 검사는 이번 10월 17일 전수 검사로 바꾸어 기록하지 않습니다. 거래 없는 구간·원천 미제공·계산 준비기간을 새 가격으로 채우지 않습니다. 최근값 대조만으로 이력 전체와 다른 제공자까지 검증했다고 표현하지 않습니다.

0.35는 검증된 main `32b2396`의 API·시세 허브를 먼저 반영했고 보호 대상 컨테이너 6개를 유지했습니다. 해당 배포 후 짧은 표본에서 핵심 시세 6개 확인 시각과 Binance 실제 체결 3개를 확인했습니다. 0.36과 0.36.1은 API와 웹만 교체하며 운영 0.35 수집기의 동작을 새 UI 배포의 효과로 돌리지 않습니다.

최종 공개 자산 대조는 2026-10-17 13:19~13:20 UTC에 수행했습니다. 양 주소의 활성 원천은 정상 1,553·지연 32개였고, health는 HTTP 503·TRADE_STALE 32개를 반환했습니다. 이후 실화면 QA 사전 조회는 정상 1,549·지연 36개였습니다. 조회 시점이 다르며, 기능 검수 통과를 모든 시세의 신선도로 바꾸어 표현하지 않습니다. 핵심 시세 6개의 확인 시각은 0.36.1 배포 후 직접 수집 없이 120초 표본에서 증가했습니다. 일회 복구 설치 검증 시 여유 공간은 29.44GiB였고 기존 실행 컨테이너 21개 식별자가 유지됐습니다. 가장 늦은 운영 표본은 [선물 복구 기록](../audit-35/derivatives-recovery-20261017.json)을 따릅니다.

48시간 대기는 추가하지 않습니다. 비밀정보·요청 헤더·개인 원본·서버 비공개 로그는 공개 증거에서 제외합니다. 동일 VPS 백업·독립 복원은 서버 전체 장애에 대한 외부 재해 복구를 뜻하지 않습니다.

13:39 UTC 최종 순차 표본은 Pages 정상 1,544·TRADE_STALE 41개, VPS 정상 1,545·TRADE_STALE 40개였고 양쪽 health는 503이었습니다. 원천 오류는 0개·예약 stalled=false, BTC·DOGE·ETH 양 거래소 6개 실제 체결은 24~33초 전·확인은 23~26초 전·실패 0개였습니다. 핵심 시세가 신선하다는 확인과 전체 시세의 신선도는 구분합니다.

대시보드의 데이터·카드·화면과 스타일 책임은 분리했지만, 기존 전역 CSS 12개 import는 남아 있습니다. 교체한 일부 규칙 제거를 전역 스타일 전체 정리 완료로 표현하지 않습니다.

## 일회 복구 예약

`coin-desk-history-once-20261018.timer`의 다음 실행은 D-Bus 마이크로초 epoch와 systemd 달력 해석 양쪽에서 **2026-10-18 00:05 UTC / 09:05 KST**로 대조했습니다. 타이머는 active/waiting, 서비스는 inactive/dead이며 설치 시 수집을 즉시 시작하지 않았습니다. Persistent=false·재시작 없음·기존 grant 만료·새 정규 UTC 예산·8GiB/부하/CPU/RAM 보호를 유지합니다. 실행 시 보호 조건이 맞지 않으면 완료하지 않고 중단할 수 있습니다.

서버의 CEST 시각 표시 때문에 설치 후 첫 문자열 검증이 실패했지만 실제 예약은 이미 생성돼 있었습니다. 재설치하지 않고 epoch를 독립 대조한 결과를 보존했습니다. 일회 작업 결과 확인은 10월 18일 13:10 KST의 이 대화 후속으로 설정했습니다. 이 후속 실행은 Codex 앱의 실행 가능 상태에 의존하며 서버 타이머 자체와 구분합니다. 기존 제품 Cron과 다른 서비스는 변경하지 않았습니다.
