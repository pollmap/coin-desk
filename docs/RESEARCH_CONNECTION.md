# X 리서치 연결

0.12의 계정 목록과 외부 링크는 바로 사용할 수 있습니다. 서버 자동 수집은 기본 비활성입니다. 사용자 제공 리스트 `1940844025483088368`의 최근 20개 글 중 등록된 37계정의 글만 표시합니다. 제공된 리스트 밖 계정의 글까지 전수 수집하지 않습니다. 최근 표본이며 모든 게시물 보관 기능이 아닙니다.

## 활성화 조건

서버에 아래 세 값이 모두 있어야 호출합니다.

- `X_BEARER_TOKEN`: X 개발자 토큰. `npx wrangler secret put X_BEARER_TOKEN`의 보안 입력으로 등록합니다. Git, 브라우저, 문서에 넣지 않습니다.
- `X_COLLECTION_ENABLED`: 운영자가 `1`로 설정해야 합니다.
- `X_MAX_REQUESTS_PER_DAY`: 1~24의 정수. 일별 요청 횟수 상한이며 금액 상한이 아닙니다. 실패한 호출도 계산합니다.

[X API 요금 안내](https://docs.x.com/x-api/getting-started/pricing)는 사용량 기반 크레딧 방식을 설명합니다. 활성화 전에 개발자 콘솔에서 실제 엔드포인트 요금·권한·지출 한도를 확인해야 합니다. 이번 배포는 유료 수집을 활성화하거나 크레딧을 구매하지 않습니다.

## 운영

[리스트 게시물 API](https://docs.x.com/x-api/lists/get-list-posts)를 사용합니다. 고정 api.x.com만 요청하고 redirect를 거부합니다. 15초 timeout, 시간당 공유 lease, UTC 일별 요청 상한이 있습니다. 방문자는 `/api/v1/research`의 저장 결과만 읽고 외부 요청을 유발하지 않습니다.

텍스트·이미지·동영상을 복제해 저장하지 않습니다. 게시물 ID, 작성자, 시각, 원문 URL, 텍스트에 명시된 지원 코인, 미디어 첨부 유무만 저장합니다. 성공 시 최신 표본으로 대체하고 24시간 이상 갱신하지 못하면 공개 피드를 숨깁니다. 작성자를 등록 목록과 대조하고 미래·삭제 제한·보호 계정·잘못된 ID를 제외합니다. 분석가 의견을 숫자나 롱/숏 신호로 변환하지 않습니다.

인증 없는 현재 배포에서 `GET /api/v1/research`는 HTTP 200, `state: disabled`, `posts: []`를 반환해야 합니다. 활성화 후에는 실제 원문과 작성자를 대조한 뒤 `ready`와 수집 시각을 확인해야 합니다. 정기 시세 수집기는 별도로 계속 동작합니다.

## 검증

`npm run check`가 API 조회의 비수집성, 중복 cron lease, 실패 시 요청 예약, 일별 상한, 오래된 데이터 숨김, 임의 URL 주입 거부와 비밀키 비노출을 검사합니다. 테스트 성공은 X 계정 권한이나 크레딧 확보를 증명하지 않습니다.
