# 0.18 검증 기록

기능·범위는 [RELEASE18](../RELEASE18.md), 검색 성능 측정은 [search-performance.json](search-performance.json)에 있습니다.

- 단위/계산·DB 복구·빌드·전체 브라우저 검사는 최종 커밋 CI로 확인합니다.
- 새 검사에서 발견한 검토 체크박스의 저장 지연 피드백, 빈 목록 접근성 오류를 수정했습니다. 테스트의 option 선택 범위를 목록으로 한정하고 한글 X fixture의 문자 인코딩을 명시했습니다. 검사를 통과시키려고 지원 범위·계산 조건·접근성 기준을 낮추지 않았습니다.
- 리본 색·날짜 구간·설정 복원, 자료 작성자/검토 필터, 가상 목록 키보드, 확장 연결 응답, 북마크 주소 변경, 인용 자료 분리 회귀 검사를 추가했습니다.
- 개인 글·이미지·메모·로그인 정보는 이 문서와 공개 배포에 넣지 않습니다. 파일 검사·내용 검토·전체 수집은 서로 다른 완료 조건입니다.
- 실제 Safari/VoiceOver는 Apple 기기 미보유로 대기입니다. WebKit 검증은 별도 결과로 기록합니다.

## 개인 자료·남은 실제 확인

- 기존 6,227행·이미지 4,387개의 구조·경로·디코딩 검사는 통과했습니다. 이번 내용 검토는 본문 33건·이미지 5개이고, 전체 방법론 검증 완료는 아닙니다.
- 사용자가 확장 설치·새로고침·수집 시작을 확인했습니다. 실제 운영 자료함에서 설치된 확장의 연결 응답도 확인했습니다. 전체 수집 범위·원본 이미지 전송·중단 후 재개 실사용은 아직 완료 증거가 없습니다.
- 기존 로컬 보관본을 실제 Chrome 자료함에 가져오려는 파일 선택은 브라우저 도구의 파일 접근 제한으로 차단됐습니다. ChatGPT 브라우저 확장의 파일 URL 접근 허용 또는 사용자 직접 폴더 선택이 필요합니다. 원본은 삭제·수정하지 않았습니다.
- 실제 Safari·VoiceOver는 Apple 기기 미보유로 검증 대기입니다. Playwright WebKit 통과와 혼동하지 않습니다.
- 임시 운영 후속 자동화는 유지합니다. 엄격한 안정성·완전 UTC 하루 비용·다음 날 브리핑·자연 갱신을 모두 확인한 후 해당 자동화만 중지하며 제품 Cron은 계속 실행합니다.
