# Coin Desk 0.14 — 화면 마감과 갱신 장애 대응

2026-09-24 검수. BTC를 중심으로 DOGE·ETH를 분석하는 기존 제품을 다듬었습니다. 신규 코인이나 임의의 예측 지표를 늘리지 않았습니다.

## 사용자 흐름과 디자인 판단

1. **코인 선택**: 상단에 ‘코인 변경’을 명시하고 펼침 화살표, BTC·DOGE·ETH의 로고·이름 바로가기를 배치했습니다. 선택 코인의 강조색은 모든 분석 메뉴에서 같습니다. 검색은 한글·티커·별칭을 받으며 결과에서 방향키·Home·End 이동을 지원합니다.
2. **가격 확인**: 상단·도구 모음의 여백을 줄여 주 차트를 앞당겼습니다. 원화 거래대금은 억 원·조 원으로 읽습니다. Upbit KRW와 Binance USDT는 실제 각 거래소 가격이며 임의 환산하지 않습니다. 시세 갱신 장애는 시세 바로 아래에 표시합니다.
3. **전체 이력 분석**: BTC MVRV 초기의 큰 값 때문에 이후 흐름이 평평하게 보이던 문제를 수정했습니다. 양수만 있는 MVRV·USD 지표는 로그축으로 시작하고 사용자가 선형축으로 바꿀 수 있습니다. 원본과 시작일은 보존하며 NUPL 및 0·음수 이력은 선형축을 유지합니다.
4. **다른 분석으로 이동**: 가격→기술적 분석에서 거래소 기준을 유지합니다. 코인별 7개 분석 메뉴, 선물의 Bybit USDT 계약 표시, 역사 사건과 가격 연결, 원문 중심 리서치 목록을 확인했습니다. 긴 산식·연결 상태는 펼쳐 읽는 기존 구조를 유지합니다.
5. **복구**: 조회가 실패하면 마지막 정상 차트를 유지하고 15·30·60초 간격으로 재시도합니다(해당 조회의 정상 주기를 초과하지 않음). 도미넌스 조회는 서버 저장값을 즉시 반환하며 방문자의 요청에서 외부 수집을 기다리지 않습니다. 지연 안내는 주 차트 위에 표시합니다.

## 서버 변경과 검증

- 실패 백오프를 지키면서 5분 이상 밀린 BTC 온체인·시장 공통 작업이 보조 코인 적재 때문에 계속 밀리지 않도록 조정했습니다.
- CoinLore 고정 URL만 받는 인증된 지역 피드 경로를 추가했습니다. 응답의 시가총액·단위 검증을 통과한 경우에만 새 관측을 저장합니다. 인증 없는 요청과 임의 URL은 거절합니다.
- 타입검사 및 테스트 **283개 통과**. 프로덕션 빌드와 Decimal 참조 계산, 문서 링크, 브랜드 자산 및 소스 패키지 검사를 통과했습니다. CI에서 발견한 정각 시간 경계의 테스트 오차도 정각·500ms·1초 후 고정 시각으로 검증하도록 수정했습니다.
- 테스트는 읽기 요청의 수집·쓰기 금지, 도미넌스 잘못된 응답의 미적재, 재시도 대기 우선순위, 지역 피드 인증, KRW·USDT 거래대금 단위를 포함합니다. 로그축 수동 전환은 실제 브라우저에서도 확인했습니다.

## 운영 완료를 막는 실제 항목

검수 중 Cloudflare Worker 로그에서 **D1 무료 일일 쓰기 한도 초과** 오류를 확인했습니다. 기존 데이터 읽기는 가능하지만 Cron의 새 데이터 저장이 실패합니다. 이 상태를 자동 운영 정상이나 실시간 데이터라고 보고하지 않습니다. 코드 배포와 갱신 정상화는 별도 완료 조건입니다.

[Cloudflare D1 공식 가격](https://developers.cloudflare.com/d1/platform/pricing/)상 무료 쓰기는 계정당 하루 100,000행이며 한국 시각 09:00에 한도가 재설정됩니다. [Workers 유료 가격](https://developers.cloudflare.com/workers/platform/pricing/)은 월 최소 US$5 및 사용량별 과금입니다. 변경 없는 관측의 덮어쓰기는 기존 조건부 upsert로 억제하지만, 현재 계정은 실제 한도에 도달했습니다. 유료 전환은 비용 승인을 받은 후 진행합니다. 승인 전 결제·요금제 변경은 하지 않았습니다.

운영 정상화 후에는 공개 health 응답, 핵심 3코인의 6개 시장 시세 시각, 방문자 없는 연속 Cron 성공, CoinLore 지역 피드 적재 성공을 다시 확인해야 합니다. X 공개 HTML 수집은 원문 링크와 확인 가능한 메타데이터만 다루며 전체 게시물 수집·계정 인증을 보장하지 않습니다. 기존 castlehousetoo 수집 실패도 숨기지 않습니다.
