# 보리차트 0.22 검증 기록

## 범위

기준은 사용자 승인 ‘보리차트 개편’입니다. 브랜드·시장·상세·비교·저장과 분석 대상의 정확성을 다룹니다. 주문, AI 투자 판단, 신규 거래소, 유료 원천, X 추가 수집은 추가하지 않습니다. 개인 저장 데이터와 운영 서버 식별자를 보존합니다.

## 발견 사항과 처리

## 계산 검증과 의도적인 제한

- `tests/relative-pair.test.ts`: 8개 대상, 옛 링크, v1/v2 저장, 손으로 계산한 비율·정규화, 독립 Pearson 계산, 미래 관측 추가 후 과거 불변, 평탄 가격.
- 기존 `advanced-analysis`, `btc-rainbow`, `history-bands`, `indicators` 계열 검사를 유지합니다. 730일·결측·확정 봉·표준편차 0·미래 데이터 미사용을 이번 화면 수정으로 완화하지 않습니다.
- Coin Metrics·Bitview 제공값의 내부 원장은 보유하지 않습니다. 제공값 표시·유도 공식과 원천 정의를 대조하며 전체 원천의 독립 재산출 완료로 표현하지 않습니다.
- 참고 링크는 프로젝트 측 설명으로 한정하며 독립적인 프로젝트 위험 등급, 토큰 언락의 실시간 검증 기능을 만들지 않습니다. 공식 페이지 확인일은 2026-10-03입니다.
- 개인 자료 전체의 내용 검토, X 전수 수집, Safari·VoiceOver 실기기 검사는 이번 완료 범위가 아닙니다. 공개 자료를 개인 검토의 대체 증거로 쓰지 않습니다.

## 개발 중 실패 기록

- 로컬 Windows Cloudflare workerd 게이트웨이 검사는 `spawn EPERM`으로 2회 실패했습니다. 제품 API 장애로 해석하지 않으며 원격 Linux CI 결과를 별도 기록합니다. 나머지 로컬 Node 서버 16개, VPS Python 15개, 복구 2개는 통과했습니다.
- 새 모바일 배치 검사에서 차트 시작점 419px→321px→300.5px가 발견되어 레이아웃을 수정했습니다. 조건을 완화하지 않았습니다. 최신 Chromium은 320px에서 290.5px, 390px에서 296.5px, 768~1920px에서 222px입니다.
- 비교 화면 최초 단일 테스트에서 338px를 확인하고 설정·메타데이터 간격을 수정했습니다.
- StrictMode 차트 재마운트 후 이전 시리즈 참조가 남아 캡처에 차트가 비어 보이는 문제를 수정하고, 비어 있지 않은 실제 범위와 canvas 보존을 검사했습니다.
- 감사 목록 생성기의 Vite 의존성 스캔 종료 경고는 사전 번들 스캔을 끄고 정상 종료하는 것으로 수정했습니다.

- 첫 전체 브라우저 실행은 146개 통과·9개 실패·1개 제외였습니다. 실패는 시장 가격/시각 클릭 영역 6건, WebKit의 복수 안내 선택자 1건, 비교 시작점 324px 1건, 의도하지 않은 개인 경로 opt-in 1건입니다. 클릭 영역과 배치·선택자를 수정했으며 최종 실행은 개인 경로 opt-in을 끕니다. 원본 파일은 수정하거나 공개하지 않았습니다.

- 후속 로컬 전체 실행은 153개 통과·2개 제외이며 Chromium 접근성 스캔에서 `Target crashed` 1건이 있었습니다. 같은 검사를 단독 실행해 재시도 설정 없이 통과했으며 종료 원인은 미확정입니다. 별도 동시 실행의 fixture 준비 시간 초과도 있었고, 이후 순차 실행은 정상입니다.
- PR CI 37124472081은 Linux WebKit 모바일 배치 2건(323.5px/312.5px)으로 실패했습니다. Windows와 다른 줄바꿈이 최근값·기준일을 두 행으로 밀어낸 증거를 확인하고, 숫자와 날짜를 grid 열로 분리했습니다. 모바일 상단 행 간격도 줄였으며 300px 기준은 유지합니다.
- 상대강도 CSV 다운로드는 두 브라우저에서 파일명·대상·단위·원천을 실제 파일 내용과 대조해 통과했습니다.

## 최종 결과

원격 CI·배포·운영 확인 결과는 검증 완료 후 이 문서와 별도 JSON 증거에 기록합니다. 현재 이 문서의 작성만으로 배포 완료를 뜻하지 않습니다.
