# 0.38 — 로그축과 레인보우, 차트를 읽는 설명

가격 차트를 같은 축 정책으로 읽고, BTC Original과 보리차트 자체 회귀를 구분한다. 사전은 긴 행 목록으로 구성하고 차트의 읽는 법과 같은 설명을 사용한다.

## 동작 기준

- 가격·캔들·슈퍼트렌드·이동평균·볼린저밴드·실현가격·레인보우는 로그축을 기본으로 한다. 명시한 URL·저장 분석·사용자 선택을 우선 보존한다.
- 수익률·낙폭·상관·NUPL·펀딩률처럼 음수 또는 비율을 해석하는 계열은 일반 축으로 표시한다. 실제 0 이하 보조선을 삭제해 로그축에 맞추지 않는다.
- 양수 가격의 자동 범위와 여백을 양수로 유지하며, 작은 가격과 평탄한 가격의 눈금·십자선·툴팁을 함께 검사한다.
- `view:btc_rainbow_original`은 BlockchainCenter의 현재 공개 Original 구현을 확인한 별도 모델이다. 역사적 2022 V2 또는 Dynamic과 같다고 주장하지 않는다. 기존 자체 회귀 ID·계산과 작업공간은 보존한다.
- 공식 날짜와 관측 행 번호 대응만 모델에 사용한다. 가격은 기존 BTC USD 원천을 사용하며, 원본 가격 배열을 새 가격 원천으로 복제하지 않는다. 미래 곡선은 만들지 않는다.
- 설명은 의미·그림·읽는 기준·숫자 예시부터 보여주고 세부 공식과 용어는 펼쳐 읽는다. 예시는 실제 관측과 구분한다.
- 사전 목록의 카드 격자와 반복 안내를 제거하고 코인·원천·기간·읽던 위치를 보존한다.

## 보존과 배포

AI·Telegram·공유·내보내기·운영 메타데이터 표시를 추가하지 않는다. 사용자 자료와 기존 저장 키·작업공간 버전 1·2를 보존한다. 기존 0.37 보고서 변경과 이번 변경의 검증 기록을 구분한다.

타입·계산·서버·복원·브라우저 검사와 PR·main CI를 확인하고 변경 서비스만 배포한다. 48시간 대기는 추가하지 않는다. 실제 휴대폰·Safari·VoiceOver와 사람의 이해도 검사는 수행 범위를 별도로 기록한다.

현재 구현·검증 진행 상태와 배포 근거는 [감사 기록](audit-38/README.md)에 기록한다. 이 명세 자체는 배포 완료의 근거가 아니다.
