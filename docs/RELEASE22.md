# 보리차트 0.22 — 주요 코인의 지표를 쉽게 읽기

이번 버전은 기존 Coin Desk의 표시 브랜드를 **보리차트**, 기존 시바견을 **보리**로 정리합니다. URL, API, 서버 서비스 이름, 데이터베이스와 `coin-desk.*` 저장 키는 유지합니다. 도메인·상표 확보를 뜻하지 않습니다.

## 달라진 흐름

시장 표에서 여덟 코인과 대표 분석을 고르고, 지표·날짜를 살펴본 뒤 설명을 읽고 저장합니다. 시장의 중복 가격 요약을 제거하고 ‘주요 8코인’, 분석 바로가기, 최근 분석 이어 보기, 키보드·터치로 여는 체결 시각을 제공합니다. 홈은 기존 시장 일괄 조회와 스트림만 사용합니다.

내 저장은 저장 목록부터 보여 줍니다. 코인·지표·기간·원천을 표시하고 같은 이름 덮어쓰기에는 확인을 거칩니다. 삭제 취소와 기기 백업·복원을 유지합니다. 개인 원본을 공유 주소나 서버로 보내지 않습니다.

상대강도는 선택 코인과 비교 코인 두 개를 사용합니다. ONDO 화면에 BTC·DOGE·ETH 고정 비교가 뜨던 문제를 수정했습니다. `benchmark_asset`를 저장하며 이전 `correlation_asset=DOGE|ETH` 주소는 해당 코인/BTC 비교로 명시적으로 변환합니다. 원천·통화·공통 날짜가 맞지 않으면 대체 데이터를 섞지 않습니다.

## 차트와 설명

- 흰색 기본, 청록 강조, 상승 빨강·하락 파랑과 부호를 유지합니다. 저장된 다크 테마도 유지합니다.
- 비교 차트는 데이터 갱신 때 기존 차트와 확대 구간을 유지합니다. StrictMode 재마운트에서도 오래된 시리즈 객체를 재사용하지 않습니다.
- 상대강도 설정은 공통 도구줄에서 펼칩니다. 설정을 열어도 차트 위치가 변하지 않고 Escape로 닫으면 초점이 돌아옵니다. 설명 페이지 왕복에도 비교 코인·비교 방식·상관 기간을 보존합니다.
- 지표 48개 정의에 짧은 뜻·기준선 해석·관측 주기·측정 범위를 연결했습니다. [지표 대조표](audit-22/indicator-definitions.md)와 [공식·숫자 예시](audit-22/indicator-definitions.json)를 생성하는 명령은 `node scripts/audit_indicators.mjs`입니다.
- 원천 제공 지표는 원천 정의를 표시합니다. 전체 블록체인을 재계산해 원천값을 독립 검증했다는 뜻은 아닙니다. MVRV에서 유도한 실현가치도 독립 근거로 취급하지 않습니다.
- 공급·언락·프로젝트 참고는 제공자와 용도를 표시한 외부 원문입니다. 투자 추천이나 실시간 언락 알림이 아닙니다.

## 운영 범위

변경된 웹/API 정적 파일만 배포합니다. SQLite 스키마, 수집기, 시세 허브, 백업과 예약 작업을 변경하지 않습니다. 원천의 실제 체결 시각과 300초 유효성을 유지합니다. **48시간 대기는 완료 조건에서 제외합니다.** Apple Safari·VoiceOver 실기기 검사는 미검증입니다.

검증·배포 상태와 발견 사항은 [감사 기록](audit-22/README.md)에 구분합니다.
