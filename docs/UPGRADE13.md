# Coin Desk 0.13 — 비트코인 중심의 분석 흐름과 서버 자동 갱신

2026-09-24. 우선순위는 **BTC → DOGE·ETH → 보조 코인**입니다. 기존 8개 코인 접근은 유지하되 신규 범위 확대보다 핵심 3개 코인의 흐름과 검증을 우선했습니다.

## 바뀐 사용 흐름

- 코인을 선택한 뒤 가격·기술적 분석·온체인·선물·도미넌스·리서치·역사를 같은 코인 문맥에서 이동합니다. 코인 변경은 큰 이름·로고 선택기와 BTC/DOGE/ETH 바로가기를 사용합니다. 온체인 원천이 없는 보조 코인은 값 대신 제공 범위를 표시합니다.
- 새 가격 화면은 URL로 기간을 지정하지 않으면 전체 확보 이력에서 시작합니다. 최근 선택했던 짧은 기간을 새 진입에 강제로 적용하지 않습니다. 돌아온 화면은 이미 받은 데이터를 즉시 재사용합니다.
- 도미넌스는 선택 코인의 큰 수치와 차트를 먼저 표시합니다. 다른 코인 비중과 계산 설명은 펼침 영역으로 이동했습니다. 과거 최근 1,000개 제한을 커서 조회로 바꿔 최초 저장 관측까지 표시합니다.
- 역사 메뉴는 비트코인에서 시작합니다. 코인별 원문 확인 사건 28개를 한 연혁으로 관리하며 BTC 반감기 4회, Mt. Gox·FTX·Terra, MicroStrategy, 현물 ETP, DOGE 출시·병합 채굴·Coinbase 발표, ETH DAO·London·Merge 등을 포함합니다. 각 사건에 공식 원문 또는 1차 기록 링크가 있습니다.
- 사건을 누르면 해당 날짜를 표시하고 전후 90일 가격으로 이동합니다. 전체 이력 버튼으로 원래 범위에 복귀합니다. 사건 당시 가격이 원천 확보 범위 밖이면 값을 만들어내지 않습니다. 월 단위 사건은 월 단위라고 표시합니다.
- 리서치는 긴 계정 목록 대신 최근 원문을 먼저 보여줍니다. 공식 소식·분석가·영상·관심 계정을 탭으로 나누며 기본 전체 피드는 BTC/DOGE/ETH와 시장 공통 글을 표시합니다. 특정 코인의 선택과 계정 즐겨찾기는 유지합니다.

## 서버 동작

- Cloudflare Cron은 방문자·PC·Codex 실행과 독립적으로 매분 동작합니다. 핵심 3개 코인 시세 6개 시장은 1분, 보조 5개 코인은 5분 갱신 목표입니다. 시세와 과거 이력·리서치 수집 실행을 분리했습니다. 공유 잠금·실패 백오프가 있으며 정확히 60초마다 성공함을 보장하지 않습니다.
- 공개 출처 42개: 사용자 지정 X 37계정, 공식 RSS 3개, 공개 영상 피드 2개. 고정 URL과 HTTPS 호스트 허용 목록으로 수집하며 같은 출처의 최대 3회 정규 리다이렉트를 허용합니다. 임의 URL·로그인·세션·유료 X API를 사용하지 않습니다. 정상 출처는 약 1시간 주기, 실패는 5분부터 최대 1시간 백오프입니다.
- 수집한 원문 링크·제목·시각·코인 태그만 저장합니다. 공개 HTML의 게시물과 명시된 자산을 읽습니다. 계정 최신 글 전체를 보장하거나 작성자를 인증하지 않습니다. 실패는 명시하고 마지막 성공 메타데이터를 24시간만 피드에 유지합니다.
- 기존 주요 3개 선물 외 보조 5개 선물도 계약 매핑과 실제 첫 페이지를 확보했습니다. 우선순위는 보조이며 수집 주기는 주요 코인보다 낮습니다. 1000PEPE 계약 OI만 ×1,000해 PEPE 수량으로 표시합니다. 펀딩비와 계정 비율에는 이 배수를 적용하지 않습니다.

## 검증 범위

타입검사·프로덕션 빌드, 테스트 **276개 통과**. Decimal 계산 참조·문서 링크·브랜드 자산 검사도 통과했습니다. 기존 테스트에 공개 수집·안전한 리다이렉트·실패 유지·24시간 만료·분 단위 수집·PEPE 단위·1,000개 이후 도미넌스 이력·주요 코인 우선순위 검증을 추가했습니다. 원격 첫 선물 적재는 실제 원천 5,000개 관측이며 중복 행은 보존했습니다. 브라우저에서 BTC 사건 선택 후 180일 구간, 전체 복귀 및 DOGE 전환을 확인했습니다.

자동 수집은 갱신 실행과 원천 성공을 구분합니다. 원천이 중단될 수 있고 X 공개 HTML 변경에 따른 유지보수가 필요합니다. 연혁은 검수한 주요 사건 모음으로 모든 과거 사건을 망라하지 않으며 뉴스 피드와 달리 편집 검수를 거칩니다. 역사 차트의 USD 참조가격과 거래소 KRW/USDT 가격은 별개입니다.
