# 0.33 검증 기록

## 범위

이번 변경은 공개 UI의 운영 메타 정보·날짜 패널·내보내기·공유 제거, 150개 자산의 테마 분류, 확정 일봉 기반 테마 매트릭스입니다. 가격·MVRV·슈퍼트렌드와 비교·저장 흐름을 유지합니다.

내부 데이터의 기준일·시각·출처·검증 상태·오류·수집 기록은 삭제하지 않습니다. 개인 자료와 백업도 보존합니다. 사이트의 간결한 표현을 데이터의 정상 여부나 완전성 주장으로 바꾸지 않습니다.

## 테마와 계산

- 150개 고유 자산에 최소 한 개의 테마를 연결했습니다. 102개는 공식 업비트 분류와 자산·거래쌍 식별을 대조했고, 나머지 48개는 공식 프로젝트·거래소·과거 공식 자료를 대조했습니다.
- 테마 분류의 근거는 편집 분류입니다. 기존 프로젝트·네트워크 사실의 검토 상태를 일괄적으로 `reviewed`로 승격하지 않았습니다.
- BEAM의 게임 자산과 동명 프라이버시 자산, NEXO의 중앙화 플랫폼, FTT의 과거 거래소 관계, ONDO와 수익청구권 자산의 차이를 구분했습니다.
- 일별 8개 연속 확정 관측으로 7일 가격 변화를 계산합니다. 마지막 거래량을 앞선 7개 거래량 중앙값과 비교합니다. 서로 다른 코인의 수량을 합산해 거래대금으로 만들지 않습니다.
- 테마의 x와 y는 각 구성 코인 좌표의 중앙값입니다. 두 좌표의 중앙값은 서로 다른 구성원에서 유래할 수 있으므로 지수·대표 코인·공통 매매 신호로 해석하지 않습니다. 화면에 중앙값과 사용 종목 수를 표시합니다.
- 결측·중복·잘못된 원천·미확정 봉·거래량 기준 0은 제외합니다. 없는 값을 0으로 채우거나 보간하지 않습니다. 테마 분류 완성은 150개 전체 가격 이력·온체인 완성을 뜻하지 않습니다.

## 첫 브라우저 실행과 수정

첫 표적 Chromium 실행은 35개 중 31개 통과·4개 실패였습니다. 실패는 삭제된 설명 절 이름, 실제 시장 버튼 이름과 불일치한 선택자, 설명창 종료 전 느슨한 정규식이 열기·닫기 두 버튼을 잡은 문제였습니다. 정확한 버튼과 닫힘·초점 복귀를 검사하도록 맞췄습니다. 첫 실행 중 사전 소스의 잔여 문구가 갱신된 구간도 있으므로 이를 완전히 동결된 최종 실행으로 합산하지 않습니다.

후속 전체 실행은 390개 중 355개 통과·33개 실패·개인 경로 opt-in 2개 제외였습니다. 실패와 trace는 `work/browser-checks/1791910610549-241480`에 보존합니다. 알려진 실제 결함은 모바일 지연 행의 높이 76.890625px, 비상호작용 지연 표시의 클릭 스타일, 값이 아직 없는 `NO_DATA` 응답을 일반 오류로 표시한 경우, 미지원 지표의 중복된 이름·잘못된 조사입니다. 목표 높이·글자·터치 크기·300초·재시도 조건을 완화하지 않고 표시를 수정합니다.

그 외 실패는 삭제된 시장 선물 링크·문구·신호 안내를 기대한 기존 검사, 생략 가능한 기본 주봉을 URL에 반드시 쓰도록 기대한 검사, Escape 종료 전 중복 선택자, 자동 갱신 fixture가 기준값을 읽기 전에 이미 변경된 문제였습니다. Home/End 기본 문서 스크롤 뒤에 초기 배치 검사를 반복한 경우에는 원래 화면 위치를 복원합니다. 단위·독립 계산·정확한 원천 요청·기존 날짜·줌·저장·실제 갱신 검사는 유지합니다. 수정 뒤 검사는 별도로 기록합니다.

독립 코드 검토에서 테마의 대체 거래소가 표시되지 않는 문제와 조회 실패 후 목록에 이전 수치가 남는 문제도 찾았습니다. 구성원 링크에 다른 거래소를 표시하고 실패 동안 그래프·상태·수치를 함께 제거합니다. 새 회귀 두 건은 두 엔진에서 통과했습니다.

실제 Chrome 로컬 확인에서는 데이터·선택 상태를 DOM으로 확인했으나 일부 `Page.captureScreenshot`이 5초 시간 초과했습니다. 한 크기 변경 직후 캡처는 갱신된 DOM 크기와 맞지 않아 시각 배치 통과 근거로 사용하지 않습니다. 원인을 확정하지 않으며 최종 운영 화면 확인은 별도로 수행합니다.

이후 저장된 Chromium 화면도 직접 검토해 점이 그래프 왼쪽 위에 배치되는 실제 결함을 확인했습니다. 공통 `[role='button']`의 `transform:none`이 SVG `g`의 좌표 변환을 덮어쓰고 있었습니다. 일반 버튼의 고정 위치 규칙에서 SVG를 제외했습니다. 위 Chrome 캡처의 점 배치 문제를 단순한 캡처 지연이라고 확정하지 않습니다. 캡처 시간 초과 자체의 원인은 여전히 별개입니다.

속성만 보던 회귀에 실제 화면 좌표 대조를 추가했습니다. SVG 기준 좌표와 그려진 원의 중심이 1px 이내로 일치해야 합니다. 상단 영역 이름도 관측점과 겹치지 않도록 그래프 밖에 배치했습니다. 시장·테마 36개 검사가 통과했고, 320~1920px·두 테마·두 엔진의 실제 좌표·영역 이름 배치 14개도 모두 통과했습니다. 마지막 화면을 다시 열어 배치를 확인했습니다. 이 결함을 포함한 변경 뒤의 새 PR·main CI만 배포 근거로 사용합니다.

후속 표적 검사는 76개 중 71개 통과·5개 실패였습니다. 남은 실패는 지연 행의 CSS 특이도, 단위가 포함된 RSI 텍스트를 숫자로 파싱한 검사, native End 스크롤과 초기 배치 검사 순서였습니다. RSI는 숫자와 단위를 나누고 독립 계산을 유지했습니다. 두 테마의 초기 배치 검사를 먼저 수행한 뒤 실제 키보드 조작을 검사합니다.

다음 40개 표적 검사는 38개 통과·지연 행 2개 실패였습니다. `display:block`은 적용됐지만 지연 문구의 1px 여백이 다른 규칙 때문에 남아 있었습니다. 원래 규칙의 대상 범위를 정확히 바꾸고 여백 0·행 76px 상한을 그대로 대조했습니다. 값·글자 크기·터치 크기와 합격선을 완화하지 않았습니다.

독립 최종 검토에서 현재가 조회 실패도 ‘연결 중’으로 남는 문제를 발견했습니다. 실제 로딩과 조회 실패·가격 부재를 구분하도록 수정했습니다. 마지막 공개 흐름·시장 검사 24개는 Chromium·WebKit 모두 재시도 없이 통과했습니다(53.6초). `/`와 `/coins` 검색·키보드·한글 별칭·필터 복원, 지연 표시, 최근값·설명·비교·확대·저장·다시 열기 및 이전 날짜 URL의 내부 보존을 포함합니다. 이 결과는 전체 CI나 운영 배포를 대신하지 않습니다.

## 외부 조건과 잔여 범위

디스크 여유 8GiB 보호에 걸린 전체 과거 이력 채우기를 UI 개편으로 해결했다고 표현하지 않습니다. 이미 확인된 최신 관측과 가장 오래된 실제 이력의 범위를 구분합니다. 실제 Apple Safari·VoiceOver와 사람 대상 사용성 검사는 별도 미검증입니다. 이번에 48시간 대기를 추가하지 않습니다.

배포는 변경된 API·웹만 대상으로 하며 기존 DB·수집기·시세 허브·예약 작업과 다른 VPS 프로젝트를 보존합니다. 검증된 CI 이미지와 정적 자산, 백업·복원·롤백 게이트를 통과한 결과만 배포 완료로 기록합니다.
