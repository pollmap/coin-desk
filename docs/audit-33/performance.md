# 0.33 성능 측정

**Pages의 LCP는 목표를 통과했고, VPS 직접 주소는 p95 2,928ms로 2.5초 목표에 미달했습니다.** 중앙값이 개선됐어도 전체 성능 목표를 통과한 것은 아닙니다. 아래는 기존 측정 파일의 집계이며, 새 측정·제품 수정·자동 재시도·기준 완화는 하지 않았습니다.

| 공개 주소 | 새 문맥 | LCP 중앙값 | LCP p95 | 첫 숫자 가격 p95 | LCP 2.5초 |
|---|---:|---:|---:|---:|---|
| Pages | 20회 | 356ms | 456ms | 1,616.5ms | 통과 |
| VPS | 20회 | 2,204ms | 2,928ms | 3,379.6ms | 미달 |

Windows Chromium 153.0.8010.12, 1280×800, 다운로드 10Mbps·업로드 5Mbps, CPU 배율 1, 브라우저 캐시 사용 안 함, 서비스 작업자 차단 조건입니다. CDN·OS의 DNS·TLS 캐시는 초기화하지 않았습니다. 0.32와 브라우저·제한 조건은 같지만 측정 시간대와 공유 환경까지 같지는 않습니다.

VPS의 0.32→0.33 LCP 중앙값은 **2,340→2,204ms**, p95는 **2,580→2,928ms**입니다. 느린 표본에서 첫 응답과 탐색 완료도 늦어졌지만 전송량 급증은 관측되지 않았습니다. 네트워크·DNS·TLS·정적 파일·API·VPS 처리 중 어디가 원인인지는 확정하지 않았습니다. 측정 PC 전체 CPU를 VPS 또는 브라우저 단독 CPU로 해석하지 않습니다.

가격 변경의 **허브 수신→DOM 반영** p95는 Pages 1,329.5ms·VPS 1,272ms이며, 시계 오차를 더한 보수 상한은 각각 **1,705ms·1,602ms**입니다. 실제 표시가 바뀐 표본은 38개·58개였습니다. 이는 물리적 화면 그리기나 거래소 이벤트→화면 지연이 아닙니다. 첫 숫자 가격·HTTP 200·LCP만으로 실제 체결의 신선도를 입증하지 않으며, 300초 기준은 유지했습니다.

| SSE 집단 | 최대 동시 연결 | 정상 주 연결 | 구독 변경 재접속 | steady 100명 | 허브→클라이언트 p95 / 오차 포함 상한 |
|---|---:|---:|---:|---:|---:|
| 첫 시험 | 100 | 100/100 | 10/10 | 60.010초 | 1,270 / 1,650ms |
| 자원 관측 보완 시험 | 100 | 100/100 | 10/10 | 60.002초 | 1,149 / 1,547ms |

각 집단은 150개 자산·실제 지원 거래소 조합 241개를 구독했고, 클라이언트당 최대 50개 자산을 사용했습니다. 각 110개 연결의 HTTP 200·정상 종료, 오류 0·자동 재시도 0, 시험 도구의 직접 API 서버 쓰기 0을 확인했습니다. 두 번째 집단은 첫 시험의 누락된 자원 관측을 보완하는 별도 시험입니다. 고유 체결 수와 지연 표본을 두 집단 간 합산하지 않습니다. SSE 전달 표본은 같은 체결을 여러 클라이언트에서 포함할 수 있고, 이 시험도 거래소→화면 지연은 측정하지 않았습니다.

자원은 읽기 전용으로 **182.258초 동안 13개 표본**을 얻었습니다. 전체 구간의 API Node RSS는 **173,494,272B로 일정**, 시세 허브 Node RSS는 **77,312,000→78,114,816B**였습니다. 컨테이너 메모리는 RSS와 별도 지표입니다.

**13개 중 두 번째 steady 100명 구간과 확실히 겹친 자원 표본은 2개뿐입니다.** VPS−측정 PC 시계 차이 +906±398ms를 적용한 보수 교집합은 19:41:02.085–19:42:01.291 UTC이고, 해당 표본은 19:41:40·19:41:55 UTC입니다. 이때 API RSS 173,494,272B·허브 RSS 77,312,000B였습니다. 전체 182초를 100명 부하로 표현하거나 첫 시험에 소급하지 않습니다. 짧은 표본은 장기 메모리 누수 없음 또는 해결의 증거가 아닙니다.

자원 도구의 최초 실패 3개는 보존했습니다: 필수 이름 인수 누락, 로컬 Docker ENOENT, 원격 comm=node 필터의 NODE_PROCESS_NOT_FOUND입니다. 실행 파일 기반 식별과 시작 시각·cgroup 보호 검사 6개를 통과한 뒤 위 13개 표본을 얻었습니다. 제품 코드는 변경하지 않았습니다.

VPS LCP 목표 미달과 원인 미확정은 남아 있습니다. 완전한 과거 이력, 실제 Safari·VoiceOver, 사람 5명의 사용성 검사는 미검증입니다. 48시간 대기는 완료 조건에 넣지 않습니다. 원시 회차·로그·헤더·내부 경로·개인정보는 공개 집계에서 제외했습니다. 측정 근거의 파일명과 해시는 같은 폴더의 performance.json에 기록했습니다.
