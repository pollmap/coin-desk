# 서버 자동 수집·시세 조회 수정

2026-09-23 KST. 서버 Cron은 중단되지 않았으며, 점검 당시 실제 거래소 일봉은 9월 23일, BTC·ETH 등의 일별 온체인은 9월 22일까지 수집됐습니다. DOGE·LINK 일부는 6시간 수집 주기의 다음 작업을 기다리고 있었습니다. 일별 관측일과 수집 성공 시각을 구분합니다.

## 수정한 문제

- 서버가 새로운 시세를 저장해도 별도의 30초 엣지 캐시에 이전 지연 응답이 남을 수 있었습니다. `overview`는 최신 DB 스냅샷을 읽도록 변경했습니다. 거래소 호출의 공유 lease·180초 최소 갱신 간격은 유지해 외부 호출 폭증을 방지합니다.
- 수집 작업이 조회 도중 갱신 권한을 획득하면, 조회가 처음 읽은 오래된 스냅샷을 그대로 반환할 수 있었습니다. 오래된 스냅샷은 반환 전 다시 조회합니다. 아직 저장되지 않은 새 값을 생성하지 않습니다.
- D1 쓰기 한도 때문에 갱신 lease나 오류 기록 쓰기가 실패하면 저장된 시세를 읽을 수 있어도 HTTP 503이 됐습니다. 쓰기 실패를 격리하고 기존 값을 지연 표시와 함께 반환합니다. 기술지표 결과 캐시의 쓰기도 조회 성공의 필수 조건에서 제외했습니다. DB 읽기까지 불가능한 경우에는 오류가 남을 수 있습니다.

## 2026-09-25 추가 보강

- 시세 조회 경로에서 D1 lease/저장 쓰기가 실패해도 거래소 원천을 한 번 직접 조회하도록 보강했습니다. 조회가 성공하면 거래소 가격과 “서버 자동 저장 지연” 안내를 함께 반환하며, 원천도 실패하면 마지막 영구 저장값을 유지합니다. 10초 엣지 캐시로 연속 방문의 중복 원천 호출을 줄입니다. 이는 차트 이력이나 백그라운드 수집을 복구하지 않습니다.
- 시세의 `stale` 판정은 저장 오류가 아니라 실제 관측 시각을 기준으로 합니다. 새 시세가 도착했지만 저장만 실패한 경우에는 현재가를 오래된 데이터로 잘못 표시하지 않습니다.
