# 0.18 · 리본 설정과 개인 자료 검토

차트에서 이동평균 리본을 조절하고, 개인 자료를 검색한 뒤 미검토 항목부터 읽고 같은 봉 간격의 차트로 연결합니다. 이번 변경은 웹과 로컬 Chrome 확장에 한정합니다. 서버 수집 Worker·D1 스키마·엄격한 관찰 기준은 변경하지 않습니다.

## 사용 흐름

- 가격·기술 → 이동평균 리본 → **리본 설정**. SMA/EMA와 2~10개 기간을 선택합니다. 기본 SMA 7·25·50·100, 장기 SMA 20·50·100·200, 빠른 EMA 8·13·21·34·55·89를 제공합니다. 일·주 기준의 기존 이동평균과 오실레이터를 유지하며 총 지표 수는 10개 이내입니다.
- 리본의 각 선은 다른 색과 기간 이름으로 구분합니다. 확정 종가·선택 봉 기준이고 결측에서 계산을 다시 시작합니다. 설정 변경 때 날짜 구간을 유지하고 기존 URL·작업공간 저장으로 복원합니다.
- 개인 자료함에서 작성자·코인·방법·여러 검색어·검토 상태를 조합합니다. 방향키/Home/End/PageUp/PageDown으로 가상 목록을 탐색하고 이전·다음 자료로 검토를 이어갑니다. 빈 결과는 별도 상태로 읽힙니다.
- 이미지 검토율의 분모는 이미지가 있는 자료입니다. 본문·이미지·방법 검토를 자동으로 완료 표시하지 않습니다. 확인 체크는 즉시 반영하되 저장 실패 시 이전 상태로 되돌립니다.
- 개인 자료의 차트 연결에 일·주·월 등 **봉 간격**도 보관합니다. USD 참조는 실제로 없는 시간봉을 허용하지 않습니다. 원문과 선택 원천의 차이를 유지합니다.

## 수집·보존 수정

- 자료함은 확장의 응답을 받아야 연결을 확인합니다. 응답이 없으면 8초 후 설치·새로고침 안내를 표시합니다. 다른 nonce·탭·원천의 전송을 허용하지 않습니다.
- 실제 로그인 X에서 북마크의 `/i/history` 이동을 확인했습니다. 북마크 모드와 화면의 선택된 **북마크** 탭이 모두 맞아야 읽습니다. 다른 기록 탭을 읽지 않습니다.
- 인용 글의 본문·이미지를 원 게시자의 자료로 합치지 않습니다. 저장 확인 뒤에만 게시물을 처리된 것으로 기록하며 새 목록 실행 시 이전 구성원 집합을 비웁니다.
- 접힌 본문이 기존 전체 본문의 앞부분일 때, 재수집으로 전체 본문·검토 상태·로컬 이미지 경로를 덮어쓰지 않습니다. 실제 수정 글은 기존 변경 이력으로 남깁니다.
- 업데이트 시 기존 확장을 삭제하지 말고 새로고침합니다. [설치·업데이트 안내](../extension/README.md).

## 성능과 검증 기준

검색 텍스트 정규화와 날짜 정렬을 색인 생성 때 수행합니다. 검색 작업에는 이미지·변경 이력 대신 필요한 필드만 보냅니다. 스크롤 때 목록 통계를 재계산하지 않고, 주석이 없는 차트의 커서 이동에서 주석 컴포넌트를 다시 그리지 않습니다. 주석 갱신은 프레임 단위로 합칩니다.

기존 보관 6,227건·검색 400회씩 5회, 워밍업 후 중앙값은 기존 5,710.89ms → 1,274.64ms로 **검색 계산 약 4.48배 개선**입니다. 10개 단일 검색어의 결과 집합은 일치합니다. Windows 로컬에서 다른 검사도 실행된 환경이며 메시지 전송·디스크·화면 렌더링을 제외한 계산 측정입니다. 전체 페이지 속도 배율로 해석하지 않습니다. [측정 기록](audit-18/search-performance.json).

검사 범위는 타입·계산·복구, Chromium/WebKit, 날짜 복원·원천 변경·캔들 확정·신호 중복, 수집 중단·재개·잘못된 대상·할당량 실패, 320/390/768/1000/1280/1440px·양 테마·키보드·200% 확대·axe입니다. [검증 현황](audit-18/README.md).
