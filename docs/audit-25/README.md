## 발견 사항과 처리

- 8개 고정 자산 목록, 원천 선택·검색·API·수집·스트림 경로를 공통 레지스트리로 변경했습니다.
- ETH 검색에서 ETHFI까지 일치해 Enter가 작동하지 않던 문제를 수정했습니다. 정확한 티커가 먼저 나오며 Enter는 첫 결과를 엽니다.
- 모바일 상대강도 차트 상단이 294px까지 밀리던 문제를 설명 패널 분리로 수정했습니다.
- 긴 한국어 종목명에서 모바일 행이 83px까지 늘어나던 문제를 말줄임과 전체 접근성 이름 유지로 수정했습니다.
- WebKit에서 갱신 지연 문구가 붙으면 모바일 행이 83px로 커지던 경우도 재현했습니다. 지연 문구는 보존하고 가격·상태·등락의 줄 간격을 조정했습니다.
- 기존 테스트의 8개/5원천/5테마·상시 도움말·이전 버튼 이름 가정은 변경한 실제 계약에 맞게 수정했습니다. 원천 혼입·보존 검사는 유지했습니다.
- 개발 중 전체 브라우저 실행에는 HMR 변경이 섞였습니다. 해당 실행은 최종 합격 증거로 사용하지 않습니다. 별도 고정 소스 검사와 원격 CI로 판정합니다.
- 초기 격리 DB 검증은 파일별 트랜잭션이 없어 느려 중단했습니다. 미완료 파일을 보존하고 새 격리 DB에서 다시 실행해 원문 전체 대조를 완료했습니다.
- SHIB 계약 추가 직후 오래된 로컬 서버 빌드가 400을 반환했습니다. 서버 빌드를 갱신한 뒤 다섯 선물 원천을 모두 수집했습니다. 운영 장애가 아닙니다.
- 이관 도구가 검증 실패 경로에서 SQLite 연결을 닫지 않아 Windows 임시 파일 정리가 실패한 문제를 수정하고 재검증했습니다.
- VPS 후보 서버의 읽기 전용 복사본은 WAL 보조 파일이 없어 처음 열기에 실패했습니다. 운영 DB는 변경하지 않고 격리된 복사본만 읽기 전용 배포에 맞는 저널 모드로 전환해 재검사했습니다.

원시 공개 응답과 개인 자료는 `work/`에 보존하며 커밋하지 않습니다. 이 문서에는 비밀정보·개인 원문이 없습니다.
