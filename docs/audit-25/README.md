## 운영·성능 판정

[자연 갱신](natural-cron.json)은 직접 수집 API와 overview를 호출하지 않은 읽기 전용 SELECT 비교입니다. 1,897초 동안 시세 확인 230개, 가격 원천 463개, 선물 13개, 온체인 3개, 참조가격 2개가 증가했습니다. 기존 16개 시세의 실제 체결·확인 시각 모두 증가했고 신규 시세 스냅샷 214개가 생성됐습니다. 네 실행 경로가 각각 31회 완료했습니다. 다른 방문자 부재나 모든 6시간 작업의 자연 실행까지 증명한 것은 아닙니다.

[운영 상태](operating-status.json)는 활성 원천만 분모에 포함하며 HTTP 503도 그대로 보존합니다. 최종 Pages 표본은 활성 1,585개 중 정상 1,530·지연 12·오류 31·미확보 12입니다. 시세 외에는 KAIA 업비트 확정 일봉만 미확보이며, 초기 시간봉 지연은 예약 수집으로 회복했습니다. 일부 업비트 종목의 원천 실제 체결이 300초를 넘는 것을 [원천 응답](quote-source-diagnostic.json)과 대조했습니다. 오래된 체결과 수집 재시도 상태를 정상으로 바꾸지 않았습니다.

[150개 가격 연결 대조](stream-price-coverage.json)는 공개 SSE의 첫 스냅샷을 읽은 결과입니다. 가격을 표시할 수 있다는 것과 300초 이내 새 체결이 있다는 것은 다릅니다. 신규 일부 저유동성 종목의 분 단위 검증 스냅샷이 없어도 스트림의 마지막 실제 가격과 체결 시각을 확인할 수 있으며, 신선한 가격으로 바꿔 표시하지 않습니다.

## 남은 제한

- VPS 직접 주소의 첫 로딩 p95 2.5초 목표는 미달입니다. 대표 Pages 주소는 통과했습니다.
- 저유동성 종목의 원천 체결 지연과 아직 실행 시각이 오지 않은 6시간 온체인·참조가격 작업을 전부 정상·자연 갱신 완료로 표현하지 않습니다. 초기 시간봉 따라잡기는 최종 표본에서 회복했습니다.
- 150개 모두가 MVRV·온체인·선물을 지원하는 것은 아닙니다. 실제 연결은 온체인 34개, MVRV 33개, Bybit 계약 136개입니다. 최근 선물 확보와 전체 과거 선물 확보도 구분합니다.
- 공식 프로젝트 관계는 검토한 13개만 연결했습니다. 전 종목 계약 주소·테마 관계 검토 완료가 아닙니다.
- 실제 Apple Safari·VoiceOver와 사람 대상 사용성 검사는 미검증입니다. 48시간 대기는 다시 추가하지 않았습니다.

## 발견 사항과 처리

- 8개 고정 자산 목록, 원천 선택·검색·API·수집·스트림 경로를 공통 레지스트리로 변경했습니다.
- ETH 검색에서 ETHFI까지 일치해 Enter가 작동하지 않던 문제를 수정했습니다. 정확한 티커가 먼저 나오며 Enter는 첫 결과를 엽니다.
- 모바일 상대강도 차트 상단이 294px까지 밀리던 문제를 설명 패널 분리로 수정했습니다.
- 긴 한국어 종목명에서 모바일 행이 83px까지 늘어나던 문제를 말줄임과 전체 접근성 이름 유지로 수정했습니다.
- WebKit에서 갱신 지연 문구가 붙으면 모바일 행이 83px로 커지던 경우도 재현했습니다. 지연 문구는 보존하고 가격·상태·등락의 줄 간격을 조정했습니다.
- 기존 테스트의 8개/5원천/5테마·상시 도움말·이전 버튼 이름 가정은 변경한 실제 계약에 맞게 수정했습니다. 원천 혼입·보존 검사는 유지했습니다.
- 개발 중 전체 브라우저 실행에는 HMR 변경이 섞였습니다. 해당 실행은 최종 합격 증거로 사용하지 않습니다. 별도 고정 소스 검사와 원격 CI로 판정합니다.
- 초기 격리 DB 검증은 파일별 트랜잭션이 없어 느려 중단했습니다. 미완료 파일을 보존하고 새 격리 DB에서 다시 실행해 원문 전체 대조를 완료했습니다.
- SHIB 계약 추가 직후 오래된 로컬 서버 빌드가 400을 반환했습니다. 서버 빌드를 갱신한 뒤 다섯 선물 원천을 모두 수집했습니다. 운영 장애가 아닙니다.
- 이관 도구가 검증 실패 경로에서 SQLite 연결을 닫지 않아 Windows 임시 파일 정리가 실패한 문제를 수정하고 재검증했습니다.
- VPS 후보 서버의 읽기 전용 복사본은 WAL 보조 파일이 없어 처음 열기에 실패했습니다. 운영 DB는 변경하지 않고 격리된 복사본만 읽기 전용 배포에 맞는 저널 모드로 전환해 재검사했습니다.
- 운영 DB 복사본의 전 종목 HTTP 대조에서 XRP 블록 수·LINK 신규 발행량이 비어 있음을 발견했습니다. 기존 코인의 새 지표까지 제외하던 이관 조건을 수정해, 기존 값은 보존하며 새 지표의 과거 관측만 추가하도록 했습니다.

원시 공개 응답과 개인 자료는 `work/`에 보존하며 커밋하지 않습니다. 이 문서에는 비밀정보·개인 원문이 없습니다.

- 실제 PENGU 화면에서 최근 체결이 300초를 넘고 분 단위 저장값이 아직 없으면 가격을 지우던 문제를 수정했습니다. 마지막 실제 가격과 지연 표시를 함께 유지하며, 300초 유효성이나 체결 시각은 변경하지 않습니다. 단절·오래된 체결·다른 거래소 혼입을 회귀 검사했습니다.
- 원격 CI 37959320897은 브라우저 181개 통과·5개 실패·개인 경로 2개 제외였습니다. Linux WebKit의 지연 행 높이 79.89px를 확인해 행의 세로 여백을 줄였습니다. 나머지 두 실패는 단절 시 과거 분 가격으로 되돌리기를 기대하던 검사였으며, 마지막 실제 체결값 보존·지연 표시·재연결 후 갱신을 검사하도록 수정했습니다. 행 높이 76px와 300초 신선도 조건은 유지합니다.
- 저장 공간 보호가 초기 대량 확보 도구에만 적용된 것을 확인했습니다. VPS의 여유 공간이 2GiB 미만이거나 용량 조회에 실패하면 과거 수집을 멈추고 최신 관측 확인은 유지합니다. 가격·참조가격·온체인·선물 체크포인트를 보존하고 공간 회복 시 이어가며 기존 자료를 삭제하지 않습니다. 운영 API는 과거 수집 중지 상태를 별도로 제공합니다.
- 선물 과거 수집 예산 소진 시 핵심 세 코인 외의 최근값 확인까지 다음 UTC 날로 미뤄질 수 있던 경로를 수정했습니다. VPS는 기존 이력이 있으면 최근 구간을 별도로 확인하고, 과거 체크포인트·10,000행 예약 한도는 보존하며 최대 6시간 뒤 다시 확인합니다.
