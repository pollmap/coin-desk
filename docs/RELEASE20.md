# Coin Desk 0.20 — 지표를 바로 보고 이해하기

첫 진입을 **BTC MVRV · 최근 5년**으로 바꿨습니다. 가격 대시보드와 분석 영역 선택을 거치지 않고 왼쪽 목록에서 고른 지표가 주 차트가 됩니다. 웹 변경이며 원천 수집 Worker, 상태 API, D1 0009 스키마, Chrome 확장은 이번 변경 대상이 아닙니다.

## 사용 흐름

1. BTC·DOGE·ETH·SOL·XRP·LINK·ONDO·PEPE를 전환합니다.
2. 가치·사이클 / 온체인 / 선물 / 기술·성과에서 지표를 선택합니다. 모바일은 검색 가능한 선택 창을 씁니다.
3. 확정값·기준일·원천을 보고 날짜를 탐색합니다. 가격 비교는 기본적으로 꺼져 있으며 켜면 별도 패널에서 날짜축과 커서를 맞춥니다.
4. 읽는 법·계산식·원천·한계를 차트 아래에서 펼칩니다. 상세 사전에는 차트를 자동으로 다시 띄우지 않습니다.
5. 더보기에서 가격 기준·봉·리본·보조 지표 두 개·주석·패턴·관련 자료에 접근합니다. 공유와 기기 저장은 기존 기능을 유지합니다.

기본 기간은 MVRV·주요 온체인 5년, 선물 3개월, RSI·리본·볼린저·낙폭·상대강도 1년, 두 밴드·계절성 전체입니다. 명시적 URL·저장 구성·날짜 범위를 먼저 복원합니다. 전체 기간·직접 확대·공유 범위는 지연 응답, 크기 변경, 자동 갱신 및 가격·보조 비교 추가 후에도 유지합니다.

## 지원과 실제 확보 상태

| 코인 | 장기 USD·MVRV | 가격 기반 분석 | 선물 |
|---|---|---|---|
| BTC | Coin Metrics, BTC 전용 Bitview 지표 | 위치 밴드, BTC 로그회귀 레인보우, 기술 분석 | 기존 Bybit |
| DOGE·ETH·XRP·LINK | 카탈로그에 정의된 Coin Metrics 지표 | 위치 밴드·기술 분석 | 기존 Bybit |
| SOL·ONDO·PEPE | 현재 MVRV·USD 참조 미지원 | 기본 Binance USDT·기술 분석 | 기존 Bybit |

지원은 데이터가 충분하다는 뜻이 아닙니다. 정상·지연·미지원·이력 부족·수집 대기·오류를 구분하며 없는 관측을 만들지 않습니다. 미지원 MVRV 코인으로 전환하면 RSI 14와 지원 가격 기준으로 이동하고 이유를 표시합니다. 직접 입력한 미지원 링크는 이유와 대안을 보여주며 요청·반복 재시도를 시작하지 않습니다. ONDO의 도움말은 ONDO를 유지합니다.

선물은 Bybit 한 거래소의 계약입니다. PEPE의 `1000PEPEUSDT` 미결제약정은 계약 수량에 1000을 곱해 PEPE 단위로 표시하는 기존 변환을 유지하며 회귀 검사를 실행합니다. 펀딩률·계정 비중은 %입니다. USD·USDT·KRW, 코인 수량과 체인 TVL의 USD 평가액을 같은 축에 섞지 않습니다. BTC 대비 비율은 **자산 가격 / BTC 가격**, 동일 원천·통화·날짜 기준입니다.

## 서로 다른 두 밴드

### 가격 위치 밴드

표시일 이전 **연속 730일** 로그가격의 평균 μ와 모집단 표준편차 σ를 씁니다. 경계는 `exp(μ+kσ)`, k는 `−2, −1.3, −0.55, 0.55, 1.3, 2`이며 위치는 `(ln(P)−μ)/σ`입니다. 표시일 가격은 통계 창에 포함하지 않습니다. 누락일 다음에는 연속 이력을 다시 쌓고 σ=0이면 위치를 계산하지 않습니다. 가격과 앞선 730일이 없으면 부족한 이력을 표시합니다.

### BTC 레인보우 — Coin Desk 로그회귀

BTC USD 일별 참조가격만 씁니다. 다른 서비스의 비공개 계수나 매수·매도 구간을 재현한 차트가 아닙니다. 공개 [BlockchainCenter 설명](https://www.blockchaincenter.net/bitcoin-rainbow-chart/)과 [CoinGlass의 별도 API](https://docs.coinglass.com/reference/bitcoin-rainbow-chart)를 참고해 계산 규칙을 자체 정의했습니다.

- x=`ln(2009-01-03 이후 경과일)`, y=`ln(USD 가격)`.
- 표시일 **이전** 유효 일별 관측 730개 이상으로 최소제곱 `y=a+bx`를 계산합니다.
- 모집단 잔차 표준편차는 `sqrt(max(0,(Syy−bSxy)/n))`입니다.
- `exp(a+bx+kσ)`에서 k=`−2.25,−1.75,…,2.25`인 10개 경계가 9개 색상 구간을 만듭니다.
- 누적 평균·중심 제곱합을 갱신하므로 처리량은 관측 수에 비례합니다. 결측 가격을 채우지 않으며 미래 날짜로 연장하지 않습니다.
- 실제 가격은 밴드 밖에서도 보입니다. 날짜별 계수, 표본 수·기간, 계산 버전 `coin-desk-expanding-log-regression-v1`을 표시합니다. 평탄한 가격은 위치를 계산하지 않습니다.

두 밴드는 Lightweight Charts의 같은 날짜 탐색·커서·로그축·주석 도구를 사용합니다. 색상은 위치 구분이며 투자 지시가 아닙니다.

## 구조와 호환

`shared/indicator-catalog.ts`가 분류·지원 자산·기본 기간·단위·원천·기준선·사전 연결을 정의합니다. 동일 개념의 Coin Metrics/Bitview 지표는 원천 선택으로 묶습니다. `src/IndicatorWorkspace.tsx`는 선택 지표와 켠 비교만 요청합니다. 관련 자료·고급 분석은 지연 로드하며 알림함도 열 때 API를 요청합니다. 페이지별 기존 데이터 캐시·페이지 조회·응답 취소가 코인별 오류 전파를 막습니다.

`metric`을 주 지표 키로 사용합니다. 기존 `/onchain`, `/futures`, `/chart`, `/metrics/:metric`, `visual`, `panels`와 작업공간 버전 1·2를 읽을 수 있습니다. 옛 BTC 지표 링크도 동일한 작업공간을 열며 가격 비교를 자동으로 켜지 않습니다. 기존 자료 연결에 지표 키를 추가했고 보조 지표는 최대 두 개를 복원합니다. 기존 기술 도구의 상세 화면은 더보기에서 접근할 수 있습니다. 개인 글·이미지·메모를 공유 URL이나 배포물에 넣지 않습니다.

초기 수집 응답 `NO_DATA`는 수집 대기로 표시하고 정상 갱신 주기에 다시 확인합니다. HTTP 오류 코드를 보존해 실제 API 오류와 구분하며, 실패 후에도 기존 관측은 유지합니다. 빈 관측을 오래된 정상 자료로 표시하지 않습니다.

차트는 원천·단위·구조가 동일하면 인스턴스를 다시 만들지 않고 시리즈 데이터를 갱신합니다. 가격·다른 단위의 지표를 보조 패널로 분리하고 사용자 구간을 복원합니다. 변경한 화면의 중복 CSS 선언도 통합했습니다.

## 검증과 배포 경계

검사 결과와 실패·수정 이력은 [감사 기록](audit-20/README.md)에 남깁니다. 전체 완료 여부와 남은 관문은 [마감 상태](audit-20/remaining.md)를 기준으로 봅니다. Chromium/WebKit 결과를 실제 Apple Safari·VoiceOver 결과로 표현하지 않습니다. Apple 실기기 검증은 대기 상태입니다. X 전체 수집·개인 자료 전수 검토는 이번 완료 범위가 아닙니다.

웹만 변경됐으므로 CI·병합 후 `npm run build`와 `npm run deploy:pages`만 수행합니다. 수집 Worker와 main Worker 및 원격 마이그레이션을 불필요하게 다시 배포하지 않습니다. 운영 안정성과 계정 전체 하루 D1 비용 확인은 [기존 운영 기록](audit-19/README.md)과 분리해 이어갑니다.
