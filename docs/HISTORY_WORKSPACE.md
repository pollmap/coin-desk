# 사건과 당시 가격을 함께 보는 역사 화면

2026-09-25. BTC 우선, DOGE·ETH 동일 사용 흐름.

## 바뀐 흐름

처음에는 해당 코인의 확보된 전체 가격 이력을 표시합니다. 데스크톱에서 사건 목록과 차트를 나란히 두어 사건을 바꿀 때 페이지 위아래를 반복 이동하지 않습니다. 목록은 연도·사건 검색, 분류, 시장 공통 사건 포함 여부, 시간순 정렬을 지원합니다.

사건을 선택하면 사건일 표식과 전후 90일 구간을 표시합니다. 전후 30일·90일·1년을 선택하거나 이전·다음 사건으로 이동할 수 있습니다. 같은 기간 버튼을 다시 누르면 수동 확대를 사건 구간으로 복원합니다. 사건·기간·로그축·가격 원천은 URL에 남아 공유하거나 다시 열 수 있습니다. 검색으로 목록이 바뀌어도 선택한 사건은 유지됩니다.

USD는 Coin Metrics 전체 참조가격, KRW와 USDT는 각각 Upbit·Binance 실제 거래소 일봉입니다. 원화나 USDT를 선택하면 다른 분석 화면으로 이동할 때도 선택한 거래소를 유지합니다. 코인을 바꾸면 이전 사건을 해제하고 새 코인의 전체 이력으로 시작하되 가격 원천과 축 설정은 유지합니다. 사이드바 역사도 현재 코인을 따릅니다.

## 날짜와 계산

- 사건일 UTC 종가를 기준으로 정확히 7·30·90일 뒤의 같은 원천 종가 변화를 계산합니다.
- 사건일 또는 비교일 관측이 없거나 유효하지 않으면 수치를 표시하지 않습니다. 다음 관측일로 대체하거나 보간하지 않습니다.
- 월 단위 사건은 해당 월 전체와 전후 구간을 표시하며 하루 기준 변화율을 계산하지 않습니다.
- 상장 전·가격 확보 전 사건은 기록 없음 안내와 확보된 전체 이력을 표시합니다. 가능한 경우 더 오래된 USD 원천으로 바로 전환할 수 있습니다.
- 사건과 가격의 동행이 인과관계를 입증하지 않습니다. 원문 링크와 계산 기준은 화면에서 확인할 수 있습니다.

## 검증

- 타입검사와 292개 테스트 통과. 사건일 결측, 비교일 결측, 가격 확보 밖, 최신일 경계, 월 전체 범위·월 중간부터 확보된 기록을 포함합니다.
- 기존 API 테스트가 실제 거래소 접속 결과에 의존하던 문제를 수정했습니다. D1 쓰기 한도 초과 시 원천 성공/실패, 저장된 시세 유무를 각각 고정된 응답으로 검증합니다.
- 브라우저: BTC FTX 전후 90일·30일, 원화 전환, 검색 중 사건 유지, 2012년 반감기의 Upbit 기록 없음과 USD 전환, DOGE 전체 이력·Terra 월 단위 사건, ETH 전체 이력·Merge를 확인했습니다.
- 로그축, 다크·라이트 테마, 코인 전환, 가격 원천 표시와 출처를 점검했습니다. [ETH 밝은 화면](history-workspace/eth-merge-light.png).
- 서버 상태의 롱 계정 비율과 일별 선물 데이터 이름을 바로잡았습니다.
