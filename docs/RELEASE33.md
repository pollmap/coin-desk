# 0.33 — 테마 흐름과 집중 차트

공개 화면에서 수집 시각·원천 상태·계산 버전·데이터 정보, 차트 내보내기·공유·날짜별 수치 패널을 제거합니다. 정상 화면은 코인·지표·값·기간·차트·비교·저장에 집중합니다. 차트 안의 기본 탐색 툴팁에는 값과 단위만 표시합니다. 사용자 자료의 백업과 복원은 보존합니다.

150개 자산에 31개 테마를 연결합니다. 테마 화면은 7일 가격 변화와 거래량 배수의 매트릭스 및 선택 가능한 목록으로 구성합니다. 한 페이지에는 최대 12개 점을 표시하고, 페이지를 바꿔도 전체 축 범위는 유지합니다. 모바일에서는 선택한 점의 이름만 표시합니다.

테마 좌표는 구성 코인들의 각 좌표 중앙값입니다. 거래량 배수는 같은 코인의 마지막 확정 일봉 거래량을 앞선 7일 거래량 중앙값으로 나눈 값입니다. 거래대금·시장점유율·투자심리 지수가 아닙니다. 상승·조정·거래량 감소는 수치의 영역 표시이며 매매 판단을 생성하지 않습니다.

기존 URL·작업공간 버전·개인 자료·날짜와 확대 범위는 내부에서 보존합니다. 정상 화면에서 날짜를 고정하는 UI는 제거하지만 이전 URL에 명시된 날짜가 저장 과정에서 사라지지 않도록 검사합니다. 실제 체결 시각의 300초 유효성, 결측 처리, 계산 준비 조건 및 원천 격리는 바꾸지 않습니다.

새 `/api/v1/theme-market`은 저장된 확정 일봉만 읽습니다. 시장 홈에서는 조회하지 않고 테마 탭에서만 요청합니다. DB 스키마·수집기·예약 작업은 변경하지 않습니다.

코드·브라우저·CI·배포·실데이터 확인 결과는 [감사 기록](audit-33/README.md)에 나눠 기록합니다. 0.32.2의 별도 배포는 보류하고 해당 모바일 수정을 이번 개편에 포함합니다. 48시간 대기는 완료 조건에 넣지 않습니다.
