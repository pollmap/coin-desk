### 테마 전환 대비 보완

첫 PR의 전체 CI는 통과했으나, 병합 후 main CI `37114563023`에서 WebKit 사전 페이지의 대비 검사 3건이 실패했습니다. [실패·수정 근거](contrast-regression.json)에 남겼습니다. 배경은 어두운 테마로 즉시 바뀌고 summary 글자는 120ms 전환 때문에 이전 색에 머물러 대비가 1.12:1이 됐습니다. `transition: none`으로 바꿔 hover와 테마 색상을 동시에 즉시 적용합니다.

새 회귀 검사는 테마 변경 직후 첫 세 프레임의 설명 버튼 글자색을 확인합니다. 수정 전 Chromium·WebKit 2개 실패, 수정 후 해당 검사와 320·390·768·1000·1280·1440px 양 테마 검사 총 14개가 재시도 없이 통과했습니다. 처음 기존 검사로 로컬 재현을 시도한 결과는 5개 통과·Chromium 프로세스 종료 1개로, 원격 대비 실패와 같은 원인이 아닙니다.
