# 0.21 구현·검증 기록

이하 네트워크 차단·미배포 기록은 이전 단계의 이력입니다. 현재 **CI 통과·운영 D1 최종 이관·VPS HTTPS·분 단위 수집 전환을 완료**했습니다. [실제 연결 증거](live/README.md)를 우선합니다. 300초 자연 갱신 검증과 하루·엄격한 48시간 안정성은 별개이며 후자는 아직 미완료입니다.

## 이전 단계 이력

### 2026-10-03 KST 강아지 복원·1분 수집 보완

기존 시바견 원본을 상단 로고·빈 관심목록·브랜드 소개·다운로드·파비콘·공유 이미지에 복원했습니다. [시장 화면](dog-market.png), [브랜드 화면](dog-brand.png), [실행 상태](dog-runtime.png)는 로컬 과거 캐시로 확인한 화면입니다.

VPS는 여덟 코인 모두 분 단위로 확인합니다. 보조 코인의 300초 제한을 제거하고, 응답이 몇 초 걸려도 다음 분 수집을 건너뛰지 않도록 분 경계로 실행 여부·시세 잠금을 판단합니다. 같은 분 중복·실패 원천 재시도는 유지합니다. 기존 Cloudflare의 핵심 60초/보조 300초 정책과 실제 체결 유효성 300초는 변경하지 않았습니다. 온체인 관측값을 매분 새 값처럼 표시하지 않습니다.

상태 화면은 네 수집 작업과 백업·복원 검사를 표시합니다. 조회 오류를 정상 실행으로 설명하지 않으며, 실행 기록 없음·백업 없음·지연을 분리합니다. 밝은 테마의 정상 표시 대비와 좁은 화면의 제목·버튼 배치도 수정했습니다. 로컬 읽기 API의 양 거래소 16개 시세 목표 60초를 확인했지만 수집 실행 기록은 없었습니다. [API 증거](local-runtime-proof.json).

검증: 타입·단위 486개, Node 서버 13개, VPS Python 7개, 복구 2개, 웹 빌드·브랜드 메타데이터 통과. 브라우저 전체 실행은 129개 통과·1개 실패·개인 경로 2개 제외입니다. 실패는 WebKit 1000px 종료 중 추적 파일 ENOENT이며, 중간에 안내한 시간 초과 추정은 최종 오류 분류가 아닙니다. 별도 검사들이 공통 결과 폴더를 사용한 충돌 가능성을 제거하도록 실행별 결과/보고서 폴더를 분리했습니다. 해당 항목은 조건·제한시간·재시도 변경 없이 1개 통과했습니다. 추가 상태 화면 4개(양 테마 axe·좁은 화면), 별도 결과 폴더 검사 2개도 통과했습니다. 전체 실행 도중 상태 CSS와 수집 코드 수정이 있었으므로 최종 소스의 단일 전체 통과로 표현하지 않습니다. [최신 검사 기록](dog-minute-followup.json).

최신 패키지: `deployment-artifacts/vps-3cdba41c340f3a8b.tar.gz`(291개 파일), SHA-256 `b672f8ef2d1ca39328b3078e5f9e2e9f942532f5b2c67c406755ffbf0f863e1f`. 개인 원본과 DB·인증은 제외했습니다. 원격 배포는 하지 않았습니다. 이 작업의 Upbit 재확인도 EACCES였으며 네트워크 제한은 유지됩니다.

남은 항목: 원격 CI·병합, 운영 D1 전체 이관·실제 VPS/HTTPS 전환, 거래소 연결·자연 시세와 온체인 갱신, 실제 부하·지연/LCP, 하루·엄격한 48시간 운영 관찰, 기존 화면 문구/CSS 전수 정리. Apple Safari·VoiceOver는 실기기 미검증입니다.


### 2026-10-03 KST 시세 갱신 후속 수정

현재 미리보기의 갱신 지연은 읽기 전용 API만 실행한 상태와 외부 네트워크 `EACCES`가 함께 원인이었습니다. `server/live.mjs`에 API·시세 hub·4개 수집기·백업을 함께 시작/종료하는 실행 경로를 추가했습니다. 검증 원장이 없는 원본 캐시는 거부하며, 원천 확인이 실패하면 실시간 실행 성공으로 표시하지 않습니다. 화면의 '1분마다 확인'은 조회와 수집을 구분하도록 수정했고 수집기 미실행 사유를 API와 시장 화면에 연결했습니다.

원본 18개 테이블·122,102행을 읽기 전용으로 열어 별도 DB에 이관하고 모든 내용 및 백업 복원을 대조했습니다. 이번 수정의 서버 13개·Python VPS 7개·Chromium/WebKit 14개(재시도 0)와 타입·빌드를 통과했습니다. 실행 전 원천 8종 검사는 모두 실패했고 Bitview·Coin Metrics·Bybit·DefiLlama·CoinLore·mempool은 네트워크 권한 차단으로 구분됐습니다. 실제 시세나 온체인 갱신 성공은 아직 확인하지 못했습니다. [실제 실행 진단](live-runtime.json).

직전 배포 준비물은 `deployment-artifacts/vps-e2d278c374abde35.tar.gz`(290개 파일), SHA-256 `13719540309f2acffc09ecb8ae18316e1cc9d83668c2f92c15a0e1f96d81af91`입니다. 아래 초기 패키지와 검사 기록은 과거 이력으로 보존합니다. 실제 VPS에는 아직 적용하지 않았습니다.

시장·상세 화면, 시장 조회 API, 중앙 시세 프로세스와 SSE 중계를 로컬에 구현하고 아래 검사를 수행했습니다. 원격 CI, VPS 배포, 운영 데이터 이관과 HTTPS는 미완료입니다. 로컬 미리보기는 기존 공개 데이터 캐시를 읽으며 2026-09-28의 오래된 값은 갱신 지연으로 표시합니다. 모의 E2E 자료와 실제 캐시 화면을 구분합니다.

최초 전체 실행은 개발 중 수정이 포함됐으며 최종 소스 전체를 한 번에 다시 통과시킨 결과가 아닙니다. 최초 7개 실패는 변경된 링크/선택창 명칭, 밝은 테마 대비, 모바일 차트 위치, PC axe 검사 시간 초과였습니다. 해당 수정과 재검사 결과를 위 표처럼 구분합니다. PC의 세 차례 axe 검사를 포함한 테스트 시간 제한은 45초에서 90초로 조정했으며 접근성·배치 조건과 재시도 횟수는 완화하지 않았습니다.

합성 체결을 넣은 로컬 SSE 동시 100명은 모두 818ms 안에 전달됐습니다. 실제 거래소 수신→화면 p95, 원격 서버 장시간 메모리와 재연결 부하의 합격 증거로 사용하지 않습니다.

실제 Windows Chrome에서 시장의 여덟 코인·Upbit KRW·지연 표시와 BTC MVRV 상세 진입을 확인했습니다. 상세 DOM은 5년 구간, Coin Metrics, 2026-09-27 확정값 1.58배를 표시했습니다. 이후 차트 크기 측정 시 화면이 시장으로 바뀌어 선택자가 시간 초과됐으므로 실제 Chrome의 크기 측정은 확정하지 않았습니다. 인앱 검수에서는 주 차트 상단 226px·높이 440px를 확인했고, 고정 PC 크기는 자동 검사로 확인했습니다.

## 검사와 수정 이력

- 기존 지표 회귀는 새 시장 진입·지표 선택창 경로에 맞게 수정했습니다. 계산·날짜·원천·개인 자료 보존 조건은 완화하지 않았습니다.
- 사라진 사이드바의 224px 여백, PC 차트 상단 위치, 모바일 불필요한 줄바꿈, 검색 입력의 잘못된 ARIA 속성, 밝은 테마 지연 문구 대비를 고쳤습니다.
- 브라우저 전체 검사 도중 수정이 있었으므로 중간 결과를 최종 일괄 통과로 표현하지 않습니다. 실패 항목은 별도 재검사합니다. WebKit 시간 초과는 실제 발생 사실로 남기고 확정되지 않은 원인을 단정하지 않습니다.
- Node SSE 중계의 fetch 응답 헤더를 직접 변경하던 결함을 발견했습니다. 복사한 헤더를 사용하도록 수정하고 실제 로컬 HTTP 중계 검사를 추가했습니다.
- 로컬 SSE 100명 검사는 합성 체결을 사용합니다. 실제 거래소 이벤트→사용자 화면 p95, VPS 장시간 메모리·재연결 부하와 다릅니다.
- 자료 백업·복원 검사는 합성 개인 자료를 사용합니다. 기존 X 원본을 열거나 공개하지 않았습니다.

## 완료하지 않은 관문

1. GitHub 443 연결 실패로 원격 CI·PR·main 병합 미실행.
2. SSH 별칭 미등록. 명시적 승인 VPS 주소와 기존 키를 이용한 조회도 소켓 단계 `Permission denied`로 실패. 인증키 불량이나 VPS 자체 장애로 단정하지 않음.
3. 실제 VPS 자원·포트·거래소 접근, Docker 실행, D1 전체 export와 내용 해시 대조, HTTPS 발급 및 최종 전환 미검증.
4. 운영 스트림 p95 3초, 실제 VPS SSE 100명 부하·메모리·재연결, 고정 PC/네트워크 LCP 2.5초 목표 미검증.
5. 완전 UTC 하루·엄격한 48시간 기록률/공백/오류 조건 미검증. Cloudflare Cron 및 기존 데이터는 변경하지 않음.
6. 실제 Windows Chrome은 시장→BTC MVRV 진입만 확인했습니다. 모든 사용자 흐름의 실기기 전수 검증은 아닙니다. Apple Safari·VoiceOver는 기기가 없어 미검증이며 자동 WebKit과 구분합니다.
7. 모든 기존 화면의 문구 추출·전수 감사 및 전체 레거시 CSS 통합은 마감하지 않았습니다. 이번에 교체한 화면의 문구·여백·상태 전달을 먼저 정리했습니다.
