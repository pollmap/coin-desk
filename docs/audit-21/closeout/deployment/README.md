## 성능과 남은 항목

1280×800, Chromium 153.0.8010.12, 다운로드 10Mbps·업로드 5Mbps, 추가 지연 0, CPU 배속 1, 동일 브라우저 프로세스의 새 컨텍스트 5개로 VPS 직접 주소를 비교했습니다.

|---|---:|---:|

| LCP p95 | 4,996ms | 4,920ms |
