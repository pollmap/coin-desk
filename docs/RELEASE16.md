# 0.16 · 차트 분석과 기기 내 개인 자료함

BTC를 중심으로 DOGE·ETH의 실제 가격 이력을 비교하고, 개인 참고 자료에서 해당 분석으로 이어지는 흐름입니다. 별도 역사·공개 리서치 게시판은 복원하지 않습니다.

## 차트에서 바로 하는 작업

- 전체 기간 초기 진입을 차트 크기·축 레이아웃이 확정된 뒤 복원합니다. 직접 확대한 구간은 데이터 갱신 때 유지합니다. 명시한 공유 날짜 범위를 우선합니다.
- 현재 진행 봉과 확정 지표를 구분합니다. 기본 범례에는 마지막 확정 지표값·기준일을 보이고, 날짜 탐색은 해당 관측의 결측을 그대로 표시합니다.
- 주 차트 왼쪽의 수평선·추세선·평행 채널·구간 측정·실행 취소를 사용합니다. 주석은 코인·원천·봉·주 지표별로 이 기기에 저장합니다. Escape로 그리기를 취소합니다.
- 분석을 고르면 바로 아래 주 화면이 바뀝니다. 계절성·사이클에서 적용되지 않는 일반 가격 도구를 숨깁니다. 기존 날짜·CSV·공유·저장을 유지합니다.
- Workspace v2는 날짜·비교 방식·주석·분석 설정을 복원하고 v1을 읽습니다. 공개 링크에는 주석, 개인 자료 ID·본문·메모·이미지를 넣지 않습니다.

## 개인 자료함

`내 작업공간 → 개인 자료함`에서 JSONL·CSV·이미지 또는 폴더를 가져옵니다. 글 ID와 이미지 참조를 유지하고 재가져오기는 중복 병합·변경 이력으로 처리합니다. 본문 확인·이미지 검토·방법론 검증을 따로 표시합니다. 검색은 별도 Worker, 화면은 가상 목록입니다.

자료를 선택하고 코인·분석·원천·지표 연결을 확인한 뒤 `내 차트로 열기`를 누릅니다. 기본 날짜는 게시일 **전 UTC 일자**까지입니다. 계절성·사이클 계산에도 명시한 종료일 이후 관측을 쓰지 않습니다. `게시 후 흐름까지 보기`로 이후를 열 수 있습니다. 이는 현재 확보한 이력을 잘라 보는 기능이며 당시 공개된 데이터 전체의 완전한 재현은 아닙니다.

IndexedDB와 로컬 주석은 현재 브라우저·사이트 원점에 귀속됩니다. 로컬 개발 사이트와 운영 사이트, 다른 브라우저 사이에는 자동 공유되지 않습니다. 백업으로 이전합니다. 원본 이미지는 선택적으로 보관하고 용량 부족 시 기존 자료를 삭제하지 않습니다. 백업은 디스크 스트림 또는 브라우저 임시 저장소로 기록하고 이미지 SHA-256을 복원 시 대조합니다.

Chrome 확장 설치와 화면 수집은 [설치 안내](../extension/README.md)를 따릅니다. 공개 다운로드는 빌드 때 코드 9개 파일만 묶고 CRC를 검사합니다. X 로그인은 Chrome에서 유지하며 쿠키·비밀번호·인증 토큰을 추출하지 않습니다. 사용자가 시작한 화면 범위만 읽고 접힌 본문·접근 제한을 표시합니다. 브라우저를 닫은 상태의 개인 X 서버 수집을 제공한다는 뜻이 아닙니다.
