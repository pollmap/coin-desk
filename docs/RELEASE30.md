# 0.30 — 같은 지표 비교와 이력 확인

코인 상세의 **비교**에서 선택 코인·지표·원천·기간을 `/compare`로 이어갑니다. 비교 화면은 **지표 / 성과**로 나누며 기존 성과 링크와 상대강도는 유지합니다. 새 지표 비교의 기본은 BTC·ETH MVRV 최근 5년입니다.

- 2~3개 코인의 MVRV·RSI 14·낙폭·펀딩률을 비교합니다. 같은 가격 원천·확정 일별 종가로 계산하고, RSI와 낙폭에는 표시 기간 이전의 전체 이력을 포함합니다. MVRV는 같은 제공자의 값이어도 코인별 공급·실현가치 정의가 다르므로 저평가 순위로 표시하지 않습니다. 계약별 정산 간격이 다른 펀딩률은 별도 패널로 표시합니다.
- 대표값은 최근 확정값을 유지하고, 마우스·터치 탐색값은 차트 안에서 미리 봅니다. 클릭 또는 키보드로 날짜를 고정했을 때만 대표값을 바꾸며 **최근값**으로 돌아갈 수 있습니다. 날짜·확대 구간·원천·비교 대상을 공유하고 기존 기기 저장 형식으로 다시 엽니다.
- `GET /api/v1/indicator-comparison`은 입력을 검증하고 자산별 미지원·관측 대기·오류를 분리합니다. 공통 날짜 수치는 선택한 모든 코인의 실제 같은 날짜만 사용하며 결측을 채우지 않습니다.
- `GET /api/v1/coverage?asset=…`는 최근 테이블과 압축 이력을 함께 읽습니다. 데이터 정보 패널을 열 때만 조회하며, 실제 체결이 오래된 경우와 수집 오류를 구분합니다. 최초 관측을 코인 출시일로 표현하지 않습니다.
- 읽기 캐시는 자산·지표·원천·기간별로 구분하고 SQLite 데이터 변경 및 최대 30초 경과에 무효화합니다. 늦은 응답을 취소·격리하고 DB가 없는 시세 스트림 전용 실행도 유지합니다. 공개 조회로 수집하거나 DB에 쓰지 않습니다.
- 원천 공백 검사는 읽기 전용입니다. 별도 운영 도구의 복구는 범위를 제한하고 기존 검증기를 거친 실제 누락 관측만 추가합니다. 기존 관측·최신 성공 시각·과거 커서를 덮어쓰지 않으며 8GiB 공간 보호 및 일일 과거 후보 10,000개 제한을 유지합니다.

흰색·청록·보리와 저장한 다크 설정, 주소·개인 자료·설정 버전 1·2를 유지합니다. 비교·미리보기 스타일은 기존 담당 파일에서 관리하며 새 전역 스타일 파일은 추가하지 않습니다. 기존 12개 전역 CSS 전체의 재작성은 하지 않았습니다.

[검증·운영 기록](audit-30/README.md). 코드·배포·실데이터 공백·성능은 각각 기록합니다. 모든 공급자의 전체 과거 자료 확보, 실제 Apple Safari·VoiceOver, 사람 대상 사용성 검사를 완료한 것으로 표현하지 않습니다. 48시간 대기는 적용하지 않습니다.
