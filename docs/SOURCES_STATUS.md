# 정기 보고서 원천 확인

기준일: 2026-10-18. 조회 성공은 해당 시점의 계약 확인이며 장기 수집 완결성을 뜻하지 않습니다.

Injective SDK 소스의 일반 chain-format과 Chronos 반환값을 구분합니다. 현물 INJ/USDT의 base decimals 18·quote decimals 6에 따라 표본 raw price `8.709e-12`는 `8.709 USDT`, raw quantity `2.29e17`은 `0.229 INJ`였습니다. 이 표본을 현재 가격이나 전체 시장 거래량으로 표시하지 않습니다.

보고서에는 허용한 지표·공급자 URL·근거만 저장합니다. 개인 주소·주문 원문·인증 헤더를 공개 fixture에 포함하지 않습니다. SDK 설치나 원천 GET 성공만으로 주문장 신선도·체결 양면 중복·기간 완결성 검증을 대신하지 않습니다.

2026-10-18 01:51 UTC 별도 SDK 표본은 활성 현물 132개·파생 285개를 반환했습니다. INJ/USDT 현물은 raw price `0.000000000008709`, quantity `50962000000000000000`에서 `8.709 USDT`, `50.962 INJ`로 변환됐습니다. INJ/USDC 무기한은 raw price `8726000`, quantity `0.12`에서 `8.726 USDC`, `0.12`로 변환됐습니다. 시장 수는 그 시점의 응답이며 제품 상수가 아닙니다.

Chronos 일봉은 `resolution=1440`을 사용합니다. 먼저 시도한 `1D`는 HTTP 400이었고 공식 계약에 맞춰 수정했습니다. 표본의 완료 일봉 29개는 2026-09-19~10-17 UTC였으며 volume은 계산에 사용하지 않았습니다. 고정 체결 시간창은 현물·파생 각각 2행만 확인했으므로 전체 수집 완료 증거가 아닙니다.

DefiLlama의 Injective DEX 응답에는 예측시장 항목도 포함됐습니다. 원천의 `category=Dexs`와 체인 매핑을 확인하고 중복·비활성 항목을 제외한 일별 breakdown만 집계합니다. 단위는 원천의 USD이며 전체 합계·rolling 24시간 값을 다시 더하지 않습니다. 미확인 이름과 null은 부분 관측으로 남깁니다. 이 값은 선정 시장의 Injective taker 체결 거래대금과 별도 지표입니다.
