# 0.34 — 전체 가격과 정확한 탐색

새 가격·슈퍼트렌드·이동평균 리본·볼린저 화면은 전체 기간을 기본으로 사용합니다. URL·저장 분석에 직접 정한 기간과 사용자가 실제로 확대한 구간은 우선합니다. 일·주·월봉은 선택 원천의 가장 오래된 실제 관측부터 조회하며, 시간봉은 최근 90일 정책을 유지합니다.

가격축은 값의 실제 표시 정밀도를 사용합니다. 작은 코인 가격을 $0.00으로 뭉개지 않으며, 현재가·확정 종가·보조 지표의 중복 축 배지를 정리합니다. 십자선의 가격과 툴팁의 관측값은 서로 구분합니다.

툴팁은 가리킨 봉의 날짜·종가·선택 지표값을 표시합니다. 공개 대표값은 최근값을 유지합니다. 날짜 수치표·공유·내보내기·운영 정보는 다시 넣지 않습니다. 결측일·다른 패널·단위가 섞이지 않도록 검사합니다.

모바일은 시간축을 포함한 차트 높이를 240~330px로 조절해 하단 메뉴 가림을 방지하고, PC의 기본 440px 높이는 유지합니다. 터치로 값 확인·탐색·이동·확대를 구분하며 키보드와 Escape도 검사합니다.

과거 이력의 공백·미제공·계산 준비기간을 구분하고 원천·통화를 이어 붙이지 않습니다. USD 종가로 실제 OHLC를 만들지 않으며, 수집 시각·결측·오류·시각 유효성 판단은 내부에 보존합니다. 과거 수집의 8GiB 공간 보호도 유지합니다.

최종 결과는 [검증 기록](audit-34/README.md)에 기록합니다. 실제 Apple Safari·VoiceOver·실물 휴대폰과 사람 대상 평가는 자동 터치 검사와 별개이며, 48시간 대기는 완료 조건에 추가하지 않습니다.

0.34.1은 배포 후 QA에서 확인한 축의 부동소수점 0 표기, 모바일 리본·볼린저 범례 배치, 터치 취소 뒤 첫 버튼 탭을 보완합니다. 관측값을 바꾸거나 취소를 클릭으로 바꾸지 않으며, 정확한 Lightweight Charts 5.2.1 원본에만 취소 정리를 적용합니다.

0.34.2는 슈퍼트렌드·이동평균 리본·볼린저의 가격축에도 같은 거래소·통화의 유효한 현재가를 연결합니다. 가격 원천과 헤더의 거래소 설정이 다른 기존 링크도 차트 원천으로 정리합니다. 확정 봉·계산·대표값은 바꾸지 않으며, 300초를 지난 체결·다른 코인·다른 통화·USD 참조와 지표축에는 현재가를 넣지 않습니다.
