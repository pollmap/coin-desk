# Coin Desk 0.10 · 코인별 분석과 장기 선물 이력

기준일: 2026-09-24 KST.

## 변경

- 코인별 전체 가격 → 기술적 분석 → 온체인 → 선물 이동 메뉴를 연결했습니다. 선물은 `/futures/BTC`, `/futures/DOGE`, `/futures/ETH`에서 열립니다. 다른 코인의 메뉴가 함께 선택되지 않습니다.
- 온체인 지표를 가치·손익, 이용·전송, 공급·시가총액, 수수료·블록, 거래소 자금 흐름으로 분류했습니다. 해당 코인이 지원하는 지표만 검색하고 선택 후 목록은 접힙니다. 중복 현재 위치 미터를 제거하고 모바일 기간 선택을 간소화했습니다.
- 선물은 펀딩비, 미결제약정, 롱 포지션 보유 계정 비중을 구분합니다. 기본 전체 확보 기간, 일별 장기/시간별 최근 전환, 현물 비교, CSV를 제공합니다. URL의 metric·interval로 선택한 지표와 관측 간격을 복원합니다.
- 펀딩비 0%, 롱 계정 비중 50% 기준선을 추가했습니다. 계정 비중을 포지션 규모 비중으로 표현하지 않습니다.
- 롱 계정 비중 축은 0–100%이며, 펀딩비 축에는 0을 포함해 비중 변화나 부호를 왜곡하지 않습니다.
- Binance 시장데이터 전용 REST는 Cloudflare 실제 실행에서 403을 반환해 채택하지 않았습니다. 기존 공식 WebSocket을 유지하고 메인 Worker의 강제 서울 배치를 해제했습니다.
- 시세 작업을 4개에서 2개 배치로 줄여 다른 수집 작업의 실행 여유를 확보했습니다. 원천 오류가 반복되면 해당 작업의 무조건 우선권을 해제합니다.
- 활성 화면 시세 조회와 서버 공유 갱신 잠금을 모두 60초로 맞췄습니다. 이전에는 화면이 1분마다 요청해도 원천 갱신은 180초에 한 번만 허용했습니다. 방문자가 없는 경우의 배경 시세 수집은 8분 목표를 유지합니다.

## 장기 선물 데이터

로컬 수집 원본을 보관하고 동일한 운영 파서로 검증했습니다. 운영 D1에 적재한 **12,689개 일별 관측을 공개 API와 전량 대조해 일치**를 확인했습니다. 일별 OI와 일별 계정 비중은 시간별 데이터와 별도 키에 저장합니다.

| 자산 | 확보 시작일 UTC | 일별 OI | 일별 롱 계정 비중 |
|---|---|---:|---:|
| BTC | 2020-08-05 | 2,242 | 2,241 |
| DOGE | 2021-06-03 | 1,940 | 1,939 |
| ETH | 2020-10-22 | 2,164 | 2,163 |

수량은 초기 적재 시점 기준입니다. 원천 결측일을 보간하거나 0으로 채우지 않았으므로 두 지표의 개수가 다릅니다. 제공 시작일은 코인 자체의 탄생일이나 현물 가격 시작일을 의미하지 않습니다. 확보 후 신규 관측은 Cron이 계속 추가합니다.

재현:

```powershell
node scripts/bootstrap-derivatives.mjs
npx wrangler d1 execute btc-desk --remote --file work/derivatives-history.sql --yes
node scripts/verify-derivatives.mjs
```

원본과 SQL은 work 디렉터리에 보존하며 Git에 올리지 않습니다. 생성 SQL은 일별 6개 시계열만 갱신합니다. 전체 DB를 교체하지 않습니다.

## 검증

- 타입검사 및 247개 테스트 통과.
- 프로덕션 빌드 통과.
- 일별/시간별 격리, 30일 이전 백필, 원천이 커서를 무시하는 경우 거부, 원천 429 오류 처리, 실패 작업의 우선순위, 코인별 선택·지표 분류 완전성 회귀 검사.
- 공개 API 12,689건 일치. 실행 증적: 로컬 work/derivatives-public-verification.json.
- 원천 연결은 공유 토큰으로 인증한 Feed Worker를 사용합니다. Bybit 선물, 8개 Binance 현물의 공개 시세·최대 32개 봉, mempool.space 두 고정 경로만 허용합니다. 임의 URL·주문 메서드·알 수 없는 자산·인증 없는 요청은 거부합니다. 원천 반환값은 메인 Worker가 기존 검증기로 다시 확인합니다.
- 1280×900 데스크톱 및 390×844 모바일에서 선물 지표·일별/시간별 전환, 온체인 지표 검색·선택 후 접힘, 코인 전환 시 전체 기간 복원을 확인했습니다. 두 뷰포트에서 문서 가로 넘침이 없었습니다.
- 화면 증적: [선물 데스크톱](audit-10/futures-desktop.png), [선물 모바일](audit-10/futures-mobile.png), [온체인 모바일](audit-10/onchain-mobile.png).
- BTC·DOGE·ETH Binance 최신 시세의 정상 응답과 stale=false를 확인했습니다. 무인 Cron의 장기 안정성과 이전 실패 작업의 순차 회복은 운영 기록으로 별도 확인합니다.

## 원천과 남은 경계

- [Binance 시장데이터 전용 API](https://developers.binance.com/en/docs/products/spot/faqs/market_data_only)
- [Bybit 미결제약정](https://bybit-exchange.github.io/docs/v5/market/open-interest)
- [Bybit 롱·숏 계정 비율](https://bybit-exchange.github.io/docs/v5/market/long-short-ratio)
- [Bybit 전체 청산 스트림](https://bybit-exchange.github.io/docs/v5/websocket/public/all-liquidation)은 500ms WebSocket 전송입니다. 현재 분 단위 Cron은 상시 스트림 연결을 유지하지 않습니다. 청산 전체 이력·히트맵을 완성된 기능으로 표시하지 않았습니다. 연속 수집기, 재접속 및 수집 공백 기록이 추가로 필요합니다.
- 48시간 관찰은 갱신 간격이 아닙니다. 서버 실행 기록으로 운영 안정성을 관찰하는 구간입니다. 코드·테스트·배포 통과로 실제 48시간 운영을 대신하지 않습니다.
