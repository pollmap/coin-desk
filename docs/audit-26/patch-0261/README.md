# 0.26.1 검증·배포 기록

2026-10-10 KST. PR [#54](https://github.com/pollmap/coin-desk/pull/54)을 main `1a83b44cde17cf1ef34ac00033df198b3a9c41b8`에 병합하고 [Pages](https://coin-desk.pages.dev)와 [VPS](https://coin-desk.62.171.141.206.sslip.io)에 배포했습니다. 코드·배포 검증과 전체 데이터 정상·과거 이력 완성·성능 목표 달성은 별도로 구분합니다.

## 수정한 동작

- 관심 코인을 8개로 잘라 저장하던 오류를 수정해 150개까지 저장·백업·복원합니다. 별을 눌러도 기존 분석·주석·추가 설정과 이전 저장 버전을 바꾸지 않습니다.
- 시장 첫 진입에서 지표·사전·개인 저장 화면 코드를 받지 않습니다. 지표 검색이나 이전 분석 주소를 열 때 불러옵니다. 늦은 검색 응답에도 Enter가 동작하며, 검색어를 지우거나 초점을 옮기면 대기 중 이동을 취소합니다.
- 공통 스타일은 처음부터 적용합니다. 지표 선택·이전 URL의 코인·날짜·원천·해시와 기존 저장 키를 보존합니다.
- `/assets/*`의 해시 파일에 장기 캐시를 적용했습니다. 실제 GET에서 두 주소의 정적 파일은 `immutable`, HTML과 API는 기존의 다른 캐시 정책임을 확인했습니다. [캐시 검사](cache.json)

## 실제 데이터·자연 갱신

150개 자산·241개 거래쌍을 유지합니다. 온체인 자산 34개 중 MVRV는 33개, USD 참조는 143개, Bybit 계약은 136개입니다. 150개 전부의 MVRV 지원을 뜻하지 않습니다.

2026-10-10 09:47 UTC에 최신 MVRV 33개·TRX 활성 주소 1개를 원천과 대조했습니다. 각 최근 10일의 값과 마지막 기준일이 모두 일치했습니다. 모든 온체인 지표의 독립 원천 대조가 아닌 34개 조합 검사입니다. [원천 대조](source-latest.json)

이번 배포 전 295초의 읽기 전용 관측에서 시세 확인 225개·가격 기준 시각 210개·봉 확인 31개·선물 확인 9개가 증가했습니다. quotes와 background lane은 각 4회 완료·1회 진행, recent와 analysis는 각 5회 완료였습니다. 배경 Cron에는 ok 2회·idle 1회·partial 1회·running 1회가 있어 전부 정상 완료라고 표현하지 않습니다. 원시 ingestion의 HTTP 429와 체결 지연 기록도 보존합니다. 직접 수집 API·overview와 검사 SQL 쓰기는 없었지만 다른 방문자의 부재는 보장하지 않습니다. 하루 전체 또는 모든 6시간 작업의 증거도 아닙니다. [자연 갱신](natural-cron.json)

이 관측 창의 과거 선물 행 수는 증가하지 않았고 일일 10,000개 후보 예산은 이미 예약된 상태였습니다. 커서 643개와 기존 이력을 보존했습니다. 과거 선물 수집은 계속되며 전체 완료로 보고하지 않습니다.

## 앞선 실패와 외부 미검증

초기 지연 검사에서 개발 모듈 경로를 차단하지 못한 테스트·개인 설정 보존 반환 타입 오류를 수정했습니다. 후보에서 공통 CSS 지연으로 본문 바로가기가 평소에도 드러나는 회귀도 수정했습니다. 후보 QA의 SSH 준비 전 접근·잘못된 날짜와 GET 전용 API에 HEAD를 보낸 캐시 검사 오류는 제품 장애와 구분합니다. 마지막 GET 검사는 통과했습니다.

Windows WebKit의 Tab·Alt+Tab은 링크에 초점을 주지 않아 최종 WebKit에서는 링크 초점을 명시한 뒤 Enter 이동을 검사합니다. 실제 Tab 순서 검사는 Chromium에서 수행했습니다. 실제 Apple Safari·VoiceOver를 검증한 것은 아닙니다. 이전 CI 취소·실패를 최종 통과 수에 합산하지 않습니다.

실제 Apple Safari·VoiceOver와 사람 대상 사용성 검사는 미검증입니다. 관계 근거가 검토된 자산은 13개이며, 신규 상장·거래소별 짧은 이력은 필요한 계산을 지원하지 않을 수 있습니다. 개인 자료·작성 중인 별도 기획서는 변경하거나 공개하지 않았습니다. **48시간 대기를 다시 요구하지 않습니다.** 증거 문서만 추가하는 커밋으로 재배포하지 않습니다. [최종 구분](final-status.json)
