# 0.26.1 검증·배포 기록

2026-10-10 KST. 시장 첫 로딩과 관심목록 보존을 수정합니다. 이 문서의 초기 상태는 로컬 검증 진행 중이며 원격 CI·운영 배포 완료를 의미하지 않습니다.

## 변경과 검사

150개 × 두 원천의 기본 링크를 전체 지표 정의와 대조합니다. 관심 코인 150개 백업·복원, 9번째 관심 코인 저장 시 개인 분석 보존, 손상·미지원 버전 거부를 검사합니다. 브라우저에서는 첫 지표 코드의 지연·Enter·검색 취소·새로고침을 확인합니다.

초기 브라우저 검사에서 개발 서버의 모듈 경로를 번들 경로로만 차단해 지연이 재현되지 않았습니다. 개발·빌드 경로 모두를 대상으로 바꾸고 시간 기반 대기 대신 응답 해제를 직접 제어합니다. 최초 실패를 통과 수에 합산하지 않습니다. 새 보존 테스트에서 반환 타입이 빠진 타입 오류도 수정했습니다.

실제 후보 화면에서 공통 스타일이 개인 저장 코드와 함께 지연 로드돼 본문 바로가기 링크가 평소에도 노출되는 회귀를 발견했습니다. 스타일을 초기 공통 진입점으로 옮기고 키보드 Tab·Enter 검사로 보완했습니다. 후보 검증 도구의 SSH 연결 준비 전 접근과 잘못 입력된 날짜도 도구 오류로 분리해 기록하며 수정 후 재검사합니다.

## 실제 데이터

2026-10-10 09:29 UTC 근처 읽기 검사에서 Pages 1,545개·VPS 1,546개 원천이 정상, 시세 40개·39개가 지연이었습니다(활성 1,585개 기준). 시점 차이로 개수가 다르며 당시 온체인·선물 지연은 없었습니다. HTTP 503을 정상 응답으로 바꾸지 않습니다. 원천 값 대조와 자연 수집 관측은 후속 결과에 기록합니다.

## 남은 확인

원격 CI·배포·운영 사용자 흐름·고정 조건의 성능 측정 결과를 추가합니다. 저유동성 종목의 체결 부재, 진행 중인 과거 수집, 실제 Apple Safari·VoiceOver와 사람 대상 사용성은 코드 수정만으로 완료 처리하지 않습니다. 48시간 대기는 요구하지 않습니다.
