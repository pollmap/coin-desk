# 0.26.2 검증·배포 기록

150개 코인 로고와 시장·검색·상세·비교·저장 화면의 식별 표시를 보완합니다. 원격 CI·배포는 진행 중이며 완료 증거를 이 문서에 반영합니다.

## 범위

로고는 실 거래쌍과 프로젝트 이름으로 대조했습니다. Upbit 91개·Binance 57개·Trust Wallet 2개, 모두 로컬 PNG입니다. 150개 파일이 서로 다른 SHA-256을 가지며 PNG 구조·CRC와 출처를 검사합니다. 이전 8개 파일과 개인 저장 키는 보존합니다.

같은 MNT 코드가 Binance 공개 자산 목록에서 몽골 통화로 사용되어 자동 후보를 제외했고 Trust Wallet의 Mantle 프로젝트·주소와 대조한 로고를 사용했습니다. 이 차이는 자산 레지스트리의 실제 거래쌍을 바꾸지 않습니다. 확인에 사용한 원문은 [파일별 출처](../../../public/coin-logos/sources.json)에 있습니다.

## 검사 및 배포

진행 중. 이미지 전체 디코딩, 320px 실패 상태·양 테마·코인 전환, 검색 → 상세 → 저장 로고 일치와 서버 캐시를 검사합니다. 타입·단위·서버·복구·브라우저 검사와 원격 CI 뒤 변경된 API/웹만 배포합니다.

현재 원천 상태·전체 이력·이전 릴리스 성능 한계는 로고 검사와 별도로 기록합니다. 실제 Safari·VoiceOver·사람의 사용성 검사를 완료로 표현하지 않습니다. 48시간 대기는 사용하지 않습니다.
