## 변경과 보존

- Upbit 91개·Binance 57개·Trust Wallet 2개, 서로 다른 로컬 PNG 150개, 합계 2,706,128바이트입니다. 원본을 변형하지 않았습니다.
- 실 거래쌍과 프로젝트 이름으로 식별했습니다. MNT의 몽골 통화 이미지, BEAM의 동명 자산, ATH의 다른 프로젝트 후보를 제외했습니다. 출처·확인일·파일 해시는 [출처 명부](../../../public/coin-logos/sources.json)에 있습니다.

- 로고는 지연 로드·비동기 디코딩하며, 해시 파일에만 1년 캐시를 적용합니다. 출처 JSON은 첫 화면에 요청하지 않습니다. 이전 8개 파일·주소·저장 키·개인 자료를 보존합니다.

## 운영 화면 확인

- 두 주소의 현재 HTTP 파일 249개씩 대조했습니다. HTML·JS·CSS·로고가 일치합니다. VPS 출처 JSON은 패키징의 LF 정규화 뒤 전체 내용이 일치하며, 확장 ZIP은 압축을 푼 모든 파일의 해시가 일치합니다. `_headers`는 배포 설정이므로 HTTP 파일 대조에서 제외했습니다.
- 150개 로고의 원본 바이트·PNG 응답·장기 캐시는 양 주소 모두 일치합니다. 첫 조회에서 Pages JS 한 개가 일시적으로 HTML을 반환했으며 추가 배포 없이 정확한 경로·배포 주소를 재확인해 일치했습니다. 원인은 확정하지 않습니다.
- 390·1000·1280px에서 검색 → PENGU RSI → 데이터 정보 → 날짜 고정 → 저장 → 복원 → 새로고침, 총 6개 운영 흐름을 통과했습니다. API 쓰기 0·axe 위반 0. Pages에서 만든 시험용 기기 백업을 새 VPS 컨텍스트로 복원했습니다.
- 모바일 차트 시작 261px·높이 330px, PC 시작 226px·높이 440px를 확인했습니다. 이 차트 로딩 시간은 LCP 벤치마크가 아닙니다.
- 실제 Windows Chrome에서도 ‘펭귄’ 검색과 PENGU 로고 32px·디코딩·가로 넘침 없음, 사용자의 저장된 다크 테마 보존을 확인했습니다. 자동 WebKit을 실제 Apple Safari 검사로 표현하지 않습니다.
