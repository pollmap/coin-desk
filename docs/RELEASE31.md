# 0.31 — 가격에서 지표와 비교로

시장에서 코인명이나 가격을 누르면 해당 거래소의 가격 차트를 엽니다. 별도의 가치평가·추세 분석 링크와 기존 공유·저장 링크는 지정한 지표를 그대로 엽니다. 가격 차트는 최근 1개월·일봉·선형 축으로 시작하며 사용자가 명시한 기간·날짜·설정이 우선합니다.

- 상세 바로가기에 가격을 추가하고 MVRV·RSI·펀딩률과 전환합니다. 현재 선택한 고급 분석도 바로가기에 남습니다.
- 가격 차트에서 캔들·종가선을 선택하고 같은 원천의 성과 비교로 이동합니다. 표시 방식은 기존 작업공간 버전 2로 저장·복원합니다.
- 가격 화면에서 거래소를 바꾸면 차트 원천도 함께 바뀝니다. USD 참조는 확정 종가선과 USD 값으로 표시합니다.
- 현재가는 별도 가격선으로 표시합니다. 실제 OHLC·확정 종가와 구분하며 틱으로 가짜 캔들을 생성하지 않습니다. 다른 자산·통화, 지연된 값·오래된 이벤트를 걸러내고 시세마다 차트를 재생성하지 않습니다.
- 운영 상태의 가격 시장 수를 실제 지원 거래쌍으로 계산하고 전체 가능한 조합 수를 별도 필드로 제공합니다.

공개 자료·REA·우리 데이터 대조 결과와 배포 상태는 [감사 기록](audit-31/README.md)에 구분합니다. 비공개 DB·상용 데이터 구매·유료 로그인 내부 기능은 조사 완료 범위에 포함하지 않습니다.
