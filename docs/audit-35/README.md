## 원천 재대조와 복구

- **Coin Metrics:** 10월 17일 공식 응답 143개와 저장 585계열을 대조했습니다. 과거 21,122개를 새 백업·독립 복원·변경 전 값 확인 후 보정했습니다. 대조 후 정확한 값 1,789,565개 일치, 허용 반올림 차이 4,767개 보존, 누락·불일치·원천 없는 저장값은 0개였습니다. 이전 최신 누락 474개는 이번 보정 전에 정상 수집으로 해소됐습니다. [원천 보정 증거](source-reconciliation-20261017.json)
- **선물:** 승인된 일회 확대는 기존 공유 예산·만료·호출 제한·8GiB 보호와 체크포인트를 유지해 실행했습니다. 처리·잔여·CPU 보호 중지는 [복구 기록](derivatives-recovery-20261017.json)의 최종 시점을 따릅니다. 체크포인트 완료와 모든 과거 관측의 독립 재조회는 구분합니다.
- **이전 이력 조사:** 10월 15일의 가격 시작점·원천 공백 확인은 [당시 진단](data-diagnosis.json)으로 보존합니다. 이번 날짜의 전수 재검증으로 바꾸지 않습니다. 원천이 제공하지 않는 값을 보간하지 않습니다.

143개는 USD 참조가격 자산 수이며 모두 MVRV 지원이라는 뜻이 아닙니다. 과거 값 차이가 공급자 수정 때문인지 이전 수집 오류 때문인지는 확정하지 않았습니다. 외부 변동으로 늘어난 디스크 여유를 이번 코드가 회수한 공간으로 주장하지 않습니다.
