# 차트 설명 이해도 확인

상태: 미실시. 자동 브라우저 검사는 아래 과제의 수행 결과가 아니다. 운영 배포와 화면 확인을 마친 뒤 처음 보는 사람이 도움 없이 수행한 결과를 기록한다.

## 과제

| 과제 | 진행자가 제시할 내용 | 확인할 이해 | 기록할 항목 |
|---|---|---|---|
| 캔들 읽기 | 가격 차트의 읽는 법을 열고, 예시 캔들의 시가·종가·고가·저가를 찾아 설명한다. 일봉을 주봉으로 바꾸면 무엇이 달라지는지 설명한다. | 몸통과 꼬리, 봉 하나가 나타내는 기간, 아직 끝나지 않은 봉의 값이 바뀔 수 있음 | 완료 여부, 걸린 시간, 오해한 용어, 도움을 준 지점 |
| 축 바꾸기 | 같은 가격 차트를 로그축과 일반축으로 바꾼다. 100→200과 200→400이 로그축에서 왜 같은 높이인지 설명한다. | 가격 자체는 같고 같은 비율 변화의 간격이 같음 | 축 선택을 찾았는지, 값이 변했다고 생각했는지, 확대 범위 유지 여부 |
| MVRV 읽기 | 읽는 법의 예시 MVRV 1.5를 자기 말로 설명한다. 실제로 산 가격과 마지막 이동 가격이 항상 같은지 설명한다. | 시가총액이 실현시가총액의 1.5배라는 뜻이며 개인의 수익률·확정 매수 판단이 아님 | 정의 이해, 예시와 실제 값 구별, 매수·매도 판단으로 오해했는지 |
| 레인보우 구분 | BTC Original과 자체 회귀의 읽는 법을 각각 열고 차이를 설명한다. DOGE의 자체 회귀가 BTC 공식을 그대로 복사한 것인지 설명한다. | 고정 공개 모델과 자산별 과거 관측 회귀의 구분, 색 구간이 수익 보장이 아님 | 구분 성공 여부, 제목·설명 중 도움이 된 부분, 막힌 위치 |

## 진행 기준

- 정답을 먼저 설명하거나 특정 버튼을 가리키지 않는다. 도움을 요청하면 제공한 내용을 기록한다.
- 참가자의 이름·연락처·개인 투자 내역을 공개 감사 기록에 넣지 않는다.
- 장치·화면 크기·브라우저·검사한 릴리스와 과제별 결과를 남긴다. 한 사람이 성공한 결과를 전체 이용자의 이해도로 확대하지 않는다.
- 사전에서 돌아온 뒤 코인·원천·기간·축·확대·읽던 위치가 유지되는지도 관찰한다.
- 실제 휴대폰·Safari·VoiceOver는 해당 장치와 도구로 수행한 경우에만 완료로 기록한다.

현재 참가자 수는 0명이며 성공률과 수행 시간은 측정하지 않았다.
