# 0.38 검증 기록

기준일: 2026-10-18. 구현·검증 진행 중이다. 코드, 계산, 실제 화면, 배포, 사람 대상 검사를 분리한다.

## 보호 범위

기존 `docs/audit-31`의 사용자 변경과 별도 제품 기획 문서는 이번 변경에 포함하지 않는다. 개인 자료·브라우저 저장 키·작업공간 버전 1·2와 기존 레인보우 모델 ID는 보존한다.

## 수정 전 확인

- 가격·슈퍼트렌드의 일반 축 기본값과 지표 전환의 강제 `log=0` 경로를 확인했다.
- 대시보드에서 확대할 때 일부 지표의 축 정책이 달라졌다.
- 양수 가격만 사용하는 Chromium 재현에서 `$-0.00004000` 눈금이 나타났다. 수정 전 실패와 trace를 비공개 작업 폴더에 보존했다. 실제 DOGE 화면의 음수 눈금과 테스트의 인위적 양수 가격 표본을 구분한다.
- 사전의 상단 카드, 현재 코인과 맞지 않는 BTC 제목, 자체 레인보우 도식 ID 불일치와 상세 설명 연결 누락을 확인했다.

## 로컬 구현 검증

- 타입검사 최초 실행은 통과했다. 이후 전체 검사를 병행한 환경에서 메모리 부족이 발생했고, 512MiB로 제한한 재검사 역시 메모리 부족으로 종료됐다. 최종 소스를 1,024MiB 제한으로 다시 검사해 통과했다. 빌드와 전체 회귀는 별도 원격 CI로 판정한다.
- 전체 단위 검사: 89개 파일, 950개 중 947개 통과·3개 실패. 실패는 기존 일반 축 기본값과 새 링크의 축 값 차이였다. 기본 진입 링크는 축을 강제하지 않고 공통 정책을 사용하도록 정리했다. 관련 단위 검사 22개가 후속 실행에서 모두 통과했다. 최초 실패를 삭제하거나 전체 단일 실행 통과로 합산하지 않는다.
- 축 브라우저 검사: Chromium·WebKit에서 고유 18개 검사를 두 실행으로 확인했다. 작은 가격·평탄 가격·넓은 가격 범위, 실제 음수 보조선의 일반 축 전환, 저장·날짜·확대 보존을 포함한다.
- Original 브라우저 검사: 최초 4개 통과·2개 실패에서 오류 상태의 준비 안내 중복을 발견했다. 이를 수정하고 정상·실패 상태의 부정확한 안내 부재까지 포함한 6개가 양 엔진에서 재시도 없이 통과했다.
- 설명·사전: 76항목을 양 엔진에서 순회했다. 통합 52개 중 50개 통과·2개 실패 후, 같은 실패 사례와 문맥 보존·도식 검사를 포함한 8개가 통과했다. 실패는 지연 로딩 모의가 새 모듈 요청을 다시 가로막은 문제와 WebKit 프로세스 종료였다.
- VPS 관련 Python 133개, Node metadata 4개, 설명 관련 단위 94개가 통과했다. 실제 운영 백업·복원은 아직 별도 단계다.
- 독립 코드 검토에서 Original 모델 ID가 자체 회귀 전환에 남는 결함을 발견했다. 서로 다른 모델로 전환할 때 모델 설정을 제거하고, 같은 모델을 다시 열 때는 보존하도록 수정했다. 양방향 전환과 저장 URL의 모델·축 복원 단위 검사를 통과했다.
- 기존 상대 Markdown 링크, 150개 로고와 브랜드 메타데이터 검사, diff 공백 검사를 통과했다. 관계없는 사용자 변경과 개인 원본은 stage 대상에서 제외했다.
- 실제 브라우저 재검토에서 가격의 기본 로그축이 MVRV로 전달되고, 반대로 MVRV의 일반 축이 가격으로 전달되는 문제를 추가 확인했다. 다른 자산·지표·원천으로 이동할 때 이전 축을 제거하고 해당 차트의 사용자 선택을 복원하도록 수정했다. 같은 차트의 명시적 URL은 보존한다.
- 저장 대시보드에서 축 변경 후 기간을 바꾸면 이전 URL의 축이 되살아나는 경로를 수정했다. 현재 축과 모델 선택을 새 URL에 함께 반영한다. 관련 단위 32개와 새 브라우저 4개가 통과했다. 최초 4개 실패는 새 테스트의 닫힌 더보기 재열기 누락과 버튼 이름 불일치였으며, 그 기록도 보존했다.
- 사전의 기초 순서를 캔들·로그축·슈퍼트렌드·MVRV·비교로 수정했다. PR CI 중간 실행의 단위 951/952에서 일반 기초 안내에 BTC 전용 제목을 허용하지 않는 검사가 실패했다. 제목을 ‘코인 비교하기’로 정리하고 관련 설명 검사 13개를 통과했다.
- 배포 검사 파일 이름과 기존 증거 보존 조건을 12개 테스트로 확인했다. 기존 정규식이 잘못됐다는 최초 독립 검토는 raw 문자열 여부를 오독한 것이었으며 제품 결함으로 기록하지 않는다. 제품 정규식은 변경하지 않았다.
- PR CI `39099844873`의 타입·단위 953개·Node 59개·Python 135개·복구 2개와 컨테이너 검사는 통과했다. Chromium 전체 회귀는 270개 통과·8개 실패·1개 제외(15.2분, 재시도 0)였다. 6개는 교체된 설명 DOM·버튼에 대한 이전 검사였으며 공식·숫자 예시·접힘 검증을 새 공통 설명에 맞췄다. 2개 축 검사는 일반 축 0 눈금의 명시적 설정 누락과 150px보다 넓은 가격축을 제외하던 계측 오류였다. 실패 화면을 보존하고 제품 코드 변경 없이 축 검사 4개를 양 엔진에서 통과했다. 전체 회귀 통과 여부는 후속 CI에서 다시 판정한다.
- 같은 실행의 WebKit은 268개 통과·9개 실패·2개 제외(18.9분) 요약 뒤 20분 작업 제한으로 취소됐다. 추가 실패는 보고서 뒤로 복귀 시 초점보다 화면 위치 초기화가 늦는 문제였다. 보고서 진입 위치와 제목 초점을 같은 프레임에서 처리하도록 수정하고 390·1280px 양 엔진 4개와 타입검사를 통과했다. 동일 보고서 자동 갱신과 대시보드 복원 경로는 유지한다.
- 설명 흐름 후속 검사는 처음 9개 통과·3개 실패였다. 슈퍼트렌드의 마지막 응답 페이지만 계산 입력으로 쓰던 검사와 새 RSI 기간 적용 전에 확대 기준을 잡던 검사를 수정했다. DOGE/Binance/주봉 전체 응답을 시간별로 결합하고 실제 지표·기간의 준비를 기다린 뒤 계산·복원 단언을 유지했다. 같은 12개가 양 엔진에서 51.3초, 재시도 0으로 모두 통과했다.

로컬 검사 도중 저장 공간 부족·메모리 부족으로 중단한 실행은 제품 검사 통과로 계산하지 않는다. 비공개 작업 폴더에 원본 로그를 보존했다. 이전 생성 QA 파일은 바이트 해시가 같은 파일끼리 NTFS 하드링크로 중복 공간을 줄였고 경로·내용은 보존했다. 운영 데이터·다른 프로젝트는 변경하지 않았다.
