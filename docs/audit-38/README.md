## 0.38.2 사전 경로 수정

0.38.1 PR #80의 최종 CI `39106150598`은 5개 작업을 모두 통과했다. main `d43d4853ad112095e529359301152eb973edbd3c`의 첫 CI `39107436965`에서는 WebKit의 두 번째 DOGE 페이지 이동 중 네트워크 프로세스가 종료됐다. 해당 검사의 기능 단언에 도달하기 전 발생했으며, 로그·trace·화면을 보존했다. Chromium은 278개 통과·1개 제외, WebKit은 276개 통과·1개 실패·2개 제외였다. 같은 main의 해당 WebKit 검사를 로컬에서 3회 실행해 모두 통과했지만, 이 결과로 원격 실패를 지우지 않는다. 실패 작업의 원격 재실행은 아래 새 제품 결함을 발견해 취소했다. 이 엔진 종료와 사전 결함의 원인이 같다고 판단하지 않는다.

최종 수동 검사에서 `/learn?asset=DOGE` → MVRV 설명 → 차트 이동 시 사전이 미지정 `log=1`을 생성하는 결함을 재현했다. 캔들 설명의 차트 링크도 가격 지표를 명시하지 않아 MVRV로 열렸다. 새로운 사전 진입은 지표 공통 축 정책을 사용하고, 가격 기초 링크는 가격을 명시한다. 동일 차트에서 설명을 읽고 돌아올 때는 명시한 축·날짜·확대·모델을 보존하며, 다른 자산·원천·지표로 이동할 때 이전 차트의 축·모델 설정이 따라가지 않도록 수정한다. 새 회귀 검사와 최종 CI·운영 검증은 별도로 기록한다.

운영 DB와 기존 서비스를 보존한 상태에서 보리차트의 사용하지 않는 이미지 캐시 3개만 정리했다. 삭제 전 압축 복구 아카이브의 전체 SHA·이미지 계층과 모든 컨테이너 참조를 대조했고, 현재·이전 복구 릴리스와 아카이브는 유지했다. 관측된 여유 공간 증가는 424.51MiB이며 동시 쓰기의 영향을 포함한다. 전역 정리·강제 삭제·다른 프로젝트 변경은 하지 않았다. 과거 감사 SQLite 압축은 추정만 했고 실행하지 않았다.

사전 수정의 최종 관련 단위 42개와 Chromium·WebKit 18개가 재시도 없이 통과했다. 브라우저 실행은 42.0초이며 신규 MVRV·가격 기본축, 같은 분석의 날짜·확대 보존, 기존 링크의 코인·원천 변경, TAO·DRV의 실제 기본 거래소를 포함한다. 150개 자산의 기본·세 원천 선택 규칙도 공통 원천 정책과 대조했다. 로컬 IAB에서 DOGE 사전 → MVRV 일반축, 캔들 설명 → 가격 로그축을 수동으로 확인했다. 이는 fixture 기반 검사이며 실제 운영 데이터 검증과 구분한다.
