# 0.38 검증 기록

기준일: 2026-10-18. 구현·검증 진행 중이다. 코드, 계산, 실제 화면, 배포, 사람 대상 검사를 분리한다.

## 보호 범위

기존 `docs/audit-31`의 사용자 변경과 별도 제품 기획 문서는 이번 변경에 포함하지 않는다. 개인 자료·브라우저 저장 키·작업공간 버전 1·2와 기존 레인보우 모델 ID는 보존한다.

## 수정 전 확인

- 가격·슈퍼트렌드의 일반 축 기본값과 지표 전환의 강제 `log=0` 경로를 확인했다.
- 대시보드에서 확대할 때 일부 지표의 축 정책이 달라졌다.
- 양수 가격만 사용하는 Chromium 재현에서 `$-0.00004000` 눈금이 나타났다. 수정 전 실패와 trace를 비공개 작업 폴더에 보존했다. 실제 DOGE 화면의 음수 눈금과 테스트의 인위적 양수 가격 표본을 구분한다.
- 사전의 상단 카드, 현재 코인과 맞지 않는 BTC 제목, 자체 레인보우 도식 ID 불일치와 상세 설명 연결 누락을 확인했다.

## 운영 기준점

04:22 UTC 읽기 조회에서 운영 릴리스는 `vps-cd0636019209d1d0`(0.36.1)이다. 여유 공간 20.57GiB, 기존 7개 서비스 healthy, 핵심 BTC·DOGE·ETH 양 거래소 6개는 실패 0·실제 거래 13~71초 전이었다. 이 표본은 모든 자산의 신선도나 과거 이력 완전성을 의미하지 않는다.

0.37 배포 도구의 Compose 자원 제한 직렬화 수정 PR #78은 별도 CI 5개 통과 후 main `e6783dc4263b2624e337bb370e44de3eccfa55c8`로 병합했다. 이번 0.38 검증과 합산하지 않는다.

## 로컬 구현 검증

- 타입검사 최초 실행은 통과했다. 이후 전체 검사를 병행한 환경에서 메모리 부족이 발생했고, 512MiB로 제한한 재검사 역시 메모리 부족으로 종료됐다. 최종 타입·빌드는 원격 CI로 다시 판정한다.
- 전체 단위 검사: 89개 파일, 950개 중 947개 통과·3개 실패. 실패는 기존 일반 축 기본값과 새 링크의 축 값 차이였다. 기본 진입 링크는 축을 강제하지 않고 공통 정책을 사용하도록 정리했다. 관련 단위 검사 22개가 후속 실행에서 모두 통과했다. 최초 실패를 삭제하거나 전체 단일 실행 통과로 합산하지 않는다.
- 축 브라우저 검사: Chromium·WebKit에서 고유 18개 검사를 두 실행으로 확인했다. 작은 가격·평탄 가격·넓은 가격 범위, 실제 음수 보조선의 일반 축 전환, 저장·날짜·확대 보존을 포함한다.
- Original 브라우저 검사: 최초 4개 통과·2개 실패에서 오류 상태의 준비 안내 중복을 발견했다. 이를 수정하고 정상·실패 상태의 부정확한 안내 부재까지 포함한 6개가 양 엔진에서 재시도 없이 통과했다.
- 설명·사전: 76항목을 양 엔진에서 순회했다. 통합 52개 중 50개 통과·2개 실패 후, 같은 실패 사례와 문맥 보존·도식 검사를 포함한 8개가 통과했다. 실패는 지연 로딩 모의가 새 모듈 요청을 다시 가로막은 문제와 WebKit 프로세스 종료였다.
- VPS 관련 Python 133개, Node metadata 4개, 설명 관련 단위 94개가 통과했다. 실제 운영 백업·복원은 아직 별도 단계다.
- 독립 코드 검토에서 Original 모델 ID가 자체 회귀 전환에 남는 결함을 발견했다. 서로 다른 모델로 전환할 때 모델 설정을 제거하고, 같은 모델을 다시 열 때는 보존하도록 수정했다. 양방향 전환과 저장 URL의 모델·축 복원 단위 검사를 통과했다.
- 기존 상대 Markdown 링크, 150개 로고와 브랜드 메타데이터 검사, diff 공백 검사를 통과했다. 관계없는 사용자 변경과 개인 원본은 stage 대상에서 제외했다.

로컬 검사 도중 저장 공간 부족·메모리 부족으로 중단한 실행은 제품 검사 통과로 계산하지 않는다. 비공개 작업 폴더에 원본 로그를 보존했다. 이전 생성 QA 파일은 바이트 해시가 같은 파일끼리 NTFS 하드링크로 중복 공간을 줄였고 경로·내용은 보존했다. 운영 데이터·다른 프로젝트는 변경하지 않았다.
