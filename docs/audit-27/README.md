## 검사와 발견 사항

- 초기 타입·단위 685개, 서버 22개, VPS 22개, 복원 2개 통과. 추가 진단 및 API 검사는 최종 CI에서 재확인합니다.
- 첫 전체 브라우저 실행: 212개 통과·2개 opt-in 제외·2개 실패. 실패는 모바일 로딩 문장이 사라질 때 목록 위치가 바뀌는 것으로 재현했습니다. 중복 로딩 문장을 제거하고 관련 회귀를 다시 검사합니다. 실패 기록을 통과로 바꾸지 않습니다.
- 별도 병렬 fixture 실행 2회는 준비 시간 안에 서버가 시작하지 못했습니다. 전체 실행과 분리한 fixture로 재검사하며 제품 데이터 장애로 표현하지 않습니다.
- 첫 PR 컨테이너 감사는 기존 Node 기본 이미지의 OS 패키지와 포함된 npm 의존성에서 수정 가능한 취약점을 발견해 차단했습니다. 런타임 OS 보안 업데이트와 운영에 쓰지 않는 npm/corepack/yarn 제거로 수정하며, 차단 조건을 낮추지 않습니다.
- 고정 한국어 검색 과제 100/100·잘못된 자산 0, 별도 150개 정확 티커 식별 검사. 원천 응답 속도나 사람 사용성 검사와 구분합니다.
- 고정 모델 `intfloat/multilingual-e5-small`, 리비전 `614241f622f53c4eeff9890bdc4f31cfecc418b3`, 공식 `onnx/model_qint8_avx512_vnni.onnx`: 결합 검색 개선 0%p → 운영 비활성. VPS 메모리·시세 회귀의 모델 활성화 게이트를 통과했다고 표현하지 않습니다.
