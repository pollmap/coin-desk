## 검색과 사용자 흐름

모바일 검색과 상단 검색이 같은 시트를 사용합니다. 티커·한글/영문 별칭 → 코인과 목적 → 설명 본문 순으로 찾습니다. `비트코인 고평가`는 가치평가 지표로 연결하며 검색어를 매수·매도 판단으로 해석하지 않습니다. 선택 코인·원천·기간·날짜를 보존하고 취소·늦은 응답·미지원 링크를 격리합니다.
