## 현재 실행 환경의 차단

- GitHub 쓰기 도구는 `MCP tool call requires approval, but approval policy is never`로 원격 브랜치 생성을 거절했습니다. 사용자의 배포 승인 부족이 아니라 실행 환경의 승인 정책입니다. 같은 정책을 우회하는 다른 쓰기 경로를 사용하지 않습니다.
- GitHub shell 연결과 기존 인증을 사용한 Wrangler 사전 조회는 외부 연결에 실패했습니다. 2026-10-01의 `wrangler whoami`도 `fetch failed`였으므로 공식 D1 일간 총량을 조회하지 않았습니다. 인증 만료나 제품 API 장애로 단정하지 않습니다.
- 공개 API URL을 in-app 브라우저에서 직접 열려던 요청은 `net::ERR_BLOCKED_BY_CLIENT`로 차단됐습니다. 기존 `/status`와 알림함의 공개 UI 및 로그인 후 원격 DB를 읽었으며 이번 공개 API 전수 검증은 완료로 표시하지 않습니다.
- 사용자의 **로그인 완료** 답변 후 Chrome의 Cloudflare 관리 UI 인증을 확인하고 원격 SELECT 검증을 완료했습니다. 비밀번호·쿠키·브라우저 프로필·토큰을 추출하지 않았습니다.
- D1 계정 전체 대시보드는 현재 날짜 부분 총량만 제공하고 과거 날짜 선택을 노출하지 않았습니다. Cloudflare가 소유·관리하는 공식 GraphQL API Explorer에 계정·영역 읽기 권한으로 연결했지만 `Type AccountImagesUniqueGroupsDimensions must define one or more fields.`라는 클라이언트 스키마 오류가 쿼리 결과를 막았습니다. 공식 도구의 스키마 새로고침 후에도 같았습니다. **로그인 실패나 Coin Desk 제품 장애가 아닙니다.** DB 하나의 최근 24시간·상위 쿼리 insights·오늘 부분 총량으로 9월 30일 계정 전체 비용을 대체하지 않습니다. [비용 확인 시도](d1-daily-20260930-unverified.json)

기존에 승인된 GitHub 쓰기를 수행할 수 있는 실행 환경과 공식 계정 일간 지표를 반환하는 조회 경로가 있어야 남은 원격 관문을 끝낼 수 있습니다. Cloudflare 사용자 로그인은 이미 완료됐으므로 반복 요청하지 않습니다. 임시 후속 자동화와 제품 Cron은 중지하지 않았습니다.

실제 Apple Safari·VoiceOver는 사용 가능한 기기가 없어 **실기기 검증 대기**입니다. X 추가 수집·개인 자료 전수 검토·유료 데이터·추가 거래소·신규 DB는 이번 마감 범위에서 제외하며 개인 원본을 보존합니다.
