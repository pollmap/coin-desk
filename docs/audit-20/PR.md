# 지표를 주 차트로 선택하는 Coin Desk 0.20

첫 화면을 BTC MVRV 최근 5년으로 바꾸고, 분석 영역·시각화·추가 지표를 거치는 조작을 단일 지표 목록으로 통합합니다. 여덟 코인을 전환할 때 지원 지표·통화를 유지하며 미지원 MVRV는 RSI로 안내하고, 직접 입력한 미지원 링크는 데이터 요청 없이 이유와 대안을 표시합니다.

기존 730일 가격 위치 밴드와 별개인 BTC USD 로그회귀 레인보우를 추가했습니다. 표시일 이전 표본만 쓰고 계수·기간·버전을 공개합니다. 날짜 탐색, 비교 추가, 자동 갱신 및 저장·공유 복원을 보존하고, 사전과 실제 계산·단위·코인 문맥을 맞췄습니다. 가격·보조 지표는 별도 패널에 두며 자료함과 고급 분석은 필요할 때 로드합니다.

검증: 타입·단위 476개, 복구 2개, 독립 Decimal 검산, 브랜드·문서·빌드. 최종 Chromium/WebKit 결과는 verification.json에 기록합니다. API 실패·지연·미지원·PEPE 단위·전체 기간·사용자 확대·공유·저장·여섯 화면 너비·양 테마·키보드·200%·axe를 포함합니다. 재시도는 0이며 Apple 실기기 검증과 개인 자료 전수 검토는 별도 대기입니다.

배포는 Pages만 변경합니다. 수집 Worker·상태 API·D1 스키마·확장·Cron은 유지합니다. 현재 실행 환경은 GitHub 쓰기 승인 정책 및 Cloudflare 외부 연결이 차단되어 PR 생성과 운영 반영을 완료하지 못했습니다.
