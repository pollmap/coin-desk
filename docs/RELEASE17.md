# 0.17 · 설명에서 실제 분석까지

사용자가 지표 이름을 모르면 차트 도구를 찾기 어렵고, 설명을 찾았어도 다시 코인·원천·기간을 설정해야 했습니다. 이번 개편은 **분석 사전 → 내 차트에 적용 → 실제 조건 확인 → 저장·공유**를 하나의 흐름으로 연결합니다.

## 사용할 수 있는 것

- `/learn`에서 한국어·영문·별칭 검색, 7개 분류, 즐겨찾기를 사용합니다. 현재 기능에 대응하는 70개 설명을 제공합니다. 기본은 핵심 설명이며 자세한 산식은 펼쳐 봅니다. 읽기 방식과 즐겨찾기는 현재 기기에 보관합니다.
- 각 설명에서 BTC·DOGE·ETH와 USD 참조·Upbit KRW·Binance USDT를 고릅니다. 지원하는 원천으로 실제 차트를 엽니다. BTC 전용·ETH 체인 지표, 거래량·실제 OHLC가 필요한 기능은 지원 범위를 명시합니다. 온체인 지표는 실제 관측 목록도 확인합니다.
- 차트 도구막대의 도움말과 지표 근거에서 해당 설명을 엽니다. 설명으로 이동할 때 코인·가격 원천·봉·날짜 구간을 유지합니다. 사전의 검색어·분류·즐겨찾기 필터는 목록으로 돌아갈 때 유지하고 차트 URL에는 넣지 않습니다.
- 목적별 시작은 가격 흐름(이동평균 리본·RSI), BTC 평가(MVRV), 선물 쏠림(확정 펀딩률), 과거 분포(계절성)입니다. 설명만 있는 가짜 분석 버튼을 만들지 않습니다.
- 상승/하락 장악형, 도지형, 망치형, 교수형, 역망치형, 유성형, 잠자리/비석 도지형의 9개 캔들 조건을 선택할 수 있습니다. 가격 차트의 작은 기호와 날짜별 목록을 통해 해당 구간으로 이동합니다. 몸통·꼬리·이전 종가·이동평균을 확인하고 판정 설명을 다시 엽니다.
- 패턴 선택과 추세 필터는 기존 작업공간 v2와 공개 차트 링크로 복원합니다. 원문·이미지·개인 메모를 링크에 넣지 않습니다. 코인 변경은 이전 패턴의 선택 초점을 제거합니다.
- 수평선·추세선·평행 채널·구간 측정 설명에서 해당 주 차트 도구를 활성화합니다. 빠른 두 번째 클릭을 생략하던 라이브러리 클릭 처리도 보완했습니다. 그리기 중에는 주석 레이어가 실제 좌표를 받으며, 완료·Escape 이후 기존 차트 조작으로 복귀합니다.

## 판정 기준

산식 버전은 `coin-desk-candles-1`입니다. TradingView의 개념·분류를 참고하되 아래 수치를 자체 공개 규칙으로 구현했습니다. 타사 탐지 결과와 일치한다고 표시하지 않습니다.

| 구분 | 실제 기준 |
|---|---|
| 입력 | 선택 거래소의 확정 OHLC. 유한한 양수 가격, 유효한 고저 범위, 음수 아닌 거래량, 봉 간격에 맞는 종료 시각. 진행 봉·미래 마감·손상 봉 제외 |
| 장악형 | 반대 방향의 직전 몸통 전체를 포함하며 현재 몸통이 더 큼. 고가·저가까지 포함할 필요 없음 |
| 중립 도지 | 몸통이 전체 고저 범위의 10% 이하. 고저 범위가 0인 봉 제외. 추세 필터 제외 |
| 망치·교수 | 몸통이 고저 범위의 10% 초과, 아래꼬리 ≥ 몸통 2배, 위꼬리 ≤ 몸통 0.5배 |
| 역망치·유성 | 몸통이 고저 범위의 10% 초과, 위꼬리 ≥ 몸통 2배, 아래꼬리 ≤ 몸통 0.5배 |
| 잠자리·비석 도지 | 몸통 ≤ 범위 10%, 짧은 꼬리 ≤ 범위 10%, 긴 꼬리 ≥ 범위 60% |
| 기본 추세 | 패턴이 완성되기 직전 확정 종가와 SMA50 비교. 상승형은 종가 < SMA50, 하락형은 반대 |
| 강화 추세 | SMA50 < SMA200(상승형) 또는 반대(하락형)를 추가. 200개 연속 표본 필요 |
| 추세 끄기 | 형태만 확인. 망치·교수 등 같은 모양의 분류가 겹칠 수 있음 |
| 결측·정렬 | 누락·잘못된 봉·중복/역순 시 추세 표본 초기화. 누락을 연결해 장악형을 생성하지 않음 |

날짜는 UTC입니다. 해당 원천·봉의 확보 기간에서 관찰하며 새로 확보한 과거 이력에 따라 표시 개수는 달라질 수 있습니다. 현재 클라이언트 차트 계산 기능이며 매수·매도 명령, 검증된 승률 또는 새로운 서버 알림 규칙을 의미하지 않습니다. 실제 OHLC가 없는 USD 일별 참조로 캔들을 만들어내지 않습니다.

## 참고한 구조와 적용 판단

[TradingView 고객지원](https://kr.tradingview.com/support/)의 검색·주제별 탐색·관련 설명 구조와 [상승 장악형 설명](https://kr.tradingview.com/support/solutions/43000583771/)의 정의·추세 확인을 참고했습니다. [패턴 분류](https://www.tradingview.com/support/solutions/43000752737-candlestick-pattern-in-screener/)의 상승·하락·중립 명칭은 해석 방향이며 확률 등급을 임의로 붙이지 않습니다.

기술적 지표의 기본 정의는 [SMA](https://www.tradingview.com/support/solutions/43000696841-simple-moving-average/), [EMA](https://www.tradingview.com/support/solutions/43000502589-moving-averages/), [RSI](https://www.tradingview.com/support/solutions/43000502338-relative-strength-index-rsi/), [볼린저밴드](https://www.tradingview.com/support/solutions/43000501840-bollinger-bands-bb/), [MACD](https://www.tradingview.com/support/solutions/43000502344-moving-average-convergence-divergence-macd-indicator/) 원문과 기존 계산 코드를 대조했습니다. 적용한 기본값·원천 제약은 Coin Desk의 실제 구현을 기준으로 작성했습니다. 온체인 설명은 기존 지표 메타데이터와 공식 원천 링크에서 가져와 화면과 정의가 따로 바뀌는 것을 줄였습니다.

다른 서비스의 전문·화면·이미지를 복제하지 않았습니다. 캔들 예시 SVG는 자체 생성한 설명용 OHLC이며 실제 시세와 구분합니다. 이 릴리스가 TradingView의 전체 기능, Pine Script, 모든 패턴이나 유료 데이터 제공을 뜻하지 않습니다.

## 구현·검증 경계

React·Lightweight Charts·Cloudflare 구조를 유지합니다. 새 의존성·운영 스키마 변경·분석 사전용 수집 호출을 추가하지 않았습니다. 기존 시장·선물·온체인 Cron과 개인 자료함은 유지합니다. 공개 리서치나 별도 역사 메뉴는 복원하지 않습니다.

[검증 및 배포 기록](audit-17/README.md)에서 코드·CI·운영 상태를 구분합니다. 실제 Apple Safari·VoiceOver, 사용자 Chrome 확장 설치·로그인 X 전체 수집/내용 검토, 완전한 UTC 하루 운영 비용과 엄격한 48시간 안정성은 기존의 별도 확인 항목입니다.

## 0.17.1 · 시세 수집 오류 분리

0.17.0 배포 후 점검에서 오래된 PEPE Upbit 시세 한 건이 거래소 묶음 전체의 재시도 시간을 늘리는 기존 문제를 확인했습니다. 다음 분의 정상 BTC·DOGE·ETH 시세도 함께 건너뛸 수 있었습니다.

- 개별 시세 누락·유효성 오류는 해당 코인의 재시도·이전 스냅샷·오류 상태로 관리합니다. 정상 코인은 기존 60초 목표로 확인합니다.
- 실제 거래소 요청 자체가 실패한 경우에는 거래소 전체의 지수형 재시도를 유지합니다. 그 분에 대상 코인이 하나뿐이었다고 요청 장애로 오인하지 않습니다.
- 마지막 체결 시각을 현재 시각으로 바꾸거나 300초 유효성 기준·상태 지연 기준을 완화하지 않습니다. 조용한 시장의 오래된 체결은 계속 지연/오류로 드러납니다.
- 격리 DB로 여러 분의 수집을 재현해 오류 전파, 실패 자료 보존, 부분 재시도, 전체 장애와 복구를 검사합니다. 이 수정은 새로운 원천이나 유료 서비스를 추가하지 않습니다.
