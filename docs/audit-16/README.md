0.16.0 첫 배포는 원격 D1 확인에서 API 7403 인증 실패로 중단됐고 Worker를 진행하지 않았습니다. 같은 자격으로 계정·DB·스키마 조회가 성공한 뒤 한 차례 재실행해 복구했습니다. 일시적 실패의 정확한 원인은 확정하지 않았습니다. 0.16.1은 빌드 → 원격 마이그레이션 확인 → 수집 Worker → main Worker → Pages 순서로 성공했습니다. 문서만 추가하는 커밋은 반복 배포하지 않습니다.

## 실제 운영 확인

- [API와 다운로드](production.json): 원천 103/103 정상, health 200, signals·briefings·ETH TVL 및 BTC·DOGE·ETH MVRV·펀딩 API 200. 확장 ZIP 9개 파일 CRC 정상, 개인 파일 없음. 확장 버전은 0.16.0이며 UI 보완 0.16.1에서 변경하지 않았습니다.
- [운영 Chrome 여섯 화면](browser-production.json): 핵심 세 코인의 온체인·선물이 각각 해당 주 지표로 열립니다. 1440×675 실제 화면에서 모두 차트 시작 위치 246px, 전체 이력 준비 상태를 확인했습니다. 1280×800의 260px 이내 기준은 Chromium/WebKit CI로 별도 확인했습니다.
- [자연 Cron](natural-cron.json): 수집 API를 직접 호출하지 않는 관찰 구간에 6개 분 단위 실행이 완료됐습니다. 배경 원천 작업 1개와 예약할 작업이 없는 정상 idle 5개를 구분합니다. 독립 시세 경로에서는 BTC·DOGE·ETH × Binance·Upbit 6개가 모두 증가했고, 최근 펀딩·미결제약정·롱 계정 비중도 세 코인 모두 새 관측으로 갱신됐습니다. 검증 SELECT의 쓰기 행 수는 0입니다.
- 과거 수집 예약 예산과 커서는 현재 조회 결과가 비어 있습니다. 생성되지 않은 키를 유실로 판정하지 않습니다. 하루 후보 10,000개 제한 코드는 유지합니다.
- [공식 계정 일간 부분 집계](d1-partial-day.json): 2026-09-27 15:57 UTC 읽기 2,861,014행·쓰기 35,837행. 계정 전체 집계이며 무료 한도 이내지만 최종 배포 이후 하루 전체 검증은 아닙니다.
- 최신 브리핑은 2026-09-27 기록입니다. 다음 날 자동 생성과 최종 배포 이후 첫 완전한 UTC 하루 2026-09-28 총량은 추가 확인합니다. 총량 조회는 2026-09-29 01:00 UTC 이후 진행합니다.
- 현재 원천 정상과 `observation48h.ready=false`를 구별합니다. 과거 중단이 포함된 엄격한 48시간 창을 초기화하거나 기록률 99%·최장 공백 180초 기준을 느슨하게 바꾸지 않았습니다.

원격 관찰은 `cron_runs`의 최근 완료 시각·결과, 핵심 `ingestion`의 `last_success`와 `data_as_of`, `state`의 `budget:derivatives-backfill`·`cursor:derivatives:%`, `daily_briefings`를 SELECT로 대조합니다. 사용자 방문 또는 강제 수집을 성공 증거로 대신하지 않습니다. 제품의 `btc-desk`·`btc-desk-quotes` 매분 Cron은 계속 실행하며 다른 서비스의 Cron은 변경하지 않았습니다.

## 차트·자료함 검증

- 1,100개 일별 관측의 전체 기간을 초기 진입·크기 변경 뒤 유지합니다. 직접 확대 후 갱신, 날짜 공유 복원, 원천별 주석 분리, 날짜 창 Escape 포커스 복귀를 검사했습니다.
- 확정 봉·누락일·거래량 0·윤년·불완전 연도·평균과 중앙값·사이클 정규화·미래 관측 차단·재돌파 중복을 계산 회귀로 확인했습니다. 적용 산식은 [RELEASE16](../RELEASE16.md)에 정리했습니다.
- Chromium/WebKit에서 개인 글 가져오기·중복·변경 이력·차트 연결, 용량 부족 뒤 기존 자료 유지, 백업 복원과 손상 이미지 해시 거절을 검사했습니다. 320·390·768·1000·1280·1440px, 양 테마, 키보드·200% 확대·axe 검사를 포함합니다.
- 기존 보관 6,227행·4,387개 이미지의 ID·파일 참조 대조에서 중복 ID·누락·빈 파일·손상 파일이 없었습니다. Pillow 파일 구조 검증과 SHA-256 복사 대조이며, 본문·이미지 전체 내용 검토를 뜻하지 않습니다.
- 격리 Chromium에서 준비 폴더 전체 6,248건(기존 글 + 첨부 21장), 이미지 4,408개를 실제 가져왔습니다. 오류·미연결 0, 검색 5초 이내, 화면 목록 15행 이하, 재접속 후 보관을 확인했습니다. 사용자의 운영 브라우저로 자동 이전한 결과는 아닙니다.
- 일반 CI에서 개인 원본 경로가 필요한 opt-in 2개는 제외합니다. 위 전체 가져오기는 실제 로컬 자료를 사용하는 별도 실행 결과입니다. 원본과 계정별 상세 해시는 공개 저장소에 넣지 않습니다.

## Chrome 확장 검증

- [격리된 실제 MV3 실행](extension-runtime.json): Chrome 메시지·탭·저장 API로 화면 글 읽기 → 자료함 연결 → 전송 → 재접속 보관을 확인했습니다. X 화면은 통제한 fixture이며 실제 로그인 수집과 구분합니다.
- 서비스 워커의 중지 후 늦은 완료 이벤트 거절, 닫힌 탭의 체크포인트 복원, 계정별 집계, 전송 실패·재시작 위치 보존을 검사했습니다.
- 고정 전송 묶음에서 500개 글·20개 이미지 이내로 나누고 이미지 데이터는 192KB 단위로 보냅니다. 이미지 중간 전송 → 자료함 새로고침 → 연결 재생성 → 재개와 미등록 이미지 거절을 양 엔진에서 확인했습니다.
- 긴 작업은 `큰 창에서 계속하기`로 동일 확장 탭에서 진행합니다. 명령은 같은 확장의 `popup.html`만 허용하며 일반 웹 페이지가 서비스 워커 수집 명령을 실행할 수 없습니다.
- [설치 안내](https://coin-desk.pages.dev/extension-guide.html)와 [ZIP](https://coin-desk.pages.dev/downloads/coin-desk-importer.zip)이 운영에서 열립니다. ZIP SHA-256: `c9b3e60fa065dfabb0da0e3ae7370ae7089b24b85261ca0577db368b2467cca6`.

## 실제 남은 확인

1. **사용자 Chrome에 로컬 확장 설치 및 로그인 X 수집:** fixture 검증과 별개입니다. 북마크·계정 전체 과거 범위 확보나 전수 내용 검토를 완료했다고 표시하지 않습니다. 설치 후 사용자가 시작하는 가져오기이며 서버 Cron으로 개인 X를 읽지 않습니다.
2. **개인 폴더를 사용할 브라우저에 가져오기:** `work/private-import/IMPORT-README.txt`를 따릅니다. 사이트·브라우저 원점마다 별도 저장되며 다른 기기로는 백업을 이용합니다.
3. **실제 Safari·VoiceOver:** 실기기 미검증입니다. Chromium/WebKit/axe 통과로 대체 표기하지 않습니다.
4. **하루 비용·다음 날 브리핑·48시간 안정성:** 임시 후속 자동화를 유지하고 실제 기간이 충족된 뒤 판정합니다. 모든 운영 조건 충족 시 임시 후속 자동화만 중지하며 제품 Cron은 유지합니다.

개인 자료는 `work/private-import`에 별도 준비하며 Git·프로덕션 빌드·소스 ZIP에서 제외합니다. 공개 기능과 확장 코드는 개인 데이터 없이 배포했습니다.
