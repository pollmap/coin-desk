# 0.16 검증 기록

현재 작업 브랜치 `codex/analysis-library-016`. 코드 검증과 운영 배포, 개인 자료 내용 검토를 구분합니다.

## 확인한 결과

- 타입검사·48개 파일 368개 단위/회귀 테스트 통과. 기존 DB 복구 2개 검사 통과. 프로덕션 빌드 및 확장 9개 파일 CRC 검사 통과.
- 1,100개 일별 관측의 전체 기간을 초기 진입·크기 변경 뒤 유지하고, 1280×800의 차트 시작 위치 260px 이내를 Chromium/WebKit에서 확인했습니다.
- Chromium/WebKit에서 개인 글 가져오기·중복·변경 이력·가격/온체인 차트 연결·다른 원천의 주석 분리, 저장 용량 부족 뒤 기존 글 유지, 확장의 표면 DOM 읽기·대상 게시물 분리·nonce 전송과 날짜 창 Escape 포커스 복귀를 포함한 수정 후 16개 회귀 검사 통과. 별도 양 엔진 백업/복원 검사에서 새 저장소 복원과 손상 이미지 해시 거절 확인.
- 기존 보관 6,227행·4,387개 이미지의 ID·파일 참조 대조: 중복 ID·누락·빈 파일·손상 파일 없음. Pillow 파일 구조 검증과 SHA-256 복사 대조입니다. 본문·이미지 전체 내용 검토를 뜻하지 않습니다. 원본과 계정별 상세 해시는 공개 저장소에 넣지 않습니다.
- 격리한 Chromium에서 준비 폴더 전체 6,248건(기존 글+첨부 21장), 이미지 4,408개를 실제 가져왔습니다. 오류/미연결 0, 검색 5초 이내, 화면 목록 15행 이하, 재접속 후 보관 확인. 사용자의 운영 브라우저에 자동 이전한 결과는 아닙니다.
- 확장 서비스 워커의 중지 후 늦은 완료 이벤트 차단, 닫힌 탭 재개 시 체크포인트 보존, 다음 계정의 집계 분리 3개 추가 검사 통과.

## 진행 중인 확인

- 로컬 Chromium/WebKit 전체 48개 브라우저 회귀 통과(4분). 개인 원본 경로를 요구하는 opt-in 검사 두 개는 일반 실행/CI에서 제외하며 별도의 실제 전체 가져오기 결과는 위에 기록했습니다. 첫 전체 실행의 실패는 테스트 서버 WebSocket 설정, WebKit 저장 공간 오류 주입과 실제 날짜 창 Escape 포커스 복귀에서 발견했고 모두 수정했습니다. 최종 CI에서도 전체 검사를 실행합니다.
- 실제 Chrome에 확장을 설치한 로그인 X 수집은 자동 fixture 검증과 별도입니다. 사용자의 확장 설치, 접근 가능한 과거 범위, 북마크 전체 수집 및 자료 전수 검토를 완료했다고 표시하지 않습니다.
- 실제 Safari·VoiceOver 실기기는 미검증입니다. 자동 WebKit/axe 통과와 구별합니다.
- 운영 배포 식별자, 공개 API, 자연 Cron·계정 하루 총량은 배포 후 추가 기록합니다. 기존 임시 후속 자동화는 이 조건 확인 전 중지하지 않습니다.

개인 자료는 `work/private-import`에 별도 준비하며 Git·프로덕션 빌드·소스 ZIP에서 제외합니다. 공개 기능과 확장 코드는 개인 데이터 없이 배포합니다.
