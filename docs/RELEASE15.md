# 0.15 통합 분석 작업공간

기준일: 2026-09-26 KST. 구현 버전 0.15.0. **운영 배포 완료, 하루 쓰기 사용량·지연 원천 후속 관찰 중**.

BTC를 중심으로 DOGE·ETH의 가격과 분석 지표를 한 화면에 모았습니다. 최신 요청에 따라 공개 리서치와 역사 화면·예약 수집은 이번 제품 범위에서 제외했습니다. 기존 데이터와 이전 릴리스 기록은 보존했습니다.

## 구현 결과

- 탐색 메뉴: 코인 분석 / 시장·비교 / 내 작업공간. 상태·브랜드는 보조 메뉴입니다.
- 큰 코인 선택, BTC·DOGE·ETH 빠른 전환, 선택 가격과 가격 원천을 같은 상단에 배치했습니다.
- 새 진입은 BTC·USD 참조·전체·로그축입니다. 명시된 기존 URL/저장 설정을 보존합니다.
- USD 참조, Upbit KRW, Binance USDT를 구분합니다. 통화 변경 시 가격·가격 지표·수익률이 함께 바뀝니다. 참조가격은 일별 종가입니다.
- 가격·기술 탭에서는 가격 아래 비교 지표를 기본 두 개, 선택 시 최대 여섯 개로 표시합니다. 한 Lightweight Charts 인스턴스의 pane을 사용해 시간축·커서·확대 구간을 공유합니다. MACD 세 선은 하나의 pane에 표시합니다.
- 온체인·선물 탭은 선택한 지표가 주 차트입니다. 탭 아래에서 지표를 선택하면 바로 아래 차트가 바뀝니다. 가격은 `가격과 비교`를 켰을 때만 작은 보조 pane으로 표시합니다. 이 탭에서는 봉 간격·가격 위치 밴드·이동평균·로그축 도구를 숨기고 지표·기간·근거에 집중합니다.
- 지표 목록은 이름·원천·단위·확보 여부와 가능한 현재값·작은 추세선으로 구성합니다. 관측 전에는 값을 만들지 않습니다. 코인 변경 시 다른 코인 전용 지표 선택을 제거합니다.
- 코인별 730일 가격 위치 밴드, 낙폭, 월별 수익률, BTC 상대강도를 제공합니다. 누락 날짜는 연결·보간하지 않습니다. 월봉 지표는 실제 달력 월을 사용합니다.
- 거래소 고급 차트의 추세선·수평선·사용자 지표 설정을 유지합니다.
- CSV·이미지·URL 공유, 날짜별 표, 저장 도구는 접힌 보조 영역에 모았습니다.
- 주요 조작 44px, 포커스 표시, 대화상자 Escape/포커스 복원, 키보드 관측 탐색, 표 형태 데이터를 적용했습니다. 실제 Safari·VoiceOver는 검증하지 않았으며 WCAG 전체 적합 인증을 의미하지 않습니다.

## 관찰 신호·브리핑

규칙은 200일 단순평균 돌파/이탈, RSI 30·70 경계, 지원 MVRV의 1 통과, 실제 정산 펀딩률의 양/음 전환입니다. 연속된 확정 관측만 계산하며 매수·매도 지시를 만들지 않습니다.

신호에는 자산·원천·단위·기준 봉·시각·이전/현재값·조건·산식 버전이 있습니다. 최초 이력 입력에는 알림을 만들지 않습니다. 이후 새 관측의 경계 통과만 알림 대상으로 저장하며 반복 실행은 중복 알림을 만들지 않습니다. 원천 정정은 이전 payload를 보관하고 revision/status를 변경합니다. 원천 누락은 자동 철회로 처리하지 않습니다.

관찰 수집은 최근 8일의 신호를 재검사합니다. 모든 과거 시점의 신호를 소급 수집하는 백테스트 서비스가 아닙니다. 기기 읽음과 관심 규칙은 localStorage에만 저장됩니다. 외부 메시지·이메일·푸시를 발송하지 않습니다.

브리핑은 매일 09:10 KST 이후 해당 날짜에 한 번 생성합니다. 중단 후 재개되면 당일분을 생성하며 실제 생성시각을 기록합니다. BTC·DOGE·ETH의 확보된 최신 확정 참조 종가, 연속일 변화, 새 신호 수와 누락 상태를 저장합니다. 과거에 생성되지 않은 브리핑을 만들어 내지 않습니다.

DefiLlama 스테이블코인 공급은 `totalCirculatingUSD`의 통화별 USD 환산 값을 합산합니다. TVL 및 스테이블코인 공급은 Ethereum 체인 지표이며 ETH 토큰 시가총액이 아닙니다.

반복 상태 저장은 동일 값이면 생략합니다. 시세는 행 삭제·재삽입 대신 같은 키를 갱신합니다. 선물과 ETH 이력은 JSON 일괄 저장으로 쿼리 수를 줄이고 값이 변경된 행만 갱신합니다. 이 수정만으로 무료 일일 한도 내 장기 운영이 입증된 것은 아닙니다.

## API·호환

- `GET /api/v1/signals?asset=BTC&limit=100`: 최대 100건, `nextCursor`는 `시각|ID`; 다음 요청의 `cursor`에 URL 인코딩합니다. 같은 시각의 여러 신호도 빠짐없이 페이지를 넘깁니다.
- `GET /api/v1/briefings`: 최근 브리핑, `before`·`limit` 지원.
- `GET /api/v1/chain-context?asset=ETH&metric=tvl`: `tvl` 또는 `stablecoins`.
- 지표 카탈로그는 지원 자산·실제 관측 수·범위·단위·최근값을 추가합니다. 해당 원천이 없는 지표는 선택을 제한합니다.
- URL은 `asset`, `price_source`, `market`, `period`, `interval`, `indicators`, `panels`, `visual`, `log`, `signal`, `compare_price`을 보존합니다. `/chart/:asset`, `/onchain/:asset`, `/futures/:asset`는 통합 화면을 엽니다. `/technical/:asset`는 기존 고급 차트입니다.
- `/research`, `/history`는 현재 쿼리를 유지해 코인 분석으로 이동합니다. 예전 조회 API는 보관 자료와 호환하며 예약 수집을 다시 켜지 않습니다.

## 운영 배포·자동화 상태

2026-09-25와 26일 새벽에는 D1 일일 쓰기 한도 소진으로 0009 마이그레이션이 거절되어 배포를 중단했습니다. 26일 09:00 KST 초기화 후 원격 0009 → Worker → Pages 배포가 성공했습니다. 운영 버전은 0.15.0입니다.

09:10:33 KST 브리핑 자동 생성, 여러 차례의 자연 Cron 완료와 핵심 코인 시세 갱신을 원격 읽기 전용 조회로 확인했습니다. 공개 API·실제 분석 화면도 확인했습니다. [배포 식별자·증거·남은 관찰](deploy-15/README.md).

선물 과거 수집은 전 자산 합계 하루 10,000개 후보 관측 예약으로 제한하고, 최근 데이터 수집과 분리합니다. 한도 초과 시 커서를 보존하고 UTC 다음 날 재개합니다. 관련 회귀 테스트를 포함해 38개 파일 324개 테스트를 통과했습니다. 이 제한은 계정 전체 D1 쓰기를 보장하지 않으므로 하루 전체 비용과 지연 원천 회복은 계속 관찰합니다.

[Cloudflare 공식 D1 요금·한도](https://developers.cloudflare.com/d1/platform/pricing/). 유료 전환이나 새 DB 우회는 하지 않았습니다. 제품 Cloudflare Cron은 매분 실행하며 임시 배포 후속 heartbeat와 별개입니다.

## 0.15.1 사용성·데이터 후속 수정

[통화·코인 이동, 로고, 기술지표 기준일, 자동 수집 용량과 검증](audit-15/final/README.md). 핵심 코인 시세 60초·최근 선물 5분을 유지하며 보조 코인 일별 자료 확인은 6시간으로 분리합니다. 운영 배포 식별자는 해당 검증 기록에서 확인합니다.

[온체인·선물 우선 화면 검증](audit-15/sections/README.md). 지표 선택은 주 차트 교체이며 여러 지표가 동시에 선택된 것으로 표시하지 않습니다. 가격 비교 여부와 선택 지표는 URL·저장 작업공간에 보존합니다. 가격 비교가 꺼진 온체인·선물에서는 가격 이력·현재가·BTC 상대강도 이력을 요청하지 않습니다.
