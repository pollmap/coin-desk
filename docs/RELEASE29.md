# 0.29 — 모든 추적 코인의 슈퍼트렌드

슈퍼트렌드를 기술·성과 지표에 추가합니다. 기본은 첨부 차트와 같은 **주봉, ATR 10, 배수 3**이며 전체 실제 거래 이력을 사용합니다. ATR 기간·배수·봉 간격을 변경하고 날짜별 값·방향을 확인할 수 있습니다. 기존 150개 코인의 실제 거래소 OHLC가 계산 대상입니다.

- 상승·하락 방향의 계단형 선과 옅은 채움을 캔들 위에 표시합니다. 한국어 화면의 기존 상승 빨강·하락 파랑을 사용하고 방향을 글자로도 표시합니다. 전환·결측 구간은 선으로 연결하지 않습니다.
- TR은 고저 차이와 이전 종가 대비 차이의 최댓값입니다. ATR은 최초 N개 TR의 평균으로 시작하고 이후 Wilder RMA를 사용합니다. 경계를 유지·갱신하는 조건과 엄격한 종가 돌파 판정을 사전에 공개합니다. 기본값은 투자 추천을 뜻하지 않습니다. [TradingView 슈퍼트렌드 정의](https://www.tradingview.com/support/solutions/43000634738-supertrend/) · [ATR 정의](https://www.tradingview.com/support/solutions/43000501823-average-true-range-atr/)
- 주·월봉은 기존 실제 OHLC 집계 API를 사용합니다. 종가만 있는 USD 참조자료로 캔들·ATR을 만들지 않습니다. 지표 선택에서는 지원하는 거래소로 열고, 명시적 USD 참조 링크에는 이유와 대안을 표시합니다.
- 진행·미래 봉을 제외하고, 누락·잘못된 봉 이후에는 연속 표본을 다시 쌓습니다. 이력이 부족한 코인에는 계산 전 상태를 표시합니다. 실제 이력보다 앞선 값을 만들지 않습니다.
- 코인·원천·봉 간격·기간·사용자 설정을 검색, 설명 이동, 공유와 저장·복원에 연결합니다. 새 차트 원시 데이터는 선택 봉 조회 한 번이며 필요한 보조 일별 지표를 켠 경우에만 일봉을 추가합니다.

[계산·화면·배포 검증 기록](audit-29/README.md). 수집 로직·DB·예약 작업과 기존 개인 저장 키는 변경하지 않습니다. 전체 운영 원천의 정상 여부와 이번 지표 구현·배포 결과는 구분합니다.
