# 0.17 검증·배포 기록

분석 사전과 실제 차트 도구 연결의 검증 기록입니다. [기능과 판정 기준](../RELEASE17.md), [이전 운영 증거](../audit-16/README.md)를 함께 봅니다.

## 로컬 검증

- 타입검사 및 단위 회귀 383개 통과. 기존 371개에 패턴 8개·사전 매핑 4개 검사를 추가했습니다.
- 모든 기존 핵심 지표·분석·패턴 설명의 ID, 지원 코인/원천, 실제 실행 링크, 관련 설명, 개인 상태 제외, 작업공간 복원을 검사합니다.
- 캔들 몸통/꼬리, 확정/진행/미래 종료 봉, 0 거래량, 누락·중복·역순, 50/200 표본, 실제 달력상 월/주/시간 간격, 가격 스케일 변화, 미래 관측 추가 시 과거 결과 불변을 확인합니다.
- E2E는 격리 메모리 DB와 실제 Worker 읽기 경로를 사용합니다. fixture의 같은 시가·종가는 도지형 관찰을 제공하고 장악형 0건을 정직하게 표시합니다. 운영 관찰 건수와 혼동하지 않습니다.
- 320·390·768·1000·1280·1440px, 양 테마·axe·200% 확대, 검색·즐겨찾기·Escape, 코인/원천 전환, 실제 관측 부재, 도움말→차트→저장/공유 복원을 검사합니다.
- 측정 도구 검증 중 Lightweight Charts의 500ms 이내 두 번째 먼 클릭 생략과 주석 레이어가 캔버스 아래에 놓이는 문제를 확인했습니다. 주석의 입력 레이어/쌓임 순서를 고쳐 두 점 측정과 세 점 채널을 빠른 클릭으로 검증합니다.

- 초기 통합 검사에서는 로컬 PC 네트워크 일시 중단(`ERR_NETWORK_IO_SUSPENDED`)과 지연으로 일부 기존 흐름이 중단됐습니다. 이를 통과로 처리하지 않고 전체를 다시 실행합니다.
- 별도로 재현한 200% 확대의 캔버스/주석 가로 넘침, 선택 관찰의 초기 레이아웃/StrictMode 이후 구간 초기화를 수정했습니다. Chromium·WebKit 양쪽의 확대·재진입·새로고침·공유·크기 변경 4개 검사가 통과했습니다.
- 복구 2개 검사, 빌드, 문서·브랜드·독립 Decimal 계산 검사를 통과했습니다. 개인 자료 원본은 이번 테스트에 공개하지 않았습니다.

전체 브라우저 재실행·CI와 배포 증거는 완료 후 아래에 기록합니다.

## 운영 확인

아직 이 릴리스의 운영 배포 결과를 기록하지 않았습니다. 원격 스키마를 확인한 뒤 기존 배포 순서를 따릅니다. 수집 로직을 바꾸거나 안정성 기준을 초기화하지 않습니다.
