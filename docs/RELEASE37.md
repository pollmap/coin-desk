# 0.37 — 보리차트 정기 보고서

시장과 Injective의 관측을 결정론적 일간·주간 보고서로 읽습니다. AI와 Telegram 기능은 포함하지 않습니다.

구현 기준은 [통합 설계](ONCHAIN_RESEARCH_INTEGRATION_PLAN.md), 실제 실행과 배포는 [감사 기록](audit-37/README.md)을 따릅니다. 코드가 존재하는 것과 실제 원천·예약·배포 확인은 별도입니다.

- 기존 시장·코인·비교·저장 탐색을 유지하고 보고서 링크를 보조로 추가합니다.
- 공식 Injective SDK·CoinLore·DefiLlama·선택 CoinGecko 입력을 별도 작업자에서 처리합니다.
- 고정 근거와 계산·문장 버전을 저장하며 정정은 새 revision으로 남깁니다.
- 0010 추가 스키마만 적용하고 기존 0001~0009와 사용자 자료를 보존합니다.
- 기존 `/research`, 개인 자료, 브리핑 API와 가격 수집을 유지합니다.
- 보고서 공개 조회는 원천 수집이나 발행을 실행하지 않습니다.

이번 릴리스는 기존 과거 선물 복구의 남은 체크포인트나 전체 시세의 신선도 문제를 해결했다고 표현하지 않습니다. 48시간 대기는 다시 넣지 않습니다.
