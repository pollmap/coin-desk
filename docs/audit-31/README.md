# 가격·지표·비교 연결과 REA 조사

## 문제와 적용

사용자가 코인 이름과 현재 가격을 눌러도 MVRV·RSI로 이동했고, 상세 바로가기에도 가격이 없었습니다. 실제 가격 API와 캔들 렌더러는 이미 존재했습니다. 기능 부재와 탐색 실패를 구분해 기존 가격 렌더러를 주 흐름에 연결했습니다.

**시장 → 가격 차트 → 지표 → 같은 지표 비교 또는 가격 성과 비교 → 저장 → 다시 열기**를 사용 흐름으로 잡습니다. 설명·원천·공식·수집 정보는 기존 정보 패널을 사용합니다. 새 대시보드·장식·소개 문구를 추가하지 않습니다.

## 조사 범위와 근거

[공식 자료 13개 서비스 대조](competitors.md)와 [구조화 목록](competitors.json)은 공식 문서·공개 페이지·불변 공개 소스 커밋을 기반으로 합니다. 토스증권·업비트 데이터랩·CoinGecko·CoinMarketCap·CoinGlass·CryptoQuant·Glassnode·TradingView·Santiment·DefiLlama·Token Terminal·Tokenomist·CryptoRank를 포함합니다.

[REA 정적 분석](rea-static.md)과 [근거 식별자](rea-static.json)는 사용자 포크 `pollmap/rea`, 커밋 `6020a0b3683ce16e1441963473605f870c247e29`, 6.1.0을 직접 빌드한 CLI 실행 결과입니다. 13개 서비스에 익명 공개 요청을 시도해 10개 서비스의 JS URL 30개를 확보했습니다. 전체 JS 그래프 8개, TradingView 좁은 식별자·요약 출력 1개, Toss 압축 입력 해석 불가 1개를 구분합니다. CryptoQuant·Glassnode의 403과 Santiment의 외부 JS 입력 부재는 그대로 남겼습니다. 광고·Turnstile 파일은 제품 구현 근거에서 제외합니다.

TradingView 첫 전체 출력은 210초 시간 제한으로 실패했고 좁은 후속 출력은 성공했습니다. Toss 파일은 gzip 바이트여서 해당 실행의 세부 구조 해석이 불가능했습니다. 원본·압축해제 뷰 해시를 보존했으며 이를 성공한 세부 역공학으로 집계하지 않습니다. REA 분석 입력과 원시 그래프는 Git에서 제외한 work에만 보관합니다.

현재 브라우저에서 보리차트 시장·상세·기존 가격 차트와 CoinGecko BTC 가격/1년 선택을 확인했습니다. CoinGecko의 가격·기간·비교 도구는 직접 관찰했으며 화면과 문서에서 확인한 기능을 서버 구조의 근거로 확대하지 않습니다. 오래 열어 둔 보리차트 탭의 이전 JS와 명시적으로 새로고침한 최신 JS를 구분했습니다. 이전 탭의 과거값 미리보기를 새 회귀 오류로 보고하지 않습니다.

| 증거 수준 | 이번에 확인한 것 | 확인하지 못한 것 |
|---|---|---|
| 실제 화면 | 가격 차트·기간·비교 진입, 기존 가격 차트 접근 난이도 | 경쟁사 모든 모바일·태블릿·유료 기능 |
| 공개 JS 정적 분석 | 파일 해시·Evidence ID·의존/문자열 후보·분석 한계 | 실행 중 요청의 실제 의미·서버 DB |
| 공식 문서·공개 코드 | OHLC/종가 차이, 비교 기준, LWC 업데이트, DefiLlama 어댑터 | 비공개 데이터 계약·캐시·배포 구조 |
| 우리 읽기 API·SELECT | 가격 값·단위·확정 시각·누락 복구 | 전체 150개 이력의 완전성·하루 운영 전체 |

외부 프레임워크 문자열만으로 실제 사용 라이브러리나 서버 DB를 확정하지 않습니다. Token Terminal의 ELT/BigQuery 공유 문서는 문서가 밝힌 역할만 사용합니다. DefiLlama의 공개 어댑터와 LWC의 브라우저 Map은 각각 계산 어댑터와 메모리 구조이며 우리에게 새 DB 도입이 필요하다는 근거가 아닙니다.

## 데이터 대조

[가격 데이터 흐름](price-data.md), [읽기 API 표본](price-api.json), [독립 원천 대조](price-source-match.json)를 참고합니다. 2026-10-13 00:21~00:31 KST 표본에서 명부 150개·Upbit 103쌍·Binance 138쌍·USD 참조 143개를 확인했습니다. 대표 BTC·DOGE·ONDO·PEPE 가격 응답의 구조·시간·통화 검증과 Upbit 확정 일봉 OHLCV 대조는 오류 0입니다. 150개 전수 원천 대조를 완료한 결과는 아닙니다.

이전 선물 시간 관측 누락 67건은 예약 복구 후 정확한 10개 반개방 범위 SELECT에서 67건 존재·잔여 0·조회 쓰기 0을 확인했습니다. 최초 원천 상태 표본은 활성 1,585개 중 정상 1,557개·지연 28개, health 503입니다. 최근 거래가 오래된 Upbit 값은 지연 표시를 유지합니다. 과거 채우기는 디스크 여유 약 7.68GiB로 보호 기준 8GiB에 못 미쳐 보류 상태였습니다.

Binance 분 시세 `ticker.24hr.closeTime`은 공식 정의상 ticker 구간 종료 시각이며, SSE `aggTrade.T`는 실제 거래 시각입니다. 상세 가격 정보에서 분 시세는 ‘시세 기준’, 스트림 거래는 ‘실제 체결’로 구분합니다. 신선도 기준을 완화하지 않았으며 REST 시각을 실제 거래 시각으로 확인하는 수집 계약 개선은 별도 발견 사항입니다.

## 구현·검증·배포 상태

가격 링크는 150개 자산과 양 거래소의 지원 조건을 검증합니다. 기존 MVRV/RSI 분석 기본값과 명시한 공유 링크는 보존합니다. 봉·종가선과 현재가선은 별도 처리하며 USD 종가를 OHLC로 만들지 않습니다. 현재가선 업데이트는 시리즈에 가격선만 갱신하고 확정 이력 배열은 재계산하지 않습니다. 고정 날짜·확대·스타일·원천·저장·복원·모바일 배치와 접근성을 회귀 검사합니다.

최종 CI·배포·운영 검증 결과는 이 문서의 후속 기록으로 추가합니다. 코드 작성만으로 배포·실제 사용자 검증 완료를 주장하지 않습니다. 실제 Apple Safari·VoiceOver와 사람 대상 사용성 과제는 별도 미검증이며 48시간 대기는 적용하지 않습니다.
