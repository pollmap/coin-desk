# 0.36 코인별 사이클 대시보드

시장에서 코인을 고른 뒤 가격·가치평가·보유자·추세를 연속해서 읽고, 필요한 차트만 크게 여는 흐름으로 정리합니다. 기존 계산과 집중 차트는 재사용합니다. [제품 기준](PRODUCT.md) · [검증·배포 기록](audit-36/README.md).

## 변경 범위

- 일반 코인 선택은 대시보드, 지표를 명시한 링크는 기존 집중 차트로 연결합니다.
- 코인별 기간·차트 구성·확대·읽던 위치를 보존하고 작업공간 버전 2의 선택 필드로 저장합니다. 버전 1·2의 기존 저장 의미는 유지합니다.
- USD 장기 종가와 실제 KRW·USDT 캔들을 분리합니다. BTC 해시 리본의 가격 조건은 USD 입력을 사용합니다.
- 전체 이력 MVRV·보유자 MVRV는 양수 관측만 있는 경우 로그축으로 읽습니다. 0·음수를 제거하지 않으며 이런 관측이 있으면 선형축을 사용합니다. NUPL·MVRV Z는 선형축을 유지합니다.
- 공통 가격을 공유하고 개별 지표는 화면 근처에서 불러옵니다. 미지원 지표·빈 관계 검색 결과를 정상 기능처럼 노출하지 않습니다.
- BTC 대비 성과와 같은 지표 비교의 행동을 구분합니다. 기존 리본·볼린저밴드·계절성은 추가 선택으로 보존합니다.
- 검증된 선택적 배포 엔진을 저장소에 옮깁니다. 기본 배포 명령이 과거 Cloudflare 수집기를 재시작하지 않도록 바꿉니다.
- 현재 제품 기준 문서를 하나로 정리하고 이전 릴리스 기록과 분리합니다.

## 운영 선행 작업

미배포 0.35를 먼저 반영했습니다. 원격 main `32b2396`의 검증된 이미지로 API·시세 허브만 교체했으며 수집기·DB 스키마를 유지했습니다. 과거 Coin Metrics 값은 현재 원천과 다시 대조하고 새 백업·독립 복원·변경 전 값 확인 후 보정했습니다. 승인된 선물 과거 복구는 만료·예산·호출 간격·8GiB 보호를 유지해 별도로 진행합니다.

기획서의 이전 오류 수·누락 수를 현재 결과로 복사하지 않습니다. 실제 결과는 감사 기록에 남깁니다.
