# Coin Desk 0.5 — 지표 참고 구간·코인별 온체인·브랜드

2026-09-20 KST 기준. [사이트](https://coin-desk.pages.dev) · [DOGE 온체인](https://coin-desk.pages.dev/onchain/DOGE?period=all) · [MVRV](https://coin-desk.pages.dev/metrics/mvrv?period=all) · [브랜드](https://coin-desk.pages.dev/brand)

## 지표 기준을 바로 읽기

차트 위에 관측일·값·현재 구간·경계 수치를 표시하고 차트 배경에 색을 넣었습니다. 기준은 숨기거나 다시 표시할 수 있습니다. 배경은 실제 시계열과 분리된 차트 주석으로 그려, 기준선 때문에 가격축이나 전체 기간이 확대되지 않습니다.

| 지표 | 표시 기준 |
|---|---|
| BTC MVRV · Bitview | 1 미만 저평가 참고 / 1~3.7 중간 / 3.7 초과 과열 참고. CryptoQuant 기준이며 Glassnode의 3.5 기준과 차이 안내 |
| BTC NUPL | 0·25·50·75%의 과거 참고 구간. 원자료 비율은 화면에서 한 번만 %로 변환 |
| SOPR·STH/LTH MVRV | 1 손익분기. 전체 MVRV의 3.7을 그대로 적용하지 않음 |
| 실현가격 | 같은 날짜 BTC 추정 가격과 같은 USD 축으로 비교 |
| 자체 MVRV-Z | 0 평가 기준. 타사 고정 고점 구간을 같은 값처럼 표시하지 않음 |
| RSI | 30 미만 과매도 참고 / 70 초과 과매수 참고. 사용자가 지정한 기간 기준 |
| MACD·볼린저 | 0 추세 기준·설정한 표준편차 범위. 독립적인 과열 판정으로 표시하지 않음 |
| Coin Metrics MVRV·NUPL | 1 평가 기준·0% 순손익 기준. BTC 과거 과열 수치를 알트코인에 이식하지 않음 |

참고 구간은 매수·매도 명령이나 반전 보장이 아닙니다. 원문과 실제 관측 데이터의 원천을 별도로 표시합니다. [기준 정의 코드](../shared/thresholds.ts)에 원문 링크와 경계값 처리 방식을 기록했습니다.

## 전체 이력 수집 결과

기존 공개 API의 43개 시계열·166페이지를 끝까지 확인했으며, 2024년 이후 데이터 잘림은 재현되지 않았습니다. 확인된 ONDO Upbit의 2024-06-14는 제공 시작일이고 마지막 일봉은 2026-09-19입니다. 새 화면은 **제공 시작일·최신 관측일·관측 개수**를 따로 표시합니다.

| 자산 | Coin Metrics 네트워크 시작 | USD·MVRV 시작 | USD 일별 관측 |
|---|---|---|---:|
| BTC | 2009-01-03 | 2010-07-18 | 5,907 |
| DOGE | 2013-12-08 | 2014-01-23 | 4,622 |
| ETH | 2015-07-30 | 2015-08-08 | 4,060 |
| XRP | 2013-01-01 | 2014-08-15 | 4,418 |
| LINK | 2017-09-16 | 2017-09-29 | 3,277 |

기본 네트워크 시계열의 최신 관측일은 2026-09-18이며 지표별 시작일은 다를 수 있습니다. BTC 해시레이트는 2009-01-09부터입니다. USD 합계 22,284일, 네트워크는 자산·날짜 기준 23,504행을 월별 776개 블록으로 보관합니다. 선택 가능한 지표 56개에는 역산 지표 15개가 포함됩니다.

활성 주소·잔고 주소·거래·전송·원장 공급·시총·MVRV를 수집합니다. 수수료는 LINK 제외, 해시는 BTC·DOGE만 제공합니다. 실현시총·실현가격·NUPL은 같은 원천의 MVRV로 역산하며, 원본 CapRealUSD를 직접 수집·독립 검산한 것으로 표시하지 않습니다.

**SOL·ONDO·PEPE의 같은 온체인 이력은 해당 무료 원천에서 제공하지 않습니다.** 거래소 전체 일봉·기술지표는 유지하고 미제공 상태와 가격 화면 진입을 안내합니다. 도미넌스 과거값은 실제 관측 시점부터 쌓으며 확보하지 못한 과거 값을 만들지 않습니다.

## 저장과 서버 갱신

새 테이블 `network_months`는 월별 일일 관측 JSON, `network_coverage`는 자산·지표별 실제 제공 범위를 저장합니다. 최초 원격 적재는 네트워크 1,684 D1 행 쓰기, 추가 XRP·LINK 참고가격은 15,394행 쓰기였습니다. 인덱스 쓰기를 포함한 실측입니다. 적재 직후 DB 크기는 약 19.34MB였습니다.

Cloudflare Cron은 새 5개 온체인 작업과 5개 장기 가격 작업을 6시간 목표 주기로 갱신합니다. 작은 페이지·체크포인트·최근 구간 재조회·원자적 저장으로 중단 후 이어갑니다. 원천별 상태는 62개, 온체인 커버리지는 56개 지표를 각각 검사합니다. 방문자·PC·Codex는 실제 수집에 필요하지 않습니다.

공개 환경에서 DOGE 작업의 다음 실행을 앞당긴 뒤, 실제 Cloudflare Cron이 `network:DOGE`를 실행해 2026-09-20 05:29:21 KST 정상 완료한 기록을 확인했습니다. 데이터 기준일은 원천의 2026-09-18로 유지되며 수집 성공 시각과 혼동하지 않습니다. 다른 네 코인은 초기 적재 완료 상태이며 이후 6시간 주기는 운영 관찰 대상입니다.

초기 수집과 검산:

```sh
python scripts/bootstrap_reference.py
node scripts/import_reference.mjs
python scripts/bootstrap_network.py
node scripts/import_network.mjs
python scripts/verify_network.py --base http://127.0.0.1:8787
python scripts/verify_reference.py --base http://127.0.0.1:8787
```

검산은 보관한 원본 SHA-256을 확인하고, 56개 지표 260,284개 관측을 API 끝페이지까지 대조합니다. 파생값은 Python Decimal로 별도 계산합니다. 백업 도구에도 새 두 테이블을 포함했습니다.

## 브랜드 자산

열린 C와 세 개의 데이터 선으로 독립 심볼을 만들었습니다. SVG 심볼·워드마크, 32/180/192/512px PNG, 여러 크기의 ICO, Web App Manifest와 Open Graph·Twitter 공유 메타데이터를 적용했습니다. [브랜드 자산·제작 방법](BRAND.md)에 파일과 이미지 제작 프롬프트를 기록했습니다.

공유 썸네일은 이미지 생성 도구로 제작한 1733×907 PNG이며 곡선은 실제 가격을 나타내지 않습니다. 이미지가 없는 응답을 파비콘으로 반환하지 않는지 파일 형식·크기·공개 응답 해시로 확인합니다.

## 검증 범위

- TypeScript, 208개 시험·22파일, production build 통과.
- 기준값 경계·단위·같은 날짜 비교·밴드 좌표, 전체 페이지·복구·다중 원천 분리를 검증.
- 로컬 실제 데이터의 56개 온체인 시계열 원본 전량 대조 통과.
- 공개 API 56개 시계열 260,284개 관측값과 장기 USD 22,284개 값의 원본 대조 통과. 실제 공개 파일을 빌드 결과와 해시 대조했고, 390px 모바일에서 가로 넘침 없이 전체 기간을 확인했습니다.
- 로컬 DB 13개 테이블의 백업·복원 해시와 무결성 검사를 통과했습니다. 이번 버전의 원격 복원 실행과는 구분합니다.
- [릴리스 증거](evidence/upgrade-05-release.json)에 Worker·Pages 버전, 원천 상태, 실제 CPU 표본을 기록했습니다. CPU 최대 12ms, 10ms 초과 1건이 있어 무료 CPU 지속 준수를 완료로 표시하지 않습니다.
- 48시간 운영과 계정 전체 무료 사용량의 지속 준수는 관찰 중입니다. 테스트 통과와 장기 운영 완료를 구분합니다.
