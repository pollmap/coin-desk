# 코인 성과 비교와 유사 서비스 조사

확인일: 2026-09-20 KST. 기능 조사는 각 서비스의 공개 화면과 공식 설명을 확인했습니다. 외부 서비스의 데이터나 유료 산출물을 복제하지 않고, Coin Desk가 수집하는 실제 거래소 OHLCV에 분석 방식을 적용했습니다.

## 구현 인터페이스

- 화면: `src/ComparePage.tsx`의 named export `ComparePage`.
- 라우트: `/compare?assets=BTC,DOGE,ETH&market=binance&period=1y`.
- 화면 스타일: `src/comparison.css`를 컴포넌트에서 직접 불러옵니다.
- 산식: `shared/comparison.ts`, 계산 버전 `common-utc-close-v1`.
- 개인 설정: 브라우저의 기존 설정 네임스페이스 내 `comparison` 키. 다른 사람과 자동 공유되지 않습니다.
- 공유 URL은 코인·시장·기간을 저장합니다. 데이터 자체나 분석 당시 시점을 동결하지 않으며 방문 시 확보된 최신 확정 일봉을 이용합니다.
- CSV는 실제 공통 날짜의 원 종가, 시작 100 지수, 시작 대비 변화율과 계산 버전을 담습니다.

## 계산과 결측 처리

모든 코인에 값이 있는 마지막 UTC 확정 일봉을 찾고, 그 날짜에서 30·90·365·1,095일을 역산합니다. 시작일을 포함하므로 30일 수익률에 필요한 표본은 31개 종가입니다. 전체는 선택한 거래소가 제공하는 공통 이력입니다.

| 항목 | 정의 |
|---|---|
| 시작 100 지수 | 해당일 종가 / 공통 시작일 종가 × 100 |
| 기간 수익률 | (공통 마지막일 종가 / 공통 시작일 종가 − 1) × 100 |
| 최대 낙폭 | min(해당일 종가 / 그날까지의 최고 종가 − 1) × 100. 값은 0 이하이며 장중 낙폭은 제외 |
| 연환산 변동성 | 일간 로그수익률 ln(Pₜ/Pₜ₋₁)의 표본 표준편차 × √365 × 100 |

- 비교 시작일은 모든 코인이 같으며, 실제 조회 구간을 화면에 표시합니다. 상장일 차이로 요청 기간이 짧아지면 안내합니다.
- 진행 중인 봉, 미래 종가, 0·음수·무한 가격과 UTC 일봉이 아닌 행은 계산하지 않습니다. 중복 날짜는 마지막 관측값으로 정리합니다.
- 선택한 코인 조회가 실패하면 그 코인을 몰래 빼고 결과를 표시하지 않습니다.
- 공통 기간의 날짜 결측을 보간하거나 이전 값으로 채우지 않습니다. 결측이 있는 경우 최대 낙폭은 관측된 공통 종가에 한정되며 변동성은 표시하지 않습니다.
- 연환산 변동성에는 최소 20개의 연속 일간 수익률이 필요합니다. 주식 시장의 252일 관례를 적용하지 않습니다.
- 다른 거래소 가격·환율을 섞지 않습니다. 수수료·세금·스테이킹 수익을 포함한 실현 투자수익이 아닙니다.
- 확대·이동해도 시작 100 기준일과 표의 계산 기간은 고정됩니다. 기간 버튼이나 코인 선택을 바꾸면 다시 계산합니다.

## 요청량과 장애 처리

비교 화면은 자체 저장소의 읽기 API만 사용합니다. 동시에 최대 두 코인을 불러오고 각 코인의 페이지는 순차 조회합니다. 페이지당 최대 1,000봉, 자산당 최대 20페이지를 허용합니다. 메뉴를 빠르게 누르면 200ms 내 변경을 모아 처리하며 이전 요청을 중단합니다.

브라우저 메모리 캐시는 15분·최대 80개 범위로 제한합니다. 화면이 보일 때 15분 간격으로 확인하며 수동 갱신은 30초 대기 시간을 둡니다. 가격 원천 수집 시각과 화면 조회 시각을 별도로 안내하고, 지연된 데이터는 지연 상태로 표시합니다.
