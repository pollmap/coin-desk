# 0.26.2 — 150개 코인 로고

기존 8개만 있었던 코인 로고를 150개 전체로 채웠습니다. 시장·검색·상세·비교·테마와 저장 분석에서 같은 자산 정의를 사용합니다.

- 거래소의 실제 거래쌍·프로젝트 이름을 대조하고 원본 PNG를 로컬 파일로 제공합니다. 가격 원천과 지원 범위는 변경하지 않습니다.
- 출처별 91개 Upbit·57개 Binance·2개 Trust Wallet입니다. 파일별 원문 URL·확인일·식별 근거·내용 해시를 보존합니다. 같은 MNT 표기의 몽골 통화 이미지는 제외했습니다.
- 150개 이미지는 약 2.58MiB이며 모두 지연 로드·비동기 디코딩을 사용합니다. 내용 해시가 있는 이미지에만 장기 캐시를 적용합니다.
- 모바일 이미지 오류에서 대체 표시가 가로로 늘어나던 CSS 충돌을 수정했습니다. 검정 투명 로고에는 흰 바탕을 제공해 다크 테마에서도 식별됩니다.
- 실패 시 원래 크기를 유지하는 두 글자 티커 표시를 사용합니다. 밝은 화면과 어두운 화면에서 같은 테마 색상을 사용하며 옆의 코인 이름을 유지합니다.
- 예전 8개 이미지 경로, 주소·저장 키·개인 원본·DB·수집 예약은 보존합니다. 외부 이미지 서버를 매 화면에서 호출하지 않습니다.
