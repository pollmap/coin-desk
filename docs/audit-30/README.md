# 0.30 지표 비교·데이터 검증 기록

같은 지표 비교(MVRV·RSI 14·낙폭·펀딩률), 최근 확정값과 탐색값 분리, 날짜 고정·공유·저장·복원, 원천별 이력 조회와 읽기 캐시를 구현했습니다. 가격 성과 비교와 기존 공유·저장 형식은 유지합니다.

## 실제 데이터와 남은 공백

2026-10-11 읽기 전용 검사는 150개 자산, 가격 원천·봉 482개 조합, 온체인·내부 가격 442개 조합, USD 참조가격 143개, 선물 지표 680개 조합을 조사했습니다. 조사 조합은 모두 관측이 있었고 온체인 coverage 인덱스와 실제 저장의 차이는 0입니다. 참조가격의 저장 시작이 명부의 최초 원천 날짜보다 늦는 사례는 없었습니다. 모든 공급자의 모든 과거 관측을 독립 재수집했다는 뜻은 아닙니다.

- 33개 MVRV의 최근 저장값을 원천의 2026-10-10 관측과 대조해 일치했습니다.
- 가격·온체인 공백은 원천 요청 372회 및 개별 날짜 검사를 진행했습니다. 확인 시점에 원천 관측이 없는 구간을 보간하거나 최신값으로 채우지 않았습니다. 거래 없음·수정·철회의 원인을 확인하지 못한 경우 미확인으로 유지합니다.
- 선물 73개 공백 중 6개 일별 롱 계정 비중은 현재 원천에서 관측이 확인되지 않았습니다. 나머지 67개 시간별 관측은 원천에 존재합니다.
- 67개 복구 시도는 일일 과거 후보 10,000개 제한 때문에 삽입 0개, `paused_daily_budget`입니다. 2026-10-12 00:00:10 UTC(09:00:10 KST)부터 기존 프로젝트의 일회성 타이머가 체크포인트 재개를 수행합니다. 공간·백업·원천·일일 예산을 다시 검사하며 성공 시 해당 타이머만 종료합니다. 예약은 복구 완료가 아닙니다.

## 공간과 보존

보리차트의 비활성 감사용 백업·실패한 임시 백업을 SHA-256, 전체 테이블 내용, 실제 복원으로 대조한 뒤 sidecar를 포함한 압축본에 보존했습니다. 운영 관측·다른 프로젝트·일일 백업은 삭제하지 않았습니다. WAL 체크포인트 전후 무결성은 정상이며 관측 변경 SQL은 0입니다. 8GiB 보호 기준은 유지합니다. 여유 공간은 시점별 측정으로 기록하며 미래 용량을 보장하지 않습니다.

## 검증 범위와 실패

주요 PR #60의 PR CI 38136835768와 main CI 38137572761은 단위 712개·Node 서버 26개·Python 24개·복구 2개·각 브라우저 127개(개인 경로 1개씩 제외)를 재시도 없이 통과했습니다. 후속 PR #61에서 비교 화면의 중복 main, 대표값의 코인 식별, 선택 날짜의 결측 표시를 보완했습니다. PR #62는 대표값·기준일의 글자 크기를 보완했습니다. 최종 CI와 배포 식별은 JSON 증거를 따릅니다.

앞선 실패를 성공에 포함하지 않습니다. PR CI 38135053639는 WebKit 초점·사전 준비 상태, 38135953582는 StrictMode 최초 비교 조회의 중복 요청 이후 WebKit 로딩 시간 초과가 있었습니다. 초기 중복 조회를 방지하고 준비 상태·초점 복귀 검사를 수정했습니다. 정확한 시간 초과 원인은 확정하지 않았습니다. 초기 로컬 Chromium Target crashed, 후속 로컬 WebKit 768px 45초 시간 초과도 미확정으로 기록합니다. QA 도구의 잘못된 expect 설정·Windows 기본 문자열 인코딩 오류는 수정 후 다시 실행했으며 제품 API 장애로 계산하지 않습니다.

실제 공개 데이터 흐름은 두 주소에서 저장·복원, hover 최근값 유지, 날짜 고정, 지표 설명, 미지원 ONDO 분리와 RSI 이동, 3개 코인 기술 지표, 펀딩률 별도 패널, DOGE 이력 정보, 양 테마·접근성을 검사했습니다. 자동 브라우저 결과와 실제 Windows Chrome 조작은 구분합니다.

## 성능·운영 해석

초기 측정 조건은 1280×800, 다운로드 10Mbps·업로드 5Mbps, 추가 지연 0, CPU 1배, 주소별 신규 브라우저 문맥 20개입니다. 변경 전 Pages LCP p95 1,512ms·VPS 3,156ms, 첫 0.30 배포 후 Pages 1,444ms·VPS 3,284ms였습니다. VPS는 2.5초 목표 미달이며 후퇴 원인을 단정하지 않습니다. 첫 VPS 측정의 Target crashed를 보존하고 동일 조건 20회를 다시 측정했습니다. 최종 릴리스 측정은 별도 JSON에 기록합니다.

최초 0.30 운영 SSE 시험은 동시 100명, 30초, 재연결 10명으로 연결 오류 0, 서버 수신→시험 클라이언트 p95 971ms입니다. 화면 반영 시간과 구분합니다. 브라우저 시계 오차를 포함한 화면 반영 상한은 Pages 1,582ms·VPS 2,070ms였습니다.

직접 수집 API·overview를 호출하지 않은 120초 원격 SELECT 표본에서 핵심 양 거래소 시세 6개의 실제 체결·확인 시각과 최근 선물 38개 확인이 증가했습니다. 다른 방문자 부재나 하루 전체의 증거는 아닙니다. 일부 업비트 자산은 실제 최근 체결이 300초를 지나 health 503이 발생합니다. API 프로세스 정상·스트림 연결·모든 원천 정상은 별개입니다.

## 배포와 외부 미검증

PR·main CI와 백업 복원을 확인한 뒤 변경된 API(웹 포함)와 Pages만 배포했습니다. 수집기 6개 컨테이너·스키마 0009·기존 예약은 유지했습니다. 공개 파일은 Linux 빌드와 대조하며 VPS HTML의 공유 이미지 주소 2개 변경만 의도적으로 허용합니다. 이전 이미지와 정적 자산을 보존합니다.

실제 Apple Safari·VoiceOver 및 처음 쓰는 사람의 과제 검사는 미검증입니다. WebKit·axe는 이를 대체하지 않습니다. 기존 전역 CSS 전체 통합은 이번 변경에서 완료한 것으로 표현하지 않습니다. 48시간 대기는 적용하지 않습니다.

최종 Pages 첫 업로드에서 `--cwd pages`가 빠져 API가 HTTP 200으로 SPA HTML을 반환했습니다. 실제 Chrome과 실데이터 QA가 실패를 검출했습니다. 기존 Pages Functions·BACKEND binding을 포함해 다시 배포하고 JSON·스키마·VPS 릴리스 일치와 두 주소의 흐름을 재검사했습니다.

대표값이 11px인 기존 스타일을 실제 Chrome에서 확인해 PR #62로 16px, 기준일과 범례는 최소 12px로 보완했습니다. 원격 CI와 최종 공개 화면의 실제 글자 크기를 검사합니다.

최종 글자 크기 수정 후 첫 성능 측정도 `browserContext.newPage: Target crashed`로 중단됐습니다. 실패를 통과 집계에서 제외하고 로그를 보존했으며, 동일한 측정 조건과 별도 새 브라우저 프로세스로 두 주소의 20회를 다시 검사했습니다. 종료 원인은 확정하지 않았습니다.

최종 120초 자연 갱신 표본은 선물 확인 시각 증가 6개로 최소 9개 조건에 못 미쳐 통과하지 못했습니다. 기준을 바꾸거나 수집 API를 호출하지 않고 300초로 관찰을 늘려 확인했습니다. 첫 표본도 `natural-first-below-threshold.json`에 보존합니다.
