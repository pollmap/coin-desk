# 0.27 — 검색·모바일 시장·데이터 상태 개선

코인을 찾고 지표로 이동하는 검색을 통합합니다. 기존 차트·개인 저장·원천과 주소는 유지합니다. [검증 및 배포 기록](audit-27/README.md)

## 사용자 화면

- 상단과 시장 검색은 같은 검색 시트를 사용합니다. `비트코인 고평가`는 BTC MVRV, `펭귄 추세`는 PENGU RSI로 연결합니다. 검색어는 투자 판단으로 해석하지 않습니다.
- 명시한 코인·원천·기간·날짜를 유지하며, 미지원 지표를 다른 코인의 데이터로 대체하지 않습니다. 늦은 검색 응답과 취소한 Enter는 다른 화면으로 이동시키지 않습니다.
- 모바일 시장은 검색·전체/관심/테마·거래소/정렬·목록 순서입니다. 이어 보기는 설정 행에 배치하며 중복 로딩 문장으로 목록이 움직이지 않게 합니다.
- 상태 화면은 요약을 먼저 읽고, 원천 표를 펼칠 때 50개씩 조회합니다. 기존 `/api/v1/status`는 호환합니다.

## 검색과 관계

`GET /api/v1/search?q=…&asset=…&kind=…&limit=…`는 100자·20개 결과까지 허용합니다. 티커·별칭, 코인과 목적, 본문 순으로 검색합니다. SQLite FTS5 trigram/BM25는 별도 worker thread에서 실행하며 대기열 16개·3초·128MiB JS 힙을 제한합니다. 실패하면 구조화 카탈로그 검색으로 복귀합니다. 운영 DB에 쓰지 않습니다.

문서는 정의·기준선·공식·예시·한계를 구분하며 출처·확인일·검토 상태·해시·색인 버전을 갖습니다. 빌드 시 변경하지 않은 문서의 조각을 재사용합니다. 운영 어휘 색인은 **384 UTF-8 바이트의 보수적 상한·32바이트 겹침**을 사용합니다. 기존 공식은 모두 상한 안에 들어 한 조각으로 보존됩니다. 선택적인 모델 시험은 고정한 실제 토크나이저로 **384 토큰·32 토큰 겹침**을 별도 검증합니다. 문자 수를 모델 토큰 수로 표현하지 않습니다.

개인 글·이미지·메모·가격 시계열은 공개 색인에 포함하지 않습니다. AAVE·SHIB는 Ethereum의 네이티브 자산이 아닌 확인한 발행 네트워크 관계로 표시합니다. 관계 종류와 개별 근거의 확인일·검토 상태를 유지하며 미검토 관계는 확정 사실로 승격하지 않습니다.

`multilingual-e5-small` 공식 ONNX int8 변환을 고정 리비전으로 비교했습니다. 100개 고정 과제에서 기본 검색 100/100, 결합 검색 100/100으로 개선 폭은 0%p입니다. 따라서 벡터 검색은 **운영 비활성**이며 모델을 VPS에 설치하지 않습니다. 시험은 첫 50개 자산의 목적·지표 조합으로 구성한 개발 회귀 과제입니다. 사람 대상 이해도 또는 모든 자유문장 검색 정확도를 뜻하지 않습니다. Neo4j·별도 벡터 DB·생성형 RAG는 추가하지 않습니다.

## 데이터와 운영 보호

- 150개 자산의 지원 시장·봉 이력·온체인 지원과 실제 저장 범위를 읽기 전용으로 대조합니다. 직접 수집·overview를 호출하지 않습니다.
- 시세 지연은 예약 수집, 실제 체결, Binance 24시간 통계 기준 시각, 일별 원천 관측, 검증 오류를 구분합니다. 기존 오류 코드와 300초 신선도는 유지합니다.
- `/api/v1/status/summary`, `/api/v1/status/sources`를 추가합니다. 원천 조회는 최대 100개·offset 10,000·검색 100자로 제한합니다. 새 경로의 5초 조회 재사용은 응답 기준 시각을 숨기지 않으며 CDN의 오래된 상태 캐시를 사용하지 않습니다.
- API 응답 크기·처리 시간·이벤트 루프 p95·메모리를 운영 runtime에 기록합니다. 검증되지 않은 프록시 IP 헤더는 신뢰하지 않습니다.
- 선택적인 과거 이력은 디스크 여유 8GiB 미만에서 보류하며 최근 수집은 유지합니다. 기존 자료·백업·다른 프로젝트를 삭제하지 않습니다.
- CSP는 후보 환경의 Report-Only 검사 후 강제합니다. HTTPS HSTS, 권한 제한, 프레임 차단, MIME 보호를 적용합니다. 차트 스타일 때문에 `style-src 'unsafe-inline'`은 허용하지만 인라인 스크립트는 허용하지 않습니다.
- CI에 npm 의존성 감사와 컨테이너 취약점·구성 검사를 추가합니다. 수정 가능한 HIGH/CRITICAL은 차단하고 수정판이 없는 항목은 별도 기록합니다.

DB 스키마·공개 기존 API·저장 키·자료함 형식은 유지합니다. 변경한 API와 디스크 보호가 있는 background만 교체하고 시세·최근봉·분석·백업·중앙 스트림 서비스는 보존합니다. 48시간 대기는 완료 조건이 아닙니다. 실제 Safari/VoiceOver와 모집 사용자 검사는 별도 미검증입니다.

## 배포와 최종 검사

0.27.0은 Pages와 VPS에 배포했고 PR #56·#57을 main에 병합했습니다. 최종 main CI는 686개 단위·44개 서버/VPS·2개 복구·216개 브라우저를 재시도 없이 통과했습니다. 두 주소의 실제 검색·차트·저장 복원·150개 자산 지원 이력, 34개 자산·408개 온체인 조합의 최근 원천값, 자연 수집과 SSE 100명을 확인했습니다.

Pages LCP p95 1.208초는 목표를 통과했고 VPS 2.760초는 2.5초 목표에 미달했습니다. 공급자 자체 시세 지연, 수정판이 없는 컨테이너 발견 사항, 실제 Safari/VoiceOver·사람 검사는 그대로 기록합니다. 벡터 검색은 개선 0%p로 운영 비활성입니다. 검사·증거 문서만 바뀐 후속 커밋은 재배포하지 않습니다. [전체 검증 기록](audit-27/README.md)
