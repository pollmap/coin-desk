# 코인별 탐색 개편 (2026-09-24)

## 목표와 완료 조건

사용자가 DOGE를 선택하면 DOGE 가격의 첫 확보일에서 시작해 온체인·선물·BTC 대비 성과까지 이어서 보고, BTC나 ETH 분석이 선택된 것처럼 보이지 않아야 합니다. 핵심 가격 차트가 첫 화면에 보여야 하며 장기 가격 통계는 적정가로 오해되지 않아야 합니다. 데이터가 없으면 숫자를 만들지 않고 원천·단위·첫 관측일·마지막 관측일을 표시합니다.

## 이번 구현

1. 사이드바는 BTC·DOGE·ETH 세 자산을 기준으로 구성합니다. 선택 자산의 하위 메뉴만 펼치고, query와 fragment까지 구분해 한 메뉴만 활성화합니다. 시장 전체 비교는 접어 둡니다.
2. 자산 진입 시 전체 가격을 기본으로 하고 Coin Metrics의 실제 첫 확보일을 차트와 범위 조절기에 표시합니다. 온체인 페이지에서도 지원하는 자산만 전환 대상으로 보여줍니다.
3. 730일 로그 가격 분포는 기본 화면에서 접고, 계산 전 730일의 공백과 적정가가 아니라는 사실을 요약에 명시합니다. 상세 출처와 작업공간도 필요할 때 펼칩니다.
4. 선물은 펀딩비, 미결제약정, 롱 보유 계정 비율을 각각 표시합니다. 롱 비율은 Bybit V5 `buyRatio × 100`이며 포지션 규모 비중이 아닙니다. 원천의 `sellRatio`와 합이 약 1인지 검증하고, 최근 30일을 먼저 가져옵니다. 백필 중 첫 관측일은 실제 확보 범위만 표시합니다.

## 후속 순서

- 최우선: BTC·DOGE·ETH의 데스크톱/모바일 화면, 자산 전환, 새 롱 비율의 원천 응답과 Cron 수집을 운영에서 검증합니다.
- 다음: 자산별 온체인 지표도 하나의 짧은 개요와 접는 세부 지표로 재배치하고, 온체인 원천별 실제 시작일을 보여줍니다.
- 그다음: 거래소와 계약 유형을 혼합하지 않는 범위에서 청산·롱/숏 관련 지표를 추가할지 원천 이력·비용·권리를 검토합니다. 미확인 수치는 추가하지 않습니다.

모든 가격·선물 자료의 갱신 시각은 각각 다릅니다. 화면의 60초 재조회가 모든 원천이 60초마다 새 관측을 생성한다는 뜻은 아닙니다.

## 이번 검증

`npm run check`에서 238개 테스트와 TypeScript 검사를 통과했고 `npm run build`도 통과했습니다. Pages 미리보기에서 DOGE 선택 시 DOGE 메뉴만 펼쳐지고 2014-01-23 첫 가격부터 차트가 보이는 것을 데스크톱·390px 모바일에서 확인했습니다. 모바일은 세 코인 선택기를 한 줄로 줄이고 기간은 선택 상자로 표시합니다. Bybit 롱 계정 비율의 세 Cron 작업은 운영 D1에서 모두 최근 성공·오류 없음으로 확인했고 공개 API에서 BTC·DOGE·ETH 각각 실제 200개 관측을 확인했습니다. 이후 이력 백필과 장기 연속 가동은 별도 관찰 대상입니다.
