# 0.28 이력 시작·위치 밴드 검증

## 발견 및 수정

DOGE 위치 밴드가 약 3년만 표시되던 원인은 두 가지였습니다. 시장에서 선택한 업비트 원화가 새 위치 밴드에도 이어졌고, 주 가격선도 밴드 계산이 가능한 날짜 이후로 잘렸습니다. 압축 보관 이력을 포함한 실제 저장에는 USD 2014-01-23, Binance USDT 2019-07-05, Upbit KRW 2021-02-24 이후의 일별 관측이 있었습니다.

새 위치 밴드는 가장 오래된 검증 원천 하나를 기본으로 선택하고, 주 가격선은 해당 원천의 전체 이력으로 표시합니다. 730일 조건·결측 초기화·미래 관측 미사용·표준편차 0의 위치 null을 유지합니다. 명시된 URL·저장 설정의 원천과 날짜는 바꾸지 않습니다.

## 범위와 증거

- [코인별 시작·밴드 시작 목록](history-starts.csv): 150개 자산, 원천별 가격 시작과 최초 계산 가능 날짜. 출시일 또는 전 세계 최초 거래일로 표현하지 않습니다.
- [원천 시작·첫 가격 검증](provider-origins.json): 241개 거래소 조합과 143개 USD 참조 조합. Upbit는 저장 시작 이전의 캔들이 없는지와 첫 캔들을 확인하고, Binance는 startTime=0, Coin Metrics는 공식 일별 카탈로그 최소 시각과 실제 첫 응답으로 확인합니다.
- [온체인 시작 대조](network-origins.json): 34개 자산·442개 저장 조합. 408개 노출 지표와 34개 내부 참조가격을 포함합니다. 유도값의 시작은 필요한 원천 필드 시작일 중 최댓값과 대조합니다. 전체 과거 관측값 검산은 포함하지 않습니다.
- [DOGE 페이지 검증](doge-before.json): 전체 페이지 5/3/3, 각각 USD 4,643개·Upbit 2,055개·Binance 2,655개 응답. 진행 봉을 포함하는 API 응답 개수이며 계산은 확정 봉만 사용합니다.

앞선 0.27 감사 도구는 `candles`의 최근 행만 집계해 보관 이력의 시작을 누락했습니다. 해당 시점의 과거 감사 파일은 보존하고, 새 도구에서 `price_archive`와 최근 봉을 합쳐 중복을 제거합니다. 정상 응답이나 최근 500개만으로 전체 이력 확보를 판단하지 않습니다.

## 검증·배포 상태

코드·브라우저·원격 CI·배포 증거는 검사가 끝나면 이 문서와 verification.json에 추가합니다. 이 초기 문서만으로 배포 완료를 주장하지 않습니다. 기존 개인 자료·사용자 문서·저장 키·이력 DB를 보존하며 48시간 대기는 적용하지 않습니다.
