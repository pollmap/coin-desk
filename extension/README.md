# Coin Desk 개인 자료 가져오기

1. ZIP을 풀고 Chrome의 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**에서 이 폴더를 선택합니다.
3. X에 로그인한 뒤 확장에서 현재 게시물·북마크·계정·리스트 모드를 선택합니다. 리스트 주소는 `/i/lists/숫자` 형식입니다.
4. **새 탭에서 읽기 시작**을 누릅니다. 사용 중인 원래 탭은 변경하지 않습니다. 수집 탭을 닫으면 작업이 멈춥니다.
5. Coin Desk → 내 작업공간 → 개인 자료함에서 **Chrome 연결**을 누르고, 확장에서 **연결한 Coin Desk에 전송**을 누릅니다. 또는 JSONL로 저장한 뒤 자료함에서 가져옵니다.

중지·재개와 중복 가져오기를 지원합니다. 수집된 글은 확장 IndexedDB에 먼저 저장되며, 사이트로 전송되지 않았더라도 남습니다. 기기 간 동기화와 브라우저가 닫힌 동안의 수집은 없습니다. 확장을 제거하면 확장 저장소는 삭제되므로 먼저 전송·JSONL 백업하세요.

X의 화면에 표시되는 본문·게시일·작성자·이미지 URL만 읽습니다. 접힌 장문, 삭제된 글, 비공개 글, 과거 검색 제한과 접근 제한은 별도 수집으로 우회하지 않습니다. '추가 로딩 없음'은 전수 과거 이력 확보 완료가 아닙니다. 목록 수집은 화면에서 확인한 구성원만 이어서 읽습니다.

인증 쿠키·비밀번호·토큰·메시지를 읽거나 서버로 전송하지 않습니다. 사이트 전송은 자료함의 일회성 연결, 탭 ID, 주소와 만료 시간을 확인합니다. 공개 링크에 개인 원문이 들어가지 않습니다.

로컬 개발 사이트에서는 **로컬 개발 자료함 연결 허용**을 먼저 누르고 해당 탭을 새로고침하세요. 로그인 만료·화면 구조 변경·일시 제한 시 체크포인트와 이미 저장한 글은 보존되며 직접 재개할 수 있습니다.

대량 전송은 확장 창을 열어둔 동안 짧은 묶음으로 이어집니다. 창을 닫거나 연결이 끊겨도 확인된 글·이미지 전송 위치가 남습니다. 자료함을 다시 연결한 뒤 **연결한 Coin Desk에 전송**을 누르면 미완료 자료부터 재개합니다. 전송 시작 때의 자료 묶음을 고정하므로 그동안 새로 수집한 글은 다음 전송에 포함됩니다. **중지**는 수집과 전송 모두에 적용됩니다.

자료가 많으면 **큰 창에서 계속하기**로 확장을 탭에 열어 두세요. 차트나 X로 이동해도 전송 화면이 닫히지 않습니다.
