# 코인 로고 출처

150개 자산의 로고를 로컬 파일로 제공합니다. 자산 ID, 프로젝트 이름과 거래소의 실제 거래쌍을 대조했습니다. 같은 티커의 다른 프로젝트나 통화 이미지는 사용하지 않습니다. PNG 원본은 편집 없이 복사했습니다. 파일별 원문 URL·확인일·SHA-256·대조 기준은 [sources.json](sources.json)에 있습니다.

- **Upbit 91개:** 공식 시장 목록의 종목명·거래쌍과 `static.upbit.com` 이미지.
- **Binance 57개:** 공개 자산 정보의 자산명·심볼과 `bin.bnbstatic.com` 이미지. 업비트의 과도하게 큰 원본 일부에도 일치하는 프로젝트 이미지를 사용합니다. 가격 원천은 변경하지 않습니다.
- **Trust Wallet 2개:** Mantle과 Akash Network의 프로젝트 정보·자산 ID와 로고를 고정 커밋 `0b78a77c9c97bb06f98f8eb66f5ab0a231f421cd`에서 대조했습니다. [MIT 라이선스](LICENSE)를 유지합니다.

거래소에서 가져온 이미지에 Trust Wallet의 MIT 라이선스를 적용하지 않습니다. 프로젝트 로고와 상표의 권리는 각각의 권리자에게 있습니다. 로고는 종목 식별 용도로 표시하며 제휴·추천을 뜻하지 않습니다. 무료 API 접근이 모든 상업적 재사용 권리를 보장한다고 표현하지 않습니다.

`v2/` 파일명에는 내용 해시가 포함되어 장기 캐시가 가능합니다. 이전 8개 로고 주소는 보존합니다. 이미지가 열리지 않으면 동일 크기의 티커 표시와 옆의 코인 이름을 사용합니다.
