Chrome에서 자료 가져오기

  1. 확장 ZIP 다운로드 후 압축을 풉니다.
  2. Chrome 주소창에 chrome://extensions를 입력하고 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드에서 coin-desk-importer 폴더를 선택합니다.
  4. X에 로그인한 뒤 확장에서 읽을 범위를 선택하고 시작합니다. 별도 수집 탭이 열립니다.
  5. 자료함에서 Chrome 연결 → 확장에서 연결한 Coin Desk에 전송을 누릅니다.

글은 이 기기에만 보관됩니다. 다른 기기로 옮기려면 자료함의 백업·복원을 사용하세요. 처음에는 정보와 썸네일을 가져오고, 원본 이미지는 용량을 확인해 추가할 수 있습니다.

Chrome이 닫히면 수집을 재개해야 합니다. X가 공개하는 화면 범위만 읽으며, 접힌 글·삭제·접근 제한을 전체 이력으로 표시하지 않습니다. 현재 가격·온체인·선물의 서버 자동 수집은 별도로 계속 동작합니다.
